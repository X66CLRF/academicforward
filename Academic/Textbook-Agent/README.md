# 📚 Textbook Agent Suite

ชุดเอเจนต์สำหรับเขียนตำราเรียนและเอกสารประกอบการสอนฉบับเต็ม — แยกออกมาจาก Research-Agents เพราะกระบวนการทำตำราต่างจากงานวิจัย ทั้งสไตล์การอ้างอิง ความยาวต่อหน่วยงาน และการส่งไม้ข้าม session

---

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้เมื่อไร | ได้อะไรออกมา |
|---|---|---|
| [structure-agent.md](structure-agent.md) | **ก่อนเริ่มเล่มใหม่** ยังไม่มีโครง ยังไม่มีคลังอ้างอิง | ไฟล์โครงสร้างเล่ม (พร้อมตารางเจ้าภาพเนื้อหา) + ไฟล์คีย์เวิร์ดสืบค้น |
| [textbook-agent.md](textbook-agent.md) | **ตอนเขียนเนื้อหาจริง** มีโครงและคลังอ้างอิงพร้อมแล้ว | เนื้อหาตำราทีละหัวข้อย่อย + Bibliography_Log + Image_Prompt_Log + บัตรสถานะ |

---

## กระบวนการ 4 ขั้น

```
ขั้น 0  structure-agent.md   ออกแบบโครงเล่ม + คีย์เวิร์ด        → ไฟล์โครงสร้าง, ไฟล์คีย์เวิร์ด
ขั้น 1  ผู้เขียน              เอาคีย์เวิร์ดไปค้นเอกสาร            → PDF และลิงก์
ขั้น 2  ผู้เขียน              อัปโหลดเข้าคลัง NotebookLM/Drive    → คลังอ้างอิงพร้อมใช้
ขั้น 3  textbook-agent.md    เขียนทีละหัวข้อย่อยในคลัง           → ตำรา
```

**ขั้น 3 ต้องทำในสภาพแวดล้อมที่เข้าถึงคลังอ้างอิงได้จริง** (NotebookLM ที่อัปโหลดไฟล์แล้ว หรือเครื่องมือที่อ่านโฟลเดอร์เอกสารได้) — สถานะ `✓ ยืนยันจากคลัง` มีความหมายก็ต่อเมื่อโมเดลเปิดเอกสารต้นทางได้จริง ถ้ารันในที่ที่เข้าคลังไม่ได้ ทุกรายการต้องเป็น `⚠ ต้องตรวจสอบ` เท่านั้น

## ไฟล์ที่เอเจนต์สร้างสะสมระหว่างทาง

เก็บไว้คู่กับโปรเจกต์ตำราของแต่ละเล่ม ไม่ใช่ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `[รหัสวิชา]_Structure.txt` | โครงบท-หัวข้อย่อย-กิจกรรม (ผลจากขั้น 0) |
| `[รหัสวิชา]_Search_Keywords.txt` | คีย์เวิร์ดสืบค้นรายบท (ผลจากขั้น 0) |
| `[รหัสวิชา]_Bibliography_Log.md` | อ้างอิงสะสมทั้งเล่ม พร้อมสถานะ ✓/⚠ |
| `[รหัสวิชา]_Image_Prompt_Log.md` | พรอมท์สร้างภาพทุกภาพ → จัดเป็นภาคผนวกท้ายเล่ม |
| บัตรสถานะ | ส่งไม้ข้าม session — ออกทุกครั้งที่จบบทหรือพัก |

## ความสัมพันธ์กับชุดอื่น

- `textbook-agent.md` ยืมจาก [../Research-Agents/1.CORE-rules.md](../Research-Agents/1.CORE-rules.md) เฉพาะ **แม่แบบบรรณานุกรม APA (ส่วนที่ 4)**, **กฎกันอ้างอิงปลอม 5 หน้ากาก (ส่วนที่ 8)** และ **AI Writing Detection (ส่วนที่ 10)**
- **กฎการอ้างอิงในเนื้อของ textbook-agent ทับกฎ CORE** เพราะตำราอ้างอิงแบบเนียนในความเรียง ไม่ใช่แบบ (ผู้แต่ง, ปี) กลางเนื้อแบบงานวิจัย
- งานร่างโครงหรือเอกสารประกอบการสอนขนาดเล็ก ใช้โหมดในของ `researcher-agent.md` หรือ `grad-agent.md` ได้ ไม่ต้องมาชุดนี้
