### ขั้นที่ 1 — เลือกไฟล์

ดูตาราง "เลือก Agent ให้ถูกตัว" ด้านบน → ระบุว่าคุณต้องใช้ไฟล์ใด

เปิดไฟล์ 2 ไฟล์นี้ในโปรแกรมแก้ข้อความ (Notepad, VS Code, ฯลฯ):

```
CORE-rules.md          ← ต้องแนบเสมอ
[role]-agent.md        ← ตามบทบาทของคุณ
```

### ขั้นที่ 3 — สร้าง System Prompt

**วิธีที่ 0: Gemini Gem (วิธีหลักของ workshop มรนว.)**
1. เปิด Gemini → เมนู **Gems** → **New Gem**

5. Save → นักศึกษาเปิดแชทใหม่จาก Gem นี้ทุกครั้ง — สมองติดมาอัตโนมัติ
> ⚠️ **คุยยาวแล้วกฎหลุด — เคสจริง**: Gem ที่ถือกฎครบก็ยังทิ้งกฎได้เมื่อแชทยาว (ไม่ audit, เขียนรวดทั้งหัวข้อ, แต่งอ้างอิงเอง) บัญชีฟรีเจอเร็วกว่าเพราะคอนเทกซ์ต่อแชทน้อยกว่า — กันด้วย **บัตรสถานะ + ขึ้นแชทใหม่** (CORE ส่วนที่ 7): 1 หัวข้อใหญ่ = 1 แชท / บัญชีฟรี 1 หัวข้อรอง = 1 แชท / กู้กลางทางด้วย "ทวน checklist ใน CORE ส่วนที่ 7 แล้วตรวจสิ่งที่เพิ่งเขียน"
> 💬 ผู้ใช้ที่ชนเพดานคอนเทกซ์บ่อยจนงานสะดุด: แจ้งได้ว่าบัญชีแบบชำระเงินรับข้อความต่อแชทได้มากกว่า (เป็นข้อมูลประกอบการตัดสินใจ + อุดหนุนทรัพยากรที่ระบบใช้) — แต่ไม่ใช่เงื่อนไขบังคับ ทุกกฎในชุดนี้ทำงานได้บนบัญชีฟรีด้วยวิธีบัตรสถานะ

## 📊 เปรียบเทียบ 3 Agents (v3.0)

| มิติ | ป.ตรี | ป.โท/เอก | นักวิจัย |
|------|------|---------|---------|

| **งานวิจัย/หัวข้อ** | 3–5 ชิ้น | 5–10 ชิ้น | 10–15 ชิ้น |
| **Theory source** | หนังสือพื้นฐาน | Primary + secondary | Seminal + recent reviews |
| **Integrity** | เข้มสุด | กลาง | ยืดหยุ่น |
| **Predatory check** | สั้น | กลาง | ละเอียด มี tools |
| **สื่อการเรียนรู้** | Lesson Plan + Quiz + Worksheet | Training Module + E-Learning | Course Design + Backward Design |
| **คู่มือ** | คู่มือโครงการ/ชมรม | SOP + Research Protocol | นโยบายสถาบัน + Lab Manual |
| **ตำรา** | — (นอกขอบเขต) | ตำราระดับบัณฑิต | ตำราระดับบัณฑิตศึกษา |
