# 🔎 scan-ocr-agent — คลังข้อความจากเอกสารสแกน (OCR & Source Vault)

> **สำหรับ**: ผู้เขียนตำรา เอกสารประกอบการสอน และงานวิจัย ที่มีแหล่งอ้างอิงเป็น **ไฟล์สแกน** (PDF ไม่มีชั้นข้อความ) ปนกับไฟล์ Word/Excel/PDF ปกติ และทำงานสลับหลายเครื่องผ่าน Google Drive
> **เวอร์ชัน**: v1.0 | **ขอบเขต**: สกัดข้อความ ทำดัชนี อ่านหน้าสแกน บันทึกย่อพร้อมเลขหน้า · ไม่ใช่การเขียนเนื้อหา
> **ใช้ร่วมกับ**: [textbook-writer](../Writing/4-textbook-writer.md) · [nsru-2568-manual-reference](../Writing/nsru-2568-manual-reference.md) · [thai-academic-language-guard](../Writing/thai-academic-language-guard.md)
> **สคริปต์**: [`scripts/extract_sources.py`](scripts/extract_sources.py) · [`scripts/render_scan_pages.py`](scripts/render_scan_pages.py)

> **แบ่งงานให้ชัด** — ไฟล์นี้รับผิดชอบ **การทำให้แหล่งอ้างอิงอ่านได้และค้นได้** สกิลสายเขียนรับผิดชอบการนำไปเรียบเรียง

## 🧭 เมนูนำทางตั้งต้น

* **[พิมพ์ 1] 🗂️ สร้างคลังข้อความทั้งโฟลเดอร์:** สกัด docx/pdf/xlsx/pptx เป็น Markdown + `INDEX.md` + `manifest.json`
* **[พิมพ์ 2] 🔎 อ่านไฟล์สแกนเฉพาะบท:** แปลงหน้าเป็นภาพ อ่านด้วย AI แล้วบันทึกย่อพร้อมเลขหน้า
* **[พิมพ์ 3] 📚 ถอดข้อมูลบรรณานุกรมจากหน้าลิขสิทธิ์:** ผู้แต่ง ปี พิมพ์ครั้งที่ สำนักพิมพ์ ISBN
* **[พิมพ์ 4] ♻️ อัปเดตคลังหลังเพิ่มไฟล์:** รันซ้ำ ข้ามไฟล์ที่ไม่เปลี่ยน

## 🛑 1. กฎเหล็ก

1. **ห้ามเขียนเนื้อหาจากไฟล์สแกนที่ยังไม่ได้อ่านจริง** — `manifest.json` ติดธง `needs_ocr: true` = ข้อความใน `extracted/` เป็นแค่ป้าย "หน้านี้ไม่มีชั้นข้อความ" ห้ามนับว่าอ่านแล้ว
2. **ข้อมูลบรรณานุกรมต้องอ่านจากหน้าปกและหน้าลิขสิทธิ์เท่านั้น** ห้ามใช้ชื่อไฟล์ ห้ามใช้ปีและเลขหน้าจากร่างเก่า
   > เคสจริง: ร่างเก่าอ้าง "วันรักษ์, 2547, หน้า 234" แต่เล่มในคลังคือ **พิมพ์ครั้งที่ 5 พ.ศ. 2548 สำนักพิมพ์จุฬาฯ บทที่ 7 หน้า 95–110** ผิดทั้งปี หน้า และสำนักพิมพ์
3. **บันทึกย่อเชิงสาระ ไม่ถอดทั้งหน้า** — เก็บนิยาม ตัวเลข สูตร ตัวอย่าง พร้อม **เลขหน้าของเล่ม** (ไม่ใช่เลขหน้า PDF) เพื่อเลี่ยงการทำซ้ำงานมีลิขสิทธิ์ และให้อ้างอิงได้ทันที
4. **ระบุวิธีสกัดในหัวไฟล์เสมอ** (`method: vision` หรือ `method: text-layer`) คนที่เปิดอ่านบนเครื่องอื่นต้องรู้ว่าข้อความมาจากไหน
5. **คลังเก็บในโฟลเดอร์งานบน Drive** ไม่เก็บในเครื่อง — เครื่องไหนเปิดโฟลเดอร์ก็ใช้ต่อได้
6. **ห้ามดาวน์โหลดหรือติดตั้งโปรแกรม OCR โดยไม่ถามผู้ใช้**

## 🗂️ 2. โครงสร้างคลัง (มาตรฐาน)

```text
<โฟลเดอร์งาน>/
├── CLAUDE.md                       ← บริบทย่อ ชี้มาที่ README
├── README_สำหรับผู้ช่วย_AI.md       ← แผนที่โฟลเดอร์ + สถานะงาน
└── _คลังข้อมูล/
    ├── INDEX.md                    ← ดัชนีคนอ่าน (ธง "สแกน ต้อง OCR")
    ├── manifest.json               ← ดัชนีโปรแกรมอ่าน (path, sha1, pages, needs_ocr)
    ├── extracted/                  ← ข้อความจากชั้นข้อความ (.md) โครงสร้างตรงต้นฉบับ
    │   └── <ไฟล์>.pdf.OCR.md        ← บันทึกจากการอ่านภาพ วางคู่ไฟล์เดิม
    └── tools/extract_sources.py
```

แหล่งอ้างอิงที่อยู่นอกโฟลเดอร์งาน (เช่น คลังตำราส่วนตัว) ให้เพิ่มใน `EXTRA_ROOTS` ของสคริปต์ ผลจะขึ้นต้นด้วย `คลังตำราอ้างอิง/`

## 🔧 3. ขั้นตอนการทำงาน

### ขั้น 1 — สร้างหรืออัปเดตคลัง

```bash
pip install python-docx pymupdf pandas openpyxl xlrd python-pptx
python "_คลังข้อมูล/tools/extract_sources.py"
python "_คลังข้อมูล/tools/extract_sources.py" --force
```

สคริปต์ทำงานดังนี้
- เทียบ sha1 ข้ามไฟล์ที่ไม่เปลี่ยน
- **ลองอ่านซ้ำ 4 ครั้ง** เมื่อเจอ `OSError` (ไฟล์ Google Drive ที่ยังสตรีมไม่เสร็จ) ถ้ายังพลาด บันทึกว่า "ยังไม่ได้ดาวน์โหลดจาก Google Drive" แล้วไปต่อ ไม่ล้มทั้งชุด
- PDF หน้าที่ข้อความน้อยกว่า 30 ตัวอักษร นับเป็นหน้าสแกน ถ้าเกินครึ่งเล่ม → `needs_ocr: true`
- ไฟล์ `.xls` ที่จริงเป็น HTML (ธปท. ส่งออกแบบนี้บ่อย) → ลอง `read_html` ถ้าได้ 0 ตัวอักษร แจ้งผู้ใช้ให้ดาวน์โหลดใหม่เป็น `.xlsx`

### ขั้น 2 — คัดไฟล์สแกนที่ต้องอ่าน

อ่าน `manifest.json` → กรอง `needs_ocr: true` → **อ่านเฉพาะไฟล์ที่เกี่ยวกับบทที่กำลังเขียน** อย่าอ่านทั้งคลังรวดเดียว (เปลืองโควตาภาพมาก)

### ขั้น 3 — แปลงหน้าเป็นภาพ

เครื่องมือ Read ของ Claude Code อ่าน PDF เป็นภาพได้เมื่อมี poppler แต่เครื่อง Windows ส่วนใหญ่ไม่มี ให้ใช้ PyMuPDF แทน

```bash
python "Automation/scripts/render_scan_pages.py" "<ไฟล์.pdf>" --out "<scratchpad>/png" --tag prai --dpi 130
```

- สีเทา 130 dpi อ่านภาษาไทยชัด ขนาดไฟล์ราว 150–300 KB ต่อหน้า
- เก็บภาพใน scratchpad ไม่เก็บบน Drive

### ขั้น 4 — อ่านภาพตามลำดับนี้

1. **หน้าปกและหน้าลิขสิทธิ์** → ผู้แต่ง (ตัดยศ) ปี พิมพ์ครั้งที่ สำนักพิมพ์ ISBN
2. **สารบัญ** → เลขหน้าหัวข้อ ใช้กำหนดว่าต้องอ่านหน้าไหนต่อ
3. **หน้าเนื้อหาเฉพาะหัวข้อที่ต้องใช้** ครั้งละ 3–4 ภาพ

### ขั้น 5 — บันทึกผลเป็น `<ไฟล์>.pdf.OCR.md`

```markdown
---
source_path: "คลังตำราอ้างอิง/<ไฟล์>.pdf"
method: "อ่านจากภาพสแกนด้วยผู้ช่วย AI (vision)"
extracted: YYYY-MM-DD
status: "บันทึกย่อเชิงสาระ + เลขหน้าอ้างอิง ไม่ใช่การถอดความทั้งบท"
---

# <ผู้แต่ง> (<ปี>) บทที่ X <ชื่อบท>

## ข้อมูลบรรณานุกรม (อ่านจากหน้าลิขสิทธิ์)
ชื่อ  นามสกุล. (ปี). *ชื่อเรื่อง* (พิมพ์ครั้งที่ N). สำนักพิมพ์.
- ISBN ...
- ⚠️ จุดที่ต่างจากร่างเดิม (ถ้ามี)

## โครงสร้างบท (จากสารบัญ)
| หัวข้อ | หน้า |

## สาระสำคัญรายหน้า
### หน้า NN — <หัวข้อ>
- **นิยาม**: ...
- ตัวอย่างในเล่ม: ...
- สูตร: ...
```

### ขั้น 6 — ส่งต่อสกิลสายเขียน

อ้างอิงแบบนาม-ปีพร้อมเลขหน้าจากบันทึก เช่น `วันรักษ์  มิ่งมณีนาคิน (2548, น. 96)` และแนบบรรณานุกรมที่ถอดจากหน้าลิขสิทธิ์ ถ้าข้อมูลช่องใดยังไม่ครบ ให้รวบแจ้งบรรทัดเดียวท้ายบรรณานุกรม
