## 2. รายงาน KPI

สคริปต์: `~\Documents\GitHub\aritc-audit\scripts\kpi-report.mjs` (ล็อกเจ้าของ gasidid.p — เขียน KPI คนอื่นไม่ได้)

```powershell
cd ~\Documents\GitHub\aritc-audit
node scripts/kpi-report.mjs list        # ดู KPI + ประเภทงาน + จำนวนรายการ
node scripts/kpi-report.mjs add --kpi design --type "อินโฟกราฟิก/สื่อหลายหน้า" `
  --title "สไลด์และใบงาน อบรมห้องสมุดในยุคดิจิทัล (มจร นครสวรรค์)" `
  --request 2026-09-21 --delivered 2026-09-25 `
  --evidence "ห้อง NoteBoard|https://noteboard.nsru.ac.th/board/<board id>"
# ตรวจผล dry run กับผู้ใช้ → ผู้ใช้ยืนยัน → รันซ้ำพร้อม --commit
```

| งาน | `--kpi` | `--type` |
|---|---|---|
| ภาพโพสต์ใบเดียว ป้าย โปสเตอร์ | `design` | `กราฟิกทั่วไป` (2 วันทำการ) |
| สไลด์ ใบงาน ชุดภาพหลายใบ ผังชุด WP/WI ภาพประกอบตำรา | `design` | `อินโฟกราฟิก/สื่อหลายหน้า` (3 วันทำการ) |
| คลิปสั้น / วิดีโอยาว | `design` | `วิดีโอสั้น` / `วิดีโอขนาดใหญ่` |
| เก็บ/สำรองภาพกิจกรรมที่ไปอบรม | `photo` | `จัดเก็บและสำรองข้อมูลภาพ` |

* `--request` = วันรับคำขอพร้อมเนื้อหาครบ (เช่น วันที่ได้รับมอบหนังสือเชิญ) · `--delivered` = วันส่งไฟล์ไฟนอล
* ชื่อรายการ: `<ชนิดสื่อ> <ชื่องาน> (<หน่วยงาน/สถานที่>)` · หลักฐานใส่ชื่อกำกับทุกลิงก์ (`ชื่อ|url`)
* งานไหนมีหลายชิ้นส่งวันเดียวกัน (สไลด์ + ใบงาน) = **1 รายการ** หลายหลักฐาน
* ห้ามรัน `--commit` โดยผู้ใช้ยังไม่ยืนยัน (เขียน DB จริง) · สคริปต์กันซ้ำด้วยชื่อ + วันส่ง
