# 📚 เอกสารอบรมการใช้งานฐานข้อมูลวิชาการ มรนว. 2568 - ส่วนที่ 3 (สำหรับผู้อบรม)

## 🤖 คลังคำสั่ง AI Prompts สำหรับผลิตสื่อจากเนื้อหาจริง (1-to-1 Content-Driven AI Prompts)

> **⚠️ แนวทางปฏิบัติสำคัญ:** พรอมต์ในส่วนนี้ออกแบบมาเพื่อดึงประสิทธิภาพเนื้อหาดิบ (บทความวิเคราะห์/ผลลัพธ์) ที่ได้จากการค้นหาจริงมาให้ AI ประมวลผลและแปลงเป็นสื่อที่แตกต่างกันตามเป้าหมายคลาสเรียน **ผู้เรียนสามารถกดคัดลอกข้อความในกรอบด้านล่าง ไปใช้วางในระบบ AI ได้ทันที** (อย่าลืมเปลี่ยนข้อความในวงเล็บ `[...]` เป็นเนื้อหาของคุณ)

### 📡 1. IEL (IEEE/IET)
*แปลงข้อมูลมาตรฐานอุตสาหกรรม ➔ ไอเดียสรุปแผ่นพับอินโฟกราฟิก*
```text
คุณคืออินโฟกราฟิกดีไซเนอร์ ช่วยนำข้อมูลมาตรฐานทางเทคนิค [วางเนื้อหาเอกสารมาตรฐานที่ค้นได้จากฐานข้อมูล IEL] มาสรุปเป็นข้อความสั้นกระชับ 5 หัวข้อหลักเพื่อใช้วางบนแผ่นพับประชาสัมพันธ์นวัตกรรม พร้อมแนะนำไอเดียการจัดวาง Layout และโครงสีของภาพที่ดูเป็นสากลและน่าเชื่อถือ
```

### 🧬 2. Springer Nature
*แปลงขั้นตอนแล็บโปรโตคอล ➔ บทวิดีโอสั้น TikTok/Reels*
```text
ช่วยนำขั้นตอนการทดลองและโปรโตคอลวิทยาศาสตร์จากเนื้อหาตรงนี้ [วางเนื้อหาแล็บโปรโตคอลที่ค้นได้จากฐานข้อมูล Springer Nature] มาเปลี่ยนเป็นสคริปต์วิดีโอสั้นความยาว 60 วินาทีสำหรับเผยแพร่ในโซเชียลมีเดีย โดยย่อยขั้นตอนซับซ้อนให้ผู้เรียนทั่วไปเข้าใจได้ง่าย ระบุมุมกล้อง คำพูดผู้พากย์ และอารมณ์ฉากให้ชัดเจน
```

### 🧪 3. ACS (American Chemical Society)
*แปลงงานวิจัยเคมีจำเพาะ ➔ โครงสร้างสไลด์นำเสนอภาษาไทย*
```text
ช่วยนำข้อมูลงานวิจัยเคมีและรายละเอียดโครงสร้างเด่นจากบทความนี้ [วางเนื้อหาบทคัดย่อหรือข้อมูลโครงสร้างที่สืบค้นได้จาก ACS] มาออกแบบเค้าโครงสไลด์บรรยายภาษาไทยจำนวน 3 หน้า โดยแบ่งเป็น หน้า 1: หัวข้องานวิจัยและ Pain point หลัก, หน้า 2: โครงสร้างทางเคมีและระเบียบวิธีทดลอง, หน้า 3: ผลลัพธ์วิจัยและการนำไปประยุกต์ใช้ในอุตสาหกรรม ขอแบบกระชับ ตรงประเด็น
```

### 📊 4. Emerald Management
*แปลงกรณีศึกษาธุรกิจ ➔ บทสรุปและคำถามชวนคิดในคลาส*
```text
คุณคืออาจารย์คณะบริหารธุรกิจ ช่วยนำกรณีศึกษาการจัดการองค์กรชุดนี้ [วางเนื้อหาเคสธุรกิจที่สืบค้นได้จาก Emerald] มาวิเคราะห์เขียนสรุปใจความสำคัญใน 1 ย่อหน้าสั้น และตั้งคำถามชวนคิด (Discussion Questions) จำนวน 3 ข้อ เพื่อให้นักศึกษานำไปอภิปรายกลุ่มเกี่ยวกับแนวคิดและทฤษฎีการแก้ปัญหาขององค์กร
```

### 🧠 5. ScienceDirect (Elsevier)
*แปลงทฤษฎีแกนหลัก ➔ เนื้อหาการ์ดดรรชนีสรุปคำศัพท์*
```text
ช่วยย่อยเนื้อหาทฤษฎีและบทนิยามวิชาการจากข้อมูลหน้านี้ [วางเนื้อหาที่ก๊อบปี้มาจาก ScienceDirect Topics Page] ให้กลายเป็นการ์ดคำศัพท์วิชาการ (Glossary Card) ที่กระชับสำหรับใช้ทบทวนความรู้ โดยแบ่งโครงสร้างข้อมูลเป็น 3 ส่วนหลัก: 1. คำศัพท์เทคนิควิชาการ 2. คำแปลและคำอธิบายเชิงทฤษฎีแบบสรุปไม่เกิน 2 ประโยค 3. ตัวอย่างรูปธรรมของการนำทฤษฎีนี้ไปใช้จริง
```

### 🌿 6. Academic Search Ultimate
*แปลงบทคัดย่อวิจัยสิ่งแวดล้อม ➔ คำโปรยแบนเนอร์สรุปแก่น*
```text
ช่วยนำบทคัดย่อ (Abstract) ของบทความวิจัยด้านสิ่งแวดล้อมฉบับนี้ [วางบทคัดย่อที่ค้นได้จาก Academic Search Ultimate] มาเขียนเป็นคำโปรย (Caption) สั้นๆ เพื่อดึงดูดผู้เขียนบทความวิจัย ความยาวไม่เกิน 3 ประโยค สำหรับนำไปแปะประกอบแบนเนอร์สรุปองค์ความรู้บนสื่อประชาสัมพันธ์ของคณะ
```

### 🚗 7. Engineering Source
*แปลงรายงานตลาดยานยนต์ ➔ บทสรุปผู้บริหารหน้าเดียว*
```text
ช่วยวิเคราะห์และประมวลผลข้อมูลจากรายงานอุตสาหกรรมชิ้นนี้ [วางข้อมูลรายงานอุตสาหกรรมที่ค้นได้จาก Engineering Source] ให้เป็นรายงานสรุปสำหรับผู้บริหาร (Executive Brief) ความยาวหนึ่งหน้ากระดาษ โดยสรุปประเด็นเป็นข้อๆ ใน 3 หัวข้อหลักคือ 1. แนวโน้มการพัฒนาเทคโนโลยีปัจจุบัน 2. ตัวเลขสถิติตลาดที่สำคัญ 3. โอกาสและความท้าทายในอนาคต
```

### 🛡️ 8. ASTSU
*แปลงข้อมูลภัยคุกคาม ➔ ข้อความคำสั่งสั่งภาพกราฟิกแดชบอร์ดไอที*
```text
ช่วยนำตัวเลขและสถิติข้อมูลภัยคุกคามทางไซเบอร์ที่ระบุในบทความนี้ [วางเนื้อหาหรือสถิติไอทีที่ค้นได้จาก ASTSU] มาแปลงเป็นแนวคิดจินตภาพเชิงลึก โดยเขียนออกมาเป็นภาษาอังกฤษ (AI Text-to-Image Prompt) สำหรับนำไปป้อนให้ AI สร้างภาพเพื่อผลิตภาพพื้นหลังสไลด์แนว 3D Isometric แดชบอร์ดข้อมูลความปลอดภัยระบบที่มีความล้ำสมัยและดูสะอาดตา
```

### 🔍 9. EBSCO Discovery Service (EDS)
*แปลงผลลัพธ์ข้อมูลภาพรวม ➔ ข้อความอธิบายขั้นตอนแผนผังกระบวนการ*
```text
ช่วยสรุปแก่นเนื้อหาที่ดึงมาจากระบบสืบค้นรวมชิ้นนี้ [วางเนื้อหาผลการสืบค้นข้อมูลรวมที่ค้นได้จาก EDS] ให้กลายเป็นข้อความอธิบายขั้นตอนการทำงาน (Workflow Description) สั้นๆ จำนวน 3 ขั้นตอน เพื่อใช้ใส่ในสื่อแผนภูมิกระบวนการเรียนรู้ แสดงให้นักศึกษาเห็นว่าโจทย์วิจัยชิ้นนี้เกิดจากการเชื่อมโยงและผสมผสานคำตอบจากศาสตร์หลากหลายสาขาร่วมกันอย่างไร
```

### 📚 10. CU e-Book Library
*แปลงบทเรียนเด่นจากตำราไทย ➔ ข้อความการ์ดสรุปแก่นวิชาการ*
```text
ช่วยนำข้อความวิชาการและข้อสรุปสำคัญจากหน้าตำราเล่มนี้ [วางเนื้อหาข้อความภาษาไทยที่คัดลอกจากตัวเล่มใน CU e-Book] มาสรุปจัดทำเป็นคำอธิบายประกอบ "การ์ดไฮไลต์ความรู้" (Book Highlight Card) เพื่อใช้ในกระบวนการจัดการความรู้ ย่อยสาระสำคัญให้อ่านเข้าใจง่ายทันทีใน 3 บรรทัด สำหรับใช้ตอบคำถามนักศึกษาในทีมได้อย่างมีประสิทธิภาพ
```
