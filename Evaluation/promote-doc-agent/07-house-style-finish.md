## **🔖 บรรทัดอ้างหลักฐานในตารางสมรรถนะ (House Style)**

ในช่องคอลัมน์ ๓ ห้ามเขียนชื่อไฟล์หลักฐานยาว ๆ ให้ปิดท้ายช่องด้วยบรรทัดรูปแบบนี้บรรทัดเดียว

```
เอกสารแนบ<ชื่อหมวด> ระดับที่ ๓: หมายเลข ๒๒, ๒๓, ๒๔ และ ๓๘
```

ชื่อหมวดดึงจากคอลัมน์ ๑ ของตารางโดยตัดวงเล็บลำดับ `(ก)` `(ข)` ออก `cite.py` เติมให้ทั้ง ๔๒ ช่องพร้อมที่วางเลข `【…】` และ **ข้ามช่องที่มีคำว่า "เอกสารแนบ" อยู่แล้วเสมอ** เพราะถือว่าเจ้าของพิมพ์เองแล้ว (กฎเหล็กข้อ ๓)

```bash
python cite.py "<path.docx>"           # dry run — ค่าตั้งต้น
python cite.py "<path.docx>" --write   # เขียนจริง
```

เลขจริงเกิดท้ายสุดจากลำดับในภาคผนวก แล้วแทน `【…】` ทีเดียวทั้งเล่ม วิธีนี้เลขไม่มีทางหลุด เพราะสืบจากภาคผนวกโดยตรง

## **🏛️ เติมคอลัมน์หน่วยงานในตารางฝึกอบรม**

ชื่อหลักสูตรที่ดึงจากชื่อไฟล์เกียรติบัตรมักไม่มีชื่อหน่วยงาน และชื่อไฟล์ที่มาจากการพิมพ์ตามภาพมักสะกดเพี้ยน วิธีที่ใช้ได้คือ **จับคู่ชื่อหลักสูตรกับแพลตฟอร์มผู้จัด** แล้วเขียนชื่อเต็มลงคอลัมน์หน่วยงาน `org.py` ทำให้แบบมีรายงานความมั่นใจ

| แพลตฟอร์ม | เขียนในเล่มว่า | หลักสูตรที่มักเป็นของเจ้านี้ |
| :--- | :--- | :--- |
| OCSC Learning Portal | สำนักงาน ก.พ. (การอบรมออนไลน์) | หนังสือราชการ · สมรรถนะหลักข้าราชการพลเรือน · วินัยและจรรยา · ภาษาอังกฤษเพื่อการทำงาน · Microsoft Office · ทักษะการคิด · เทคนิคการนำเสนอ · การบริหารงบประมาณและการเงิน |
| TDGA | สถาบันพัฒนาบุคลากรภาครัฐด้านดิจิทัล (TDGA) สำนักงานพัฒนารัฐบาลดิจิทัล (องค์การมหาชน) (การอบรมออนไลน์) | ธรรมาภิบาลข้อมูล · digital literacy · blockchain for government services · hadoop/big data · UX-UI · รัฐบาลดิจิทัล |
| Thai MOOC | โครงการมหาวิทยาลัยไซเบอร์ไทย (Thai MOOC) กระทรวงการอุดมศึกษา วิทยาศาสตร์ วิจัยและนวัตกรรม (การอบรมออนไลน์) | รายวิชาที่ขึ้นต้นว่า Thaimooc ในชื่อไฟล์ |

**กฎการเขียน** ใส่ `(การอบรมออนไลน์)` ต่อท้ายทุกหลักสูตรออนไลน์ ตามแบบที่ใช้อยู่เดิมในเล่ม และเขียนชื่อหน่วยงานเต็ม ไม่ใช้ตัวย่อลอย

**ต้องบอกระดับความมั่นใจเสมอ** `org.py` ออก TSV ที่มีคอลัมน์ ค่าเดิม · หน่วยงานที่จับคู่ได้ · ความมั่นใจ · คีย์เวิร์ดที่ใช้ตัดสิน ให้เจ้าของตรวจ **หลักสูตรที่จัดโดยเครือข่าย เช่น ห้องสมุดสีเขียว ให้ความมั่นใจได้แค่ปานกลาง** เพราะเจ้าภาพหมุนเวียนรายปี ต้องเปิดใบประกาศยืนยัน และแถวที่ชื่อไฟล์ไม่บอกเนื้อหา (`1.jpg`) ห้ามเดาหน่วยงานเด็ดขาด

## **📄 งานเลขหน้าและสารบัญ (ตอนปิดเล่มเท่านั้น)**

คำนวณเลขหน้าจาก `.docx` ไม่ได้ Word เท่านั้นที่รู้ว่าอะไรอยู่หน้าไหน ต้อง export PDF ก่อนแล้วอ่านเลขที่พิมพ์อยู่จริง

```
1  แก้ .docx ให้ครบทุกอย่าง
2  VBA แปลงเลขทั้งเล่ม
3  Save as PDF
4  อ่านเลขหน้าจาก PDF แล้วทำสารบัญ
```

ลำดับนี้สลับไม่ได้ แก้ `.docx` เพิ่มหลัง export = เลขหน้าเลื่อน ต้อง export ใหม่

เลขหน้าเป็นเลขไทย อยู่แถบบนของหน้า อ่านด้วย `pymupdf` โดย clip กล่องแถบบนแล้วจับเฉพาะคำที่เป็นตัวเลขล้วน
