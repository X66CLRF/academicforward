## **📊 ตารางสมรรถนะ — จุดที่ทำงานจริง**

ตารางในเล่มเป็น **ตาราง 3 คอลัมน์** ทุกใบ

| คอลัมน์ | ชื่อ | สถานะ |
| :--- | :--- | :--- |
| ๑ | สมรรถนะ | ฟอร์มราชการ **ห้ามแตะ** |
| ๒ | ระดับที่ ๑–๕ และพฤติกรรมการปฏิบัติงาน | ฟอร์มราชการ **ห้ามแตะ** |
| ๓ | **บันทึกร่องรอยคุณภาพ** | **ช่องเดียวที่แก้ได้** |

แถวที่คอลัมน์ ๒ ไม่มีคำว่า "ระดับที่" คือแถวหัวตาราง ไม่ใช่เกณฑ์ ข้ามไป

### รูปแบบการอ้างหลักฐาน (House Style)

ต่อท้ายข้อความในช่องคอลัมน์ ๓

```
เอกสารแนบการใช้คอมพิวเตอร์ ระดับที่ ๓: หมายเลข ๔๔, ๔๕, ๔๖ และ ๗๑
```

- ระบุเลขเจาะจง **ห้ามใช้ช่วงเลข** เช่น ๔๔-๗๑
- **หนึ่งเลข ใช้ได้ช่องเดียวทั้งเล่ม** ถ้าเลขเดิมเหมาะกับสองช่อง ให้เลือกช่องที่ตรงที่สุด อีกช่องหาหลักฐานอื่นหรือปล่อยว่างแล้วทักผู้ใช้
- ห้ามใส่ระยะห่างด้วย `spacing before/after` ที่บรรทัดนี้ ถ้าต้องการเว้นจากเนื้อความให้ใช้ย่อหน้าว่าง
- ตัวสุดท้ายคั่นด้วย "และ" ตัวอื่นคั่นด้วยจุลภาค
- ส่วนหน้า `เอกสารแนบ<หมวด> ระดับที่ <ระดับ>` ต้องตรงกับหมวดในคอลัมน์ ๑ และระดับในคอลัมน์ ๒

### ต้องเขียนถึงระดับไหน

| ขอตำแหน่ง | กรอกระดับ |
| :--- | :--- |
| **ชำนาญการ** | ๑ – ๓ |
| **ชำนาญการพิเศษ** | ๑ – ๕ |

เรียงตามความยาก ระดับสูงกว่าต้องยากกว่าเสมอ

### วิธีเขียนช่องร่องรอยคุณภาพ

เขียนเป็นความเรียง ลำดับ

1. ผู้ปฏิบัติงานทำอะไร (อ้างอิงจาก JD WP WI คู่มือปฏิบัติงาน)
2. ทำแล้วเกิดผลอะไร วัดได้เป็นตัวเลขยิ่งดี
3. ปิดท้ายด้วยการอ้างเลขหลักฐาน

**ห้ามเขียนลงในเนื้อความ**

| ห้าม | ทำไม | เขียนแทนว่า |
| :--- | :--- | :--- |
| "รายวิชาที่อบรมรองรับงานส่วนนี้คือ…" · "หลักสูตรที่สอดคล้องได้แก่…" | ชี้นำกรรมการ และตัวหลักสูตรไม่ใช่ผลงาน ชื่อหลักสูตรอยู่ในตารางฝึกอบรมกับภาคผนวกอยู่แล้ว | ตัดทิ้ง ปล่อยให้เลขหลักฐานพูดแทน |
| "แสดงให้เห็นว่าผู้ปฏิบัติงานมีสมรรถนะระดับที่ ๓" | ตัดสินแทนกรรมการ | บรรยายงานที่ทำจริงให้ตรงคำกุญแจของระดับนั้น |
| ตัวเลขที่ไม่มีหลักฐานรองรับ | ตรวจย้อนไม่ได้ | เขียนเชิงคุณภาพอิง JD และระเบียบวิธีปฏิบัติงาน |

### บันไดระดับ — สิ่งที่ต้องเปลี่ยนคือคำกริยา ไม่ใช่ความยาว

| ระดับ | ความสัมพันธ์กับงาน | คำกริยาที่ควรปรากฏ | เพดาน — ห้ามล้ำ |
| :--- | :--- | :--- | :--- |
| ๑ | **ใช้ของที่มีอยู่** | ใช้ / จัดทำ / บันทึก / เข้าร่วม / ทำตามเทมเพลต | อย่าพูดถึงการปรับปรุงงาน |
| ๒ | **ทำให้คล่องและลดขั้นตอน** | ใช้อย่างคล่องแคล่ว / ทำงานซ้ำให้อัตโนมัติ / ลดขั้นตอน / ให้คำแนะนำเฉพาะหน้า | อย่าพูดถึงการออกแบบระบบทั้งระบบ |
| ๓ | **ขอบเขตกว้างขึ้น ปัญหายากขึ้น** | ประยุกต์หลักการ / พัฒนางานในหน้าที่ / แก้ปัญหาที่ยุ่งยากและมีขอบเขตกว้างขวาง / ใช้หลายเครื่องมือร่วมกันเป็นระบบงาน | **อย่าใส่ ถ่ายทอดความรู้ เป็นที่ปรึกษา อ้างทฤษฎี** — เป็นของระดับ ๔ |
| ๔ | **เชี่ยวชาญ + สอนต่อ** | ประยุกต์ทฤษฎี / ถ่ายทอดความรู้ / ให้คำปรึกษาแนะนำ / ดัดแปลงปรับปรุงของเดิม | เก็บไว้ใช้ตอนขอชำนาญการพิเศษ |
| ๕ | **สร้างใหม่ + ขยายผลกว้าง** | สร้างองค์ความรู้ใหม่ / วางระบบ / วางมาตรฐาน / ขอบเขตกว้างขวางมาก | เก็บไว้ใช้ตอนขอชำนาญการพิเศษ |

คอลัมน์ขวาสุดคือหัวใจ **ระดับหนึ่ง ๆ ไม่ได้วัดแค่ว่าเขียนถึงอะไร แต่วัดว่าไม่เขียนถึงอะไรด้วย**

ถ้อยคำจริงในฟอร์มระดับ ๓ ของหมวดความรู้ความสามารถ ระบุไว้ ๓ คำ ต้องตอบให้ครบ

```
ประยุกต์หลักการ  พัฒนางานในหน้าที่  แก้ไขปัญหาที่มีความยุ่งยากและมีขอบเขตกว้างขวาง
```

**`ถ่ายทอดความรู้` และ `ให้คำปรึกษาแนะนำ` เป็นถ้อยคำของระดับ ๔ ไม่ใช่ระดับ ๓**
เขียนเรื่องการสอนไว้ในระดับ ๓ ได้ถ้ามีจริง แต่อย่าอ้างว่าเป็นข้อกำหนดของระดับนั้น

### ⚠️ เผื่อเพดานไว้ — ระดับ ๓ ห้ามเขียนแรงเกิน

ขอชำนาญการเขียนถึงระดับ ๓ แต่วันหนึ่งจะขอชำนาญการพิเศษที่ต้องเขียนถึงระดับ ๕
**อัดของดีทั้งหมดไว้ที่ระดับ ๓ ตั้งแต่รอบแรก = รอบหน้าไม่เหลืออะไรให้ไต่ต่อ**

ก่อนเขียนระดับ ๓ ให้อ่านถ้อยคำระดับ ๔ ก่อนเสมอ อะไรที่เข้าข่ายระดับ ๔ ให้กันไว้ อย่าใส่ในระดับ ๓ แม้จะทำได้จริง

ระยะห่างระหว่างระดับต้องสม่ำเสมอ ถ้า ๒→๓ กระโดดไกลกว่า ๑→๒ มาก แปลว่าระดับ ๓ แรงเกิน
