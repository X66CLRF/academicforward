# 📋 Evaluation Suite — เอกสารขอกำหนดตำแหน่งสูงขึ้น (สายสนับสนุน)

> **สำหรับ**: บุคลากรสายสนับสนุน มหาวิทยาลัยราชภัฏนครสวรรค์ ที่ขอรับการประเมินระดับชำนาญการ / ชำนาญการพิเศษ

---

## 📂 สารบัญไฟล์ในหมวดนี้:

| ไฟล์ | ชื่อเรียก | ฟังก์ชันหลัก |
| :--- | :--- | :--- |
| 📋 **[promote-doc-agent.md](promote-doc-agent.md)** | **promote-doc Agent** | **ไฟล์เดียวจบ** — ถ้อยคำเกณฑ์ ๑๒ สมรรถนะ × ๕ ระดับ + กฎเผื่อเพดาน + เรียบเรียงช่องบันทึกร่องรอยคุณภาพ + จับคู่หลักฐาน + ออกเลขเอกสารแนบ + เช็คลิสต์ปิดเล่ม |
| 🐍 **[scripts/](scripts/)** | ชุดสคริปต์ Python | แก้ไฟล์ `.docx` โดยไม่พังฟอร์แมต — เขียนเลขอ้างลงตาราง เรียงเลขคำบรรยายใต้ภาพ ตรวจหลักฐานครบ |
| 🗂️ **[templates/evidence-template.tsv](templates/evidence-template.tsv)** | เทมเพลตตารางหลักฐาน | ผู้ใช้ตีความภาพเอง กรอกลงตารางนี้ แล้วเอเจนต์รับช่วงต่อ |

---

## 🔑 หลักการสำคัญ 3 ข้อ

**1. สองสายเดินแยกกัน** สายเขียนเนื้อหา (คู่มือปฏิบัติงาน / JD WP WI / วิจัย / พอร์ทโฟลิโอ) กับสายหลักฐาน (คำสั่ง / เกียรติบัตร / อบรม / ภาพปฏิบัติงาน) ทำพร้อมกันได้ ไม่ต้องรอกัน แล้วมาเจอกันตอนจับคู่

**2. เลขเอกสารแนบเกิดท้ายสุด** ระหว่างทางใช้รหัสชั่วคราว `E001` เพราะถ้าตั้งเลขจริงตั้งแต่ต้น พอตัดหลักฐานออกใบเดียวเลขจะเลื่อนทั้งแถบ

**3. เอเจนต์ไม่อ่านภาพแทนผู้ใช้** ผู้ใช้เปิดดูและตีความเอง เอเจนต์เกลาสำนวนและจับคู่ให้

