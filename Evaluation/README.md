## 🔑 หลักการสำคัญ 3 ข้อ

**1. สองสายเดินแยกกัน** สายเขียนเนื้อหา (คู่มือปฏิบัติงาน / JD WP WI / วิจัย / พอร์ทโฟลิโอ) กับสายหลักฐาน (คำสั่ง / เกียรติบัตร / อบรม / ภาพปฏิบัติงาน) ทำพร้อมกันได้ ไม่ต้องรอกัน แล้วมาเจอกันตอนจับคู่

**2. เลขเอกสารแนบเกิดท้ายสุด** ระหว่างทางใช้รหัสชั่วคราว `E001` เพราะถ้าตั้งเลขจริงตั้งแต่ต้น พอตัดหลักฐานออกใบเดียวเลขจะเลื่อนทั้งแถบ

**3. เอเจนต์ไม่อ่านภาพแทนผู้ใช้** ผู้ใช้เปิดดูและตีความเอง เอเจนต์เกลาสำนวนและจับคู่ให้

**4. ยืมเล่มเทมเพลทของคนอื่นได้ แต่จำนวนรายการต้องมาจาก JD ของเจ้าตัว** เลขข้อของเจ้าของเทมเพลทไม่ใช่เกณฑ์ ถ้าไม่เท่ากันต้องทักผู้ใช้ก่อนเสมอ และรายการงานในส่วนที่ ๑ กับส่วนที่ ๒ ต้องนับได้เท่ากัน

**5. backup ทุกครั้งก่อนเขียนไฟล์** snapshot `document.xml` (~๓ MB) ทุกการแก้ + ก๊อบเล่มเต็มเป็น `ร่าง02` `ร่าง03` ตอนปิดรอบ เล่มที่มีภาคผนวกรูปหนักเป็นร้อย MB การ snapshot เฉพาะ XML ถูกกว่ามากและกู้ได้ครบ
