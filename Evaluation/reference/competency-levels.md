# 📐 ถ้อยคำเกณฑ์แต่ละระดับ — ใช้เป็นตัวตั้งเวลาเขียน

> ถอดจากแบบฟอร์มขอรับการประเมินฯ ประเภทวิชาชีพเฉพาะหรือเชี่ยวชาญเฉพาะ
> **ถ้อยคำในคอลัมน์ ๒ เป็นของฟอร์ม ห้ามแก้** ไฟล์นี้ใช้ดูว่าแต่ละระดับ "ขออะไร" เพื่อเขียนคอลัมน์ ๓ ให้ตอบตรง

---

## 🔑 กฎที่อ่านได้จากถ้อยคำ

**1. ทุกระดับสะสม** ทุกข้อขึ้นต้นว่า `มีทักษะระดับที่ N-๑ และ...` หรือ `แสดงสมรรถนะระดับที่ N-๑ และ...`
เขียนระดับสูงโดยไม่มีของระดับล่าง = ตอบไม่ตรงเกณฑ์

**2. คำที่ปรากฏครั้งแรกในระดับใด คือกุญแจของระดับนั้น** เขียนแล้วต้องมีคำนั้นอยู่ในเนื้อความ

**3. หมวดสมรรถนะเชิงพฤติกรรมมี bullet ชี้พฤติกรรมย่อยกำกับทุกระดับ** เขียนคอลัมน์ ๓ ให้ไล่ตอบ bullet เหล่านั้นทีละข้อ อย่าตอบรวม ๆ

**4. ระวังกับดัก ระดับ ๒ กับ ๓ ของ "ความรู้ความสามารถ" ถ้อยคำเกือบเหมือนกันทุกคำ** ต่างแค่ `สูงเฉพาะทาง` กับ `สูงมากเฉพาะทาง` ฟอร์มไม่ได้แยกให้ **คนเขียนต้องแยกเอง** ด้วยขอบเขตงานและความยากของปัญหา ไม่ใช่ด้วยคำคุณศัพท์

**5. เผื่อเพดานไว้เสมอ — ระดับ ๓ ห้ามเขียนแรงเกิน**

ขอชำนาญการเขียนถึงระดับ ๓ แต่วันหนึ่งจะขอชำนาญการพิเศษที่ต้องเขียนถึงระดับ ๕
ถ้าอัดของดีทั้งหมดไว้ที่ระดับ ๓ ตั้งแต่รอบแรก พอทำเล่มพิเศษจะไม่เหลืออะไรให้ไต่ต่อ

```
ผิด    ๒ ใช้คล่อง  →  ๓ เขียนโปรแกรมเอง ออกแบบทั้งระบบ เป็นวิทยากรระดับชาติ
       กระโดดข้ามเพดาน ๔ กับ ๕ ไปแล้วตั้งแต่รอบแรก

ถูก    ๒ ใช้คล่อง ทำงานซ้ำให้อัตโนมัติ
       ๓ ใช้หลายโปรแกรมร่วมกันเป็นระบบงาน ขอบเขตกว้างขึ้น
       ๔ ดัดแปลงปรับปรุงโปรแกรมเดิม        ← เก็บไว้รอบหน้า
       ๕ เขียนโปรแกรมขึ้นใหม่ทั้งระบบ       ← เก็บไว้รอบหน้า
```

**วิธีคุมไม่ให้ล้น** ก่อนเขียนระดับ ๓ ให้อ่านถ้อยคำระดับ ๔ ก่อนเสมอ
อะไรที่เข้าข่ายระดับ ๔ ให้กันไว้ อย่าใส่ในระดับ ๓ แม้จะทำได้จริง

ระยะห่างระหว่างระดับควรสม่ำเสมอ ๑→๒ ห่างเท่าไหร่ ๒→๓ ควรห่างประมาณนั้น
ถ้า ๒→๓ กระโดดไกลกว่า ๑→๒ มาก แปลว่าระดับ ๓ แรงเกิน

## ๑. ความรู้ความสามารถ

### (ก) ความรู้ความสามารถที่ใช้ในการปฏิบัติงาน

| ระดับ | คำกุญแจที่โผล่ครั้งแรก | เขียนให้เห็นอะไร |
| :--- | :--- | :--- |
| ๑ | มีวุฒิการศึกษาระดับปริญญา · นำองค์ความรู้ที่ศึกษามาใช้ | จบอะไร แล้วเอาความรู้นั้นมาใช้กับงานตรงไหน |
| ๒ | ความชำนาญงาน ทักษะ ประสบการณ์**สูงเฉพาะทาง** · ประยุกต์หลักการ · พัฒนางานในหน้าที่ · แก้ไขปัญหาที่ยุ่งยาก | งานเฉพาะทางที่ทำได้ + ตัวอย่างการพัฒนางานหรือแก้ปัญหา |
| ๓ | ประสบการณ์**สูงมาก**เฉพาะทาง (ถ้อยคำอื่นเหมือนระดับ ๒ ทุกคำ) | ขอบเขตกว้างขึ้น ปัญหายากขึ้น จำนวนงานมากขึ้น **แยกด้วยเนื้องาน ไม่ใช่ด้วยคำว่า "มาก"** |
| ๔ | **ความเชี่ยวชาญ** · **ทฤษฎีหลักวิชาการ** · **ถ่ายทอดความรู้** · **ให้คำปรึกษาแนะนำ** | อ้างทฤษฎีได้ + สอนคนอื่นได้ |
| ๕ | เชี่ยวชาญและประสบการณ์**สูงมาก** · ปัญหายุ่งยาก**มาก** ขอบเขตกว้างขวาง**มาก** | ระดับ ๔ แต่ขยายผลกว้างกว่า |

**หมายเหตุสำคัญ** `ถ่ายทอดความรู้` และ `ให้คำปรึกษา` เป็นถ้อยคำของ**ระดับ ๔** ไม่ใช่ระดับ ๓
เขียนเรื่องการสอนไว้ที่ระดับ ๓ ได้ แต่อย่าอ้างว่าเป็นข้อกำหนดของฟอร์ม

### (ข) ความรู้เรื่องกฎหมายและกฎระเบียบของราชการ

| ระดับ | ขออะไร |
| :--- | :--- |
| ๑ | รู้กฎหมาย/ระเบียบที่เกี่ยวกับงานประจำที่ทำอยู่ |
| ๒ | **หาคำตอบทางกฎหมายได้เองเมื่อมีข้อสงสัย** |
| ๓ | **ประยุกต์เพื่อแก้ปัญหา หรือตอบข้อสงสัยให้หน่วยงานหรือบุคคลอื่น** |
| ๔ | รู้กฎหมายอื่นที่เกี่ยวเนื่องด้วย + **แนะนำหรือให้คำปรึกษาในภาพรวม** |
| ๕ | **เชี่ยวชาญ** วิเคราะห์เหตุผลและแก้ปัญหาได้อย่างมีประสิทธิภาพ |

## ๒. ทักษะที่จำเป็นสำหรับการปฏิบัติงานในตำแหน่ง

### (ก) การใช้คอมพิวเตอร์

| ระดับ | ถ้อยคำฟอร์ม | แปลว่าต้องเขียนถึง |
| :--- | :--- | :--- |
| ๑ | ใช้คอมพิวเตอร์ในระดับเบื้องต้นได้ | โปรแกรมพื้นฐานที่ใช้ประจำ |
| ๒ | ใช้โปรแกรมขั้นพื้นฐานได้อย่าง**คล่องแคล่ว** | ใช้คล่อง เริ่มทำอัตโนมัติ ลดขั้นตอน |
| ๓ | ใช้โปรแกรม**ต่างๆ** ในการปฏิบัติงานได้อย่างคล่องแคล่ว | หลากหลายโปรแกรม ใช้ร่วมกันเป็นระบบงาน |
| ๔ | **แก้ไขหรือปรับปรุงโปรแกรม**เพื่อพัฒนาระบบการปฏิบัติงาน | ดัดแปลงของเดิม ปลั๊กอิน สคริปต์ |
| ๕ | **เขียนโปรแกรม**เพื่อพัฒนาระบบการปฏิบัติงาน | เขียนขึ้นใหม่ทั้งระบบ |

### (ข) การใช้ภาษาอังกฤษ

| ระดับ | ขออะไร |
| :--- | :--- |
| ๑ | พูด เขียน อ่าน ฟัง เบื้องต้น สื่อสารให้เข้าใจได้ |
| ๒ | **เข้าใจสาระสำคัญ**ของเนื้อหาต่างๆ |
| ๓ | **ติดต่อสัมพันธ์ในการปฏิบัติงานได้ ถูกหลักไวยากรณ์** |
| ๔ | เข้าใจ**สำนวน** ประยุกต์ได้เหมาะสมทั้งไวยากรณ์และเนื้อหา |
| ๕ | ใกล้เคียงเจ้าของภาษา + **เชี่ยวชาญศัพท์เฉพาะสาขาของตน** |

### (ค) การคำนวณ

| ระดับ | ขออะไร |
| :--- | :--- |
| ๑ | คิดคำนวณพื้นฐานถูกต้องรวดเร็ว |
| ๒ | **ทำความเข้าใจข้อมูลด้านตัวเลข**ได้ถูกต้อง |
| ๓ | **ใช้สูตรคณิตศาสตร์หรือเครื่องมือ**ในการคำนวณ |
| ๔ | **วิเคราะห์ข้อมูลทางสถิติและตัวเลขที่ซับซ้อน** |
| ๕ | **แก้ไขข้อผิดพลาดในข้อมูลตัวเลข** เข้าใจภาพรวม อธิบายชี้แจงได้ |

| :--- | :--- |

| ๒ | **วิเคราะห์และประเมินผล**ข้อมูลได้ถูกต้อง |
| ๓ | **สรุปผล เสนอทางเลือก ระบุข้อดีข้อเสีย** โดยอ้างอิงข้อมูล |
| ๔ | **พยากรณ์ หรือสร้างแบบจำลองเพื่อพยากรณ์** |
| ๕ | **ออกแบบหรือประยุกต์วิธีการจัดทำแบบจำลอง** |

## ๓.๑ สมรรถนะหลัก

หมวดนี้เป็นสมรรถนะเชิงพฤติกรรม ทุกระดับมี bullet พฤติกรรมย่อยกำกับ **เขียนให้ไล่ตอบ bullet**

### (ก) บริการที่ดี

| ระดับ | แก่นของระดับ |
| :--- | :--- |
| ๑ | ให้บริการตามที่ผู้รับบริการต้องการ **ด้วยความเต็มใจ** แจ้งความคืบหน้า ประสานงานให้ต่อเนื่อง |
| ๒ | **ช่วยแก้ปัญหา** รับเป็นธุระ ไม่ปัดภาระ นำข้อขัดข้องไปพัฒนาบริการ |
| ๓ | **ให้บริการเกินความคาดหวัง** ให้เวลาเป็นพิเศษ ให้ข้อมูลที่เป็นประโยชน์แม้ไม่ได้ถูกถาม |
| ๔ | **เข้าใจความต้องการที่แท้จริง** ไม่ใช่แค่สิ่งที่ร้องขอ |
| ๕ | คิดถึงประโยชน์**ระยะยาว** เป็นที่ปรึกษาที่ไว้วางใจ กล้าเสนอทางที่ต่างจากที่ผู้รับบริการขอ |

### (ข) การยึดมั่นในความถูกต้องชอบธรรมและจริยธรรม

| ระดับ | แก่นของระดับ |
| :--- | :--- |
| ๑ | **สุจริต** ไม่เลือกปฏิบัติ ถูกต้องตามกฎหมายและวินัย |
| ๒ | **มีสัจจะ เชื่อถือได้** รักษาคำพูด มีจิตสำนึกความเป็นข้าราชการ |
| ๓ | **ยึดมั่นในหลักการและจรรยาบรรณวิชาชีพ** ไม่เบี่ยงเบนด้วยอคติหรือผลประโยชน์ กล้ารับผิด |
| ๔ | **ยืนหยัดเพื่อความถูกต้อง** แม้อยู่ในสถานการณ์ยากลำบากหรือทำให้ผู้เสียประโยชน์ไม่พอใจ |
| ๕ | **อุทิศตนเพื่อความยุติธรรม** แม้เสี่ยงต่อความมั่นคงในตำแหน่งหน้าที่ |

### (ค) การทำงานเป็นทีม

| ระดับ | แก่นของระดับ |
| :--- | :--- |
| ๑ | **ทำหน้าที่ของตนในทีมให้สำเร็จ** รายงานความคืบหน้า ให้ข้อมูลที่เป็นประโยชน์ |
| ๒ | **ให้ความร่วมมือ** เข้ากับผู้อื่นได้ดี พูดถึงเพื่อนร่วมงานเชิงสร้างสรรค์ |
| ๓ | **ประสานความร่วมมือของสมาชิก** รับฟัง ตัดสินใจและวางแผนร่วมกัน |
| ๔ | **สนับสนุนช่วยเหลือเพื่อนร่วมทีม** ยกย่องให้กำลังใจ ช่วยแม้ไม่มีการร้องขอ |
| ๕ | **นำทีมให้สำเร็จ** เสริมสร้างความสามัคคี คลี่คลายข้อขัดแย้ง |

## ๓.๒ สมรรถนะเฉพาะตามลักษณะงานที่ปฏิบัติ

### (ก) การคิดวิเคราะห์

| ระดับ | แก่นของระดับ |
| :--- | :--- |
| ๑ | **แยกแยะปัญหาเป็นส่วนย่อย** เรียงลำดับความสำคัญ |
| ๒ | **เข้าใจความสัมพันธ์ขั้นพื้นฐาน** ระบุเหตุและผล ข้อดีข้อเสีย |
| ๓ | **เข้าใจความสัมพันธ์ที่ซับซ้อน** เชื่อมโยงเหตุปัจจัยที่ซับซ้อน |
| ๔ | **วิเคราะห์หรือวางแผนงานที่ซับซ้อน** แยกแยะเหตุปัจจัยในรายละเอียด |
| ๕ | **ใช้เทคนิคและรูปแบบต่างๆ** เตรียมทางเลือกป้องกันหรือแก้ปัญหาล่วงหน้า |

### (ข) การมองภาพองค์รวม

| ระดับ | แก่นของระดับ |
| :--- | :--- |
| ๑ | ใช้**กฎพื้นฐาน หลักเกณฑ์ หรือสามัญสำนึก** |
| ๒ | **ประยุกต์ใช้ประสบการณ์** ระบุความเชื่อมโยงและความไม่ครบถ้วนของข้อมูล |
| ๓ | **ประยุกต์ทฤษฎีหรือแนวคิดที่ซับซ้อน** |
| ๔ | **อธิบายเรื่องยุ่งยากซับซ้อนให้เข้าใจง่าย** สังเคราะห์ข้อมูลได้ |
| ๕ | **คิดริเริ่มสร้างสรรค์องค์ความรู้ใหม่** ที่อาจไม่เคยปรากฏมาก่อน |

### (ค) การสืบเสาะหาข้อมูล

| ระดับ | แก่นของระดับ |
| :--- | :--- |
| ๑ | **ใช้ข้อมูลที่มีอยู่** ถามผู้เกี่ยวข้องโดยตรง |
| ๒ | **สืบเสาะด้วยวิธีมากกว่าการตั้งคำถามพื้นฐาน** ถามผู้ใกล้ชิดเหตุการณ์ |
| ๓ | **แสวงหาข้อมูลเชิงลึก** ตั้งคำถามต่อเนื่องจนได้ที่มาของปัญหา |
| ๔ | **สืบค้นอย่างเป็นระบบ** วางแผนเก็บข้อมูลตามช่วงเวลา **ดำเนินการวิจัย** |
| ๕ | **วางระบบการสืบค้น** และมอบหมายผู้อื่นสืบค้นอย่างต่อเนื่อง |

### (ง) ความเข้าใจผู้อื่นและตนเอง

| ระดับ | แก่นของระดับ |
