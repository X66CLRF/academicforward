# 🎮 Agent Core Protocol — Classroom Play Hub

> **เอกสารกลางสำหรับสั่งงาน AI Agent**
> ให้ AI อ่านไฟล์นี้ + `template.html` แล้วผลิต "ฮับสอน/เล่นเกมในห้องเรียน" หัวข้อใหม่ได้ทันที
> โดย **แก้แค่ config ก้อนเดียว** (`const HUB = {...}`) — ไม่ต้องแตะโครงสร้างหรือสไตล์เลย

---

## 1. ผลลัพธ์ที่ได้ (สิ่งที่ template สร้าง)

ไฟล์ HTML ไฟล์เดียวที่เปิดในเบราว์เซอร์ได้ ประกอบด้วย 4 ส่วน ขับเคลื่อนจาก `HUB` config:

| ส่วน | ทำอะไร |
|---|---|
| **🚀 สไลด์สอน** | สไลด์นำเสนอทีละหน้า มีปุ่มถัดไป/ย้อนกลับ, โหมดเต็มจอ (ปุ่มลูกศร/Esc), หน้าสุดท้ายมีปุ่มเข้าสู่เกม |
| **📺 โหมดฉายเกม** | กระดานเกมฉายจอหน้าห้อง เลือกหัวข้อจาก dropdown · แต่ละด่าน "ล็อก/ปลดล็อก" ได้ · คลิกโจทย์เพื่อคัดลอก · โหมดฉายเต็มจอ |
| **🖨️ ใบความรู้ A4** | ใบความรู้พิมพ์ได้ (กดปุ่มเครื่องพิมพ์มุมขวาบน) 1 ใบต่อ 1 หัวข้อ · ขยายดูเต็มจอบนหน้าจอได้ · จัดหน้า A4 อัตโนมัติเมื่อพิมพ์ |
| **🧭 Sidebar + Header** | เมนูซ้ายสร้างอัตโนมัติตามจำนวนหัวข้อ · หัวเรื่องฮับด้านบน |

**กติกาเกมในตัว:** เปิดด่านทีละด่าน → นักเรียนใช้เครื่องมือ AI (เช่น NotebookLM) หาคำตอบจากใบความรู้ → ทีมแรกที่ทำได้รับแต้ม

## 2. โครงสร้าง config (`HUB`) — schema เต็ม

แก้เฉพาะ `<script id="hub-config">` ใน `template.html` ส่วน `<script id="hub-engine">` **ห้ามแตะ**

```js
const HUB = {
  brandEmoji: "✨",                 // อีโมจิหัวเรื่องฮับ
  title: "ชื่อฮับ — ...",            // ชื่อที่โชว์บน header + title แท็บ

  // ── สไลด์สอน : array เรียงตามลำดับ ──
  slides: [
    { title: "หัวสไลด์ (ใส่อีโมจินำได้)",
      content: `HTML ของเนื้อสไลด์` },   // ใช้ utility class ที่มีอยู่ได้เลย
    // ... กี่สไลด์ก็ได้
  ],

  // ── หัวข้อ : แต่ละ topic = 1 ปุ่ม sidebar + 1 ชุดเกม + 1 ใบความรู้ A4 ──
  topics: [
    {
      id: "topicA",               // ตัวอักษร/ตัวเลขล้วน ไม่ซ้ำกัน (ใช้สร้าง element id)
      emoji: "🌊",
      navLabel: "ชื่อหัวข้อสั้น",   // โชว์ใน sidebar + dropdown

      palette: {                  // ชุดสีของหัวข้อ (ดู §3)
        heroGradient: "linear-gradient(135deg,#0c4a6e 0%,#0369a1 60%,#164e63 100%)",
        heroLabel: "#7dd3fc",     // สีคำโปรยบน hero (อ่อน)
        heroSub:   "#bae6fd",     // สีบรรทัดรองบน hero
        accent:    "#0ea5e9",     // สีเส้นขอบหลัก
        accentDark:"#0c4a6e",     // สีหัวข้อ/ตัวหนา (เข้มสุด)
        accentMid: "#0369a1",     // สีระดับกลาง
        badgeBg:   "#f0f9ff",     // พื้นป้ายเลข
        badgeBorder:"#7dd3fc",    // ขอบป้ายเลข
        badgeText: "#0369a1",     // ตัวเลขในป้าย
        wrapBorder:"#e0f2fe",     // ขอบกล่องเนื้อหา
        divider:   "#bae6fd",     // เส้นคั่นระหว่างหัวข้อย่อย
        body:      "#1e3a5f"      // สีตัวอักษรเนื้อหา
      },

      // กระดานเกม
      mission: "🌊 ชื่อภารกิจของหัวข้อนี้",
      challenges: [               // แนะนำ 3 ด่าน: 2 ด่านปกติ + 1 BOSS
        { level: "ด่านที่ 1", color: "#059669", title: "🃏 ชื่อด่าน", tool: "Flashcards",
          prompt: "โจทย์/คำถามให้นักเรียนถาม AI",
          reward: "เงื่อนไขรับรางวัล" },
        { level: "ด่านที่ 2", color: "#d97706", title: "📊 ชื่อด่าน", tool: "Infographic",
          prompt: "...", reward: "..." },
        { level: "BOSS", boss: true, color: "#dc2626", title: "⚡ ชื่อด่าน", tool: "Video + Quiz",
          prompt: "โจทย์ปลายเปิดท้าทาย", reward: "รางวัลใหญ่" }
      ],

      // ใบความรู้ A4
      sheetKicker: "ใบความรู้ประกอบกิจกรรม · ชุดที่ 1",
      sheetTitle:  "🌊 ชื่อใบความรู้",
      sheetSub:    "คำโปรยใต้ชื่อ",
      sections: [                 // แนะนำ 3–4 หัวข้อย่อย
        { n: "01", title: "หัวข้อย่อย",
          html: `<p style="font-size:17px;line-height:1.85">เนื้อหา ใช้ <strong>ตัวหนา</strong> เน้นคำได้</p>` },
        { n: "02", title: "...", html: `<ol style="font-size:17px;line-height:1.85;padding-left:22px;display:flex;flex-direction:column;gap:8px"><li>...</li></ol>` }
      ],
      footer: "* ข้อความท้ายใบความรู้ *"
    }
    // ... กี่หัวข้อก็ได้ (sidebar/dropdown/ใบความรู้ ขยายอัตโนมัติ)
  ]
};
```

### หมายเหตุสำคัญของแต่ละฟิลด์
- **`id`** ต้องไม่ซ้ำและเป็น `a–z / 0–9` เท่านั้น (ใช้สร้าง `tab-<id>`, `challenges-<id>`)
- **`challenges[].color`** คุมสีหัวด่าน + เส้นขอบ + ป้ายรางวัล — มาตรฐาน: เขียว `#059669` (ด่าน 1) · ส้ม `#d97706` (ด่าน 2) · แดง `#dc2626` (BOSS)
- **`boss: true`** ทำให้ป้ายด่านกะพริบ + เติม 🔥
- **`prompt`** ระบบจะใส่เครื่องหมายคำพูด `"..."` ให้เอง — เขียนเนื้อโจทย์อย่างเดียว
- **`sections[].html`** ใส่ HTML ตรง ๆ ได้ ใช้ inline style ตามตัวอย่าง (`font-size:17px;line-height:1.85`) เพื่อให้พิมพ์ A4 สวย

## 3. กติกาดีไซน์ (สิ่งที่ AI ต้องรักษาไว้)

1. **ภาษาไทย** เป็นหลัก · ฟอนต์ `Sarabun` (โหลดไว้แล้ว ห้ามเปลี่ยน)
2. **พื้นหลังแอป** สีครีม `#faf7f0` · โทนหลักของฮับคือ amber/ส้ม `#d97706` / `#b45309` (header, ปุ่มพิมพ์, สไลด์) — **คงไว้**
3. **palette ต่อหัวข้อ** เลือกได้อิสระแต่ต้องเป็น "ชุดเดียวกัน": gradient เข้ม → ตัวอักษร hero สีอ่อนในโทนเดียวกัน → badge/divider สีอ่อนสุด. ใช้สีในตระกูลเดียว (เช่น น้ำเงิน sky, ม่วง indigo, เหลือง amber, เขียว emerald) อย่าผสมมั่ว
4. **ขนาดตัวอักษรใบความรู้** เนื้อหา 17px / หัวข้อย่อย 20px (อย่าเล็กกว่านี้ — ต้องอ่านออกตอนพิมพ์)
5. **อย่าใส่เนื้อหาน้ำขุ่น** — ทุกด่าน/ทุกหัวข้อย่อยต้องมีสาระจริง ไม่ใส่ตัวเลข/ไอคอนเกินจำเป็น
6. **อีโมจิ** ใช้ได้ (เป็นส่วนหนึ่งของสไตล์ฮับนี้) แต่พอประมาณ
7. จำนวนแนะนำ: สไลด์ 6–11 หน้า · หัวข้อ 2–4 หัวข้อ · ด่าน 3 ด่าน/หัวข้อ · หัวข้อย่อยใบความรู้ 3–4 อัน

---

## 4. ขั้นตอนสั่งงาน AI Agent

1. ให้ AI อ่าน **ไฟล์นี้** + **`template.html`**
2. บอกหัวข้อที่ต้องการ เช่น *"ทำฮับเรื่องระบบสุริยะ 3 หัวข้อ: ดวงอาทิตย์ / ดาวเคราะห์ / ดาวหาง"*
3. AI **คัดลอก `template.html` เป็นไฟล์ใหม่** แล้วเขียนทับเฉพาะ `const HUB = {...}` ใน `<script id="hub-config">`
4. ห้ามแก้ `<script id="hub-engine">`, CSS, หรือโครง HTML
5. เปิดไฟล์เช็ก: สไลด์เลื่อนได้ / เปิด-ปิดด่านได้ / กดพิมพ์แล้วใบความรู้จัดหน้า A4 ครบทุกหัวข้อ

## 5. พรอมต์สำเร็จรูป (คัดลอกไปวางได้เลย)

```
ฉันแนบไฟล์ "Agent Core Protocol.md" และ "template.html" มาให้
ช่วยสร้างฮับใหม่เรื่อง: <ใส่หัวข้อหลัก>
หัวข้อย่อย: <หัวข้อ 1>, <หัวข้อ 2>, <หัวข้อ 3>
กลุ่มเป้าหมาย: <เช่น นักเรียน ม.ต้น>

ทำตาม protocol ทุกข้อ:
- คัดลอก template.html เป็นไฟล์ใหม่ แก้เฉพาะ const HUB เท่านั้น
- สไลด์สอน 8 หน้า, แต่ละหัวข้อมี 3 ด่าน (ปกติ 2 + BOSS 1) และใบความรู้ A4 3–4 หัวข้อย่อย
- เนื้อหาภาษาไทย ถูกต้อง มีสาระจริง ไม่ใส่ filler
- เลือก palette คนละโทนสีให้แต่ละหัวข้อ (ชุดสีกลมกลืนกัน)
ส่งกลับเป็นไฟล์ HTML ที่เปิดใช้ได้ทันที
```

## 6. เช็กลิสต์ก่อนส่งมอบ

- [ ] ทุก `topic.id` ไม่ซ้ำ เป็น a–z/0–9
- [ ] สไลด์เลื่อน + เต็มจอ + ปุ่ม "เริ่มเกม" ทำงาน
- [ ] เปิด/ปิดด่าน + คัดลอกโจทย์ + เลือกหัวข้อใน dropdown ทำงาน
- [ ] กดพิมพ์ → ใบความรู้ทุกหัวข้อขึ้นหน้า A4 แยกหน้า สีพิมพ์ติด
- [ ] เนื้อหาถูกต้อง ไม่มี placeholder หลงเหลือ
