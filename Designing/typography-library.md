## 1. บทบาทฟอนต์ (เจ้าของตัดสินแล้ว)

| ชั้น | ฟอนต์ | หมายเหตุ |
| :--- | :--- | :--- |
| **หัวเรื่อง / คำนำหน้า / ป้ายเดือน** | **Pattaya** (ค่าเริ่มต้นทุกงานโพสต์และปกสไลด์) | เลือกทรงจากข้อ 3 |
| ข้อความรอง คำโปรย **ชิป ข้อมูลที่ต้องอ่าน** เครดิต | **ฟอนต์ไทยอ่านง่าย ตัวหนา ≥ 54px ที่หน้า 2160** (Mitr 500–600 หรือฟอนต์ที่เจ้าของเลือกใน Canva) — **ห้ามใช้ Pattaya** (เจ้าของแก้ 5 ต.ค. 69: Pattaya อ่านยากและไม่สวยเมื่อเป็นเนื้อหา) | อ่านง่ายที่ขนาดเล็ก ฟอนต์ตัวประดิษฐ์ใช้ต่ำกว่า ~56px ที่หน้า 2160 ไม่ได้ |
| เนื้อหายาว/ตัวเล็กในสไลด์ | Mitr หรือ Sarabun | Pattaya ใช้เฉพาะหัวข้อ ห้ามทำย่อหน้า |

Pattaya เป็นตัวเอียงในตัว ไม่ต้องใส่ `font-style: italic` เพิ่ม และ `<em>` ในทรง 12 ต้องตั้ง `font-style: normal`

## 2. กฎจัดตัวอักษรไทย (ตรวจจากภาพจริงแล้ว)

1. **line-height ≥ 1.25** และ `padding-top ≈ .12em` — วรรณยุกต์/สระบนของบรรทัดแรกไม่ถูกตัด (ใส่ใน `.pt` แล้ว)
2. **ขอบหนาใช้ `-webkit-text-stroke` คู่ `paint-order: stroke fill`** — ไม่ใส่ `paint-order` ขอบจะกินตัวอักษรครึ่งหนึ่ง
3. **ฟิลล์ไล่สีกับขอบทึบ**: `-webkit-text-stroke` ใช้ร่วม `background-clip:text` ไม่ได้ ขอบจะกลืนสีที่ไล่ → ทรง 09/14 ใช้ขอบด้วย `drop-shadow` 8 ทิศแทน
4. **ห้าม `letter-spacing` กว้าง**กับข้อความไทย (ตามกฎใน `style-library`)
5. **หัวเรื่องบรรทัดเดียวไม่เกิน ~1500px กว้าง** ที่หน้า 2160 · เกินให้ตัดบรรทัดที่ขอบคำ (`text-wrap: balance`) ไม่ลดขนาดจนเล็กกว่า 200px
6. **ขนาด**: หัวเรื่อง 240–280px (หน้าแรกถึง 320) · หัวรอง 100–120px · ป้ายเดือน 100–120px ในแคปซูลขาว · ทุกค่าใน `pattaya.css` เป็น `em` — ปรับ `font-size` ตัวเดียว ทรงทั้งหมดย่อขยายตาม
7. **ทรงแบบกล่อง/แถบ (07, 11, 15) ใส่กับ `<span>` ในหัวเรื่อง** ไม่ใส่ที่ `<div>` เพราะจะกลายเป็น inline ทั้งบล็อก
8. **ตัวอักษรต้องเป็นข้อความจริงเสมอ** (HTML text / SVG `<text>` → Canva text) ห้ามแปลงเป็นรูป — ตาม `canva-handover.md` ข้อ 0
9. **วางบนพื้นแน่น (สันหนังสือ ทรูเชต์ ภาพถ่าย)** ใช้ทรง 11 แคปซูล หรือ 15 ริบบิ้น หรือ 01/02 ขอบขาวหนา — ไม่ใช้ 06 กลวง 13 นูนต่ำ ซึ่งเส้นบางหายไปกับลาย

## 3. ตารางเลือกทรง (16 ทรง — ดูรูปที่ `pattaya-sheet.html`)

| # | class | ลักษณะ | พื้นที่เหมาะ | ใช้กับงาน |
| :-: | :--- | :--- | :--- | :--- |
| 01 | `pt-sticker` | ตัวกรมท่า ขอบขาวหนา | พื้นสีอ่อน/ภาพ/ลายใดก็ได้ | **ค่าเริ่มต้น** หน้าชุดนิยาย/วารสาร |
| 02 | `pt-sticker2` | ขอบขาว + เส้นนอกกรมท่า | พื้นสีกลาง ภาพถ่าย | ปกที่ต้องเด้งออกจากภาพ |
| 03 | `pt-hard` | เงาแข็งทองออฟเซ็ต | ครีม ขาว | โพสต์ข่าวสดใส กิจกรรม |
| 04 | `pt-gold` | ทองไล่สี ขอบกรมท่า | ครีม ขาว พื้นอ่อน | เกียรติบัตร ประกาศรางวัล ปกอบรมทางการ |
| 05 | `pt-long` | ตัวขาว เงายาวทอง | **พื้นกรมท่า/เข้ม** | ปกสไลด์อบรมพื้นเข้ม |
| 06 | `pt-hollow` | เส้นขอบกลวง | พื้นเรียบสะอาด | หัวข้อรอง ตัวเลขใหญ่ประกอบ |
| 07 | `pt-marker` | ไฮไลต์ทองใต้คำ | ครีม ขาว | คำเน้นกลางประโยค |
| 08 | `pt-stack` | ตัวขาว ซ้อนสามมิติกรมท่า | พื้นทอง/พาสเทล | โพสต์ชวนร่วมกิจกรรม |
| 09 | `pt-grad` | กรมท่าไล่สี ขอบขาว | พื้นอ่อน ภาพ | หัวเรื่องหลักทางการแต่ไม่แข็ง |
| 10 | `pt-neon` | เรืองแสงทอง | **พื้นกรมท่า/เข้ม** | ปกชุดดิจิทัล/AI เปิดบริการใหม่ |
| 11 | `pt-pill` | ตัวกรมท่าในแคปซูลขาว | พื้นแน่น ภาพถ่าย | ป้ายเดือน หัวบนลายสันหนังสือ |
| 12 | `pt-two` + `<em>` | สองสี คำเน้นสีชมพู | พื้นอ่อน | "แนะนำ**นวนิยาย**" แยกคำเน้น |
| 13 | `pt-emboss` | นูนต่ำ ตัวสีครีม | ครีมเท่านั้น | ลายน้ำหัวข้อ พื้นหลังปกเรียบ |
| 14 | `pt-stripe` | ลายทางกรมท่า-ชมพู ขอบขาว | พื้นอ่อน | กิจกรรมนักศึกษา สนุก |
| 15 | `pt-ribbon` | แถบกรมท่า ตัวขาว เอียง | ทุกพื้น | ป้ายประกาศ หัวสไลด์ |
| 16 | `pt-soft` | กรมท่า เงานุ่ม | พื้นอ่อนเรียบ | หัวข้อสไลด์วิชาการ อ่านสบาย |

**หนึ่งหน้า = หนึ่งทรง** ห้ามผสมสองทรงในหัวเรื่องเดียวกัน (ยกเว้น 12 ที่มีคำเน้น) · ชุดโพสต์ต่อเนื่องใช้ทรงเดียวทั้งชุดเหมือนใช้ลายตระกูลเดียว

## 4. ใช้ใน Canva (ตัวอักษรเป็นข้อความจริง)

Canva ไม่รับ CSS ตรง ๆ — ตั้งข้อความฟอนต์ **Pattaya** แล้วจำลองทรงด้วยเอฟเฟกต์ข้อความ (ชื่อเอฟเฟกต์/ค่าที่ตั้งอาจต่างตามเวอร์ชัน ตรวจในแอปก่อนทุกครั้ง — ตารางนี้ยังไม่ได้ทดลองในแอปจริง):

| ทรง | วิธีใน Canva |
| :--- | :--- |
| 01 / 02 | เอฟเฟกต์ **Outline** (ขาว หนา) · 02 เพิ่มเส้นนอกสีกรมท่าด้วยข้อความซ้อนอีกชั้น |
| 03 / 05 | เอฟเฟกต์ **Shadow** (ออฟเซ็ตสูง ความเบลอ 0 สีทอง) · 05 ใช้ **Echo** |
| 06 | เอฟเฟกต์ **Hollow** |
| 07 | เอฟเฟกต์ **Background** หรือกล่องสีทองเป็นชั้นแยกใต้ข้อความ |
| 10 | เอฟเฟกต์ **Neon** |
| 11 / 15 | **Background** ของข้อความ (มุมมน สูงสุด) หรือกล่องแยกชั้น |
| 04 / 09 / 14 | ทำไม่ได้ตรงทรง (Canva ไม่ไล่สีในตัวอักษร) → ใช้สีทึบ + Outline และบอกเจ้าของว่าลดทรงแล้ว |

กฎ: เอฟเฟกต์ใดไม่มีใน Canva ให้เลือกทรงอื่นที่ทำได้ **ห้ามแปลงเป็นรูปเพื่อรักษาทรง**
