## 🧩 รูปแบบชุดภาพ (ตามงานจริงในโฟลเดอร์ `นิยาย/<เดือน>`)

ภาพแต่ละใบขนาด 2160×2160 ตั้งชื่อ `1.png` `2.png` ... แต่ละรอบใช้พื้นหลังคนละสีกับรอบก่อน
- `1.png` = ภาพหน้าชุด: แถบโลโก้ ARITC สีขาวตรงกลางด้านบน · หัวเรื่อง "แนะนำนวนิยาย" (ฟอนต์ Pattaya สีกรมท่า ขอบขาว) · ป้ายขาว "ประจำเดือน [ด.ด. ปป]" สีแดง · ภาพประกอบ 1 ภาพตามสไตล์ที่เลือก (ดูตารางสไตล์ด้านล่าง)
- `2.png` เป็นต้นไป = ปกเล่มละ 1 ใบ อยู่กลางภาพ มีเงา แถบโลโก้ด้านบน **ไม่มีข้อความอื่น**

## 🎨 สไตล์ภาพประกอบหน้าชุด

เลือกสไตล์ก่อนผลิตทุกครั้ง ถ้าผู้ใช้ไม่ระบุ: งานแนะนำทรัพยากรที่มีปกจริง → **แบบ A** · งานประกาศ/เชิญชวนที่ไม่มีปก → **แบบ B**

| แบบ | ชื่อ | ลักษณะ | สถานะ |
| :--- | :--- | :--- | :--- |
| **A** | **สติกเกอร์ไดคัท (Die-cut Sticker)** | ภาพเวกเตอร์สีเรียบ ขอบขาวหนารอบรูปทรงทั้งภาพ + เงานุ่มใต้ภาพ เหมือนสติกเกอร์ที่ตัดตามรูป | ✅ แม่แบบเริ่มต้น (`novel-set.py`) |
| **B** | **เรขาคณิต + สี** | ตาม [slide-hub-agent.md](slide-hub-agent.md) ข้อ 3.3 และ design-system: พื้นสว่าง + dot grid จาง · แผงกราฟิก 1 แผง (วงกลมซ้อน + ไอคอน lucide ในวงกลมขาวมีเงา) · การ์ดขาวมุมมน 24px · ป้าย pill · สีเน้นเดียว · ไม่มีภาพวาด | ✅ ค่าเริ่มต้นของงานประกาศ/เชิญชวน (`suggest-geo.py`) |
| C | _(สำรองไว้เพิ่มในอนาคต)_ | | ⏳ |

**กติกาแบบ A (สติกเกอร์ไดคัท):**
- ภาพประกอบต้องสื่อแก่นเรื่องของชุด (เช่น ก.ย.69 รอบ 2 = จันทร์เสี้ยว + กิ่งเหมย จาก "จันทราอัสดง") ห้ามใช้ภาพชั้นหนังสือ/ห้องสมุดกลาง ๆ
- ขอบขาวสร้างด้วยฟิลเตอร์ SVG `#diecut` ในสคริปต์ (`feMorphology dilate` รัศมี 16 + `feDropShadow`) ห่อทั้งภาพด้วย `<g filter="url(#diecut)">` ห้ามวาดขอบขาวเองทีละชิ้น
- รูปทรงที่มีช่องเว้า (เช่น จันทร์เสี้ยว) ใช้ `mask` ตัด ห้ามวาดวงกลมสีพื้นทับ เพราะจะบังลายพื้นหลังและทำให้ขอบไดคัทผิดรูป
- หัวเรื่องใช้ขอบขาวแบบเดียวกัน (`-webkit-text-stroke` + `paint-order:stroke fill`) ให้เข้าชุดกับสติกเกอร์
- ทั้งภาพใช้สีเรียบ ไม่ไล่เฉด ไม่ใส่พื้นผิว

**เพิ่มสไตล์ใหม่:** เพิ่มแถวในตาราง + ทำสคริปต์แม่แบบแยกไฟล์ (`templates/novel-set-<ชื่อ>.py`) แล้วระบุกติกาเฉพาะแบบไว้ใต้ตาราง

## 🌊 ลายพื้นหลัง

- ลายอยู่ใน `PATTERNS` ของสคริปต์ ตอนนี้มี `wave` ลายเดียว
- ถ้า `[GRAPHIC-SPEC]` มี `new-pattern:` ให้ถามผู้ใช้ก่อนว่าจะสร้างลายใหม่หรือใช้ `wave` เมื่อสร้างแล้วต้องเพิ่มแถวในตารางลายของ PR Agent ด้วย ทั้งสองไฟล์ต้องมีชื่อลายตรงกัน
- ทุกลายต้อง **ต่อกันได้**: คาบแนวนอน/แนวตั้งหาร 2160 ลงตัว เมื่อ Facebook เรียง 2×2 ลายจึงต่อเนื่อง
- แผนเลย์เอาต์ (1 / 2 / 3 / 4 ภาพ / แนวนอน) เขียนเป็นคอมเมนต์ไว้ในสคริปต์ ทำเพิ่มทีละแบบเมื่อใช้จริง

## 🛑 กฎ

0. **ห้ามใช้อีโมจิในไฟล์กราฟิก** (อีโมจิใช้ได้เฉพาะในข้อความโพสต์)
1. **ขนาด 2160×2160 px** เสมอ เว้นแต่ผู้ใช้ระบุอื่น
2. **ใช้ปกจริง** ห้ามเจนปกใหม่ ห้ามครอป/ยืดจนชื่อเรื่องบนปกขาด (ล็อกความสูงปก 1560 px ให้ความกว้างตามสัดส่วนเดิม)
3. **ฟอนต์ตามแม่แบบ** (Google Fonts): `novel-set` = Pattaya · `suggest-geo` = Sarabun · `suggest-card` = Kanit
   หัวเรื่องหลายบรรทัดต้องตัดบรรทัดเองด้วย `<br>` ที่รอยต่อคำ + `white-space:nowrap` ห้ามให้เบราว์เซอร์ตัดกลางคำ (เช่น "บอร์ด / เกม")
4. ข้อความบนภาพมีเฉพาะหัวเรื่องและเดือน ชื่อเรื่อง/เลขหมู่/เรื่องย่ออยู่ในคำบรรยายใต้ภาพของโพสต์
5. **รูปทรงนุ่ม ไม่ตัดเหลี่ยม**: แบ่งพื้นที่ด้วยก้อน blob / ขอบโค้ง ห้ามแบ่งพื้นหลังเป็นแผงสี่เหลี่ยมตัดตรง ป้ายหัวเรื่องใช้ทรงแคปซูล (`border-radius:999px`)
6. **โลโก้ไม่มีกล่องรองพื้น**: วางโลโก้ (PNG พื้นใส) บนพื้นสีอ่อนโดยตรง ห้ามใส่กล่องขาวหรือพื้นหลังรองโลโก้
7. ลายพื้นบนพื้นครีมใช้เส้นสีอ่อนกว่าพื้นเล็กน้อย (`CREAM_LINE`) ห้ามใช้เส้นสีเข้มจนแย่งสายตา

## ⚙️ ขั้นผลิต

1. แปลงปก PDF เป็น JPG ที่ 200 dpi
   ```python
   import pymupdf
   pymupdf.open("1.pdf")[0].get_pixmap(dpi=200).save("h1.jpg")
   ```
2. คัดลอก [templates/novel-set.py](templates/novel-set.py) และ `templates/aritc-logo.png` ไว้ข้างไฟล์ปก แก้ `OUT`, สีพื้น `BG`, ข้อความเดือน และภาพวาดใน `MOON` ให้ตรงชุดนั้น (คงบล็อก `diecut` ไว้) แล้วรัน (สคริปต์ถ่ายภาพด้วย Edge ให้เอง)
3. ตรวจ: ขนาดต้องเป็น 2160×2160 · สระ/วรรณยุกต์ไม่ลอย · ปกไม่ขาด · เลขหมู่ตรงระเบียน
4. บันทึกเป็น `1.png` `2.png` ... ในโฟลเดอร์งานเดียวกับปก
5. ภาพที่มี QR: ถอดรหัสตรวจด้วย `cv2.QRCodeDetector().detectAndDecode()` ต้องได้ลิงก์ตรงกับ `URL`
