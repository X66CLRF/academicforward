## 1. ออก PDF

```powershell
$e = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
$u = ([System.Uri]"<path>\deck.html").AbsoluteUri
Start-Process $e -ArgumentList "--headless=new","--disable-gpu","--no-pdf-header-footer","--virtual-time-budget=15000","--user-data-dir=$env:TEMP\edgepdf","--print-to-pdf=`"<out>.pdf`"",$u -Wait
```
* สไลด์ `@page{size:1280px 720px;margin:0}` · ใบงาน `@page{size:A4}`
* HTML โหลด Sarabun จาก Google Fonts ได้ — PDF ฝังฟอนต์ให้เอง จึงใช้ offline ได้ (เช็กด้วย pymupdf ว่าในไฟล์มี `Sarabun-*`)
* เขียนสคริปต์แก้ไฟล์ที่มีภาษาไทย/backslash เป็นไฟล์ `.py` แล้วรัน — ห้าม heredoc ใน bash (ตีความ `\u` ผิด)

## 2. ตรวจก่อนส่ง (ต้องผ่านทุกข้อ)

- [ ] ฟอนต์ใน PDF เป็น **Sarabun** ทั้งหมด ไม่มี Prompt / Tahoma (ไทยในกล่อง `.kw` ตกไป Tahoma ถ้า mono ไม่มี fallback → `font-family:'Consolas','Menlo','Sarabun',monospace`)
- [ ] ไม่มี emoji (ใช้ไอคอน lucide SVG)
- [ ] ไม่มีข้อความล้นกรอบ / ทับกัน · **ไทยตัดบรรทัดเฉพาะรอยต่อวลี (ช่องว่าง)** ห้ามตัดกลางคำ เช่น `e-|book` `ของ|มหาวิทยาลัย` (สคริปต์ `NOBR` ใน `splice.py` ครอบวลีด้วย nowrap + คอลัมน์ `min-width:0`) · ข้อความบนสไลด์ผ่าน **thai-lint** — `build_pdf.py` รันให้อัตโนมัติ (คลังคำ `Writing/lexicon/thai-lexicon.tsv`) warn ต้องเป็น 0 ก่อนส่ง · ใบงาน/ไฟล์แจกรัน `lint_thai.py` เอง · ผู้ใช้ติคำไหน เพิ่มเข้า tsv · Arial ในรายการฟอนต์ = มีอักขระที่ Sarabun ไม่มี (เช่น →) ให้เปลี่ยน · หัวเรื่องไทยไม่ชนป้ายเล็ก (3.2)
- [ ] ไม่มีพื้นเข้มเต็มหน้า · ไม่มีแถบสีขอบซ้าย · ไม่ระบายสีเต็มกล่อง
- [ ] ช่องให้เลือกมีข้อความกำกับ ("จริง"/"ปลอม")
- [ ] ปกมีวิทยากร + รูปเต็มตัวกรอบมุมมน + ใบรับรอง · โลโก้ ARITC
- [ ] มีหน้าปิดท้าย "จำ 3 ข้อนี้ไว้" + อีเมลองค์กร · ไม่มีเบอร์/ช่องทางส่วนตัว
- [ ] เนื้อหาจาก source ครบทุกข้อ · โน้ตผู้พูดที่บอกว่า "ไม่ใส่เฉลย" ต้องไม่มีเฉลยบนสไลด์
- [ ] **ถ้อยคำเป็นของผู้ใช้** (ข้อ 3.6) — ไม่มีสโลแกนที่แต่งเอง · ตรวจข้อความที่เพิ่มเองด้วย `Writing/5-prose-cleaner.md` โหมด 1
- [ ] ชื่อไฟล์แจกและ `<title>` ไม่มีเลขเวอร์ชัน · ฉบับเก่าอยู่ใน `_archive\`
