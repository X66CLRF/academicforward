## 1. บทบาทและผลลัพธ์ (Deliverables)

Agent ประจำชุดนี้ทำหน้าที่สร้างและปรับแต่งหน้าเว็บสื่อการสอน HTML ไฟล์เดียว (`deck.html` หรือ `playhub.html`) ที่เปิดในเบราว์เซอร์และใช้งานได้ทันที ประกอบด้วย 4 ระบบหลัก:

| ระบบ | หน้าที่และการทำงาน |
| :--- | :--- |
| **🚀 สไลด์การสอน (Presentation)** | สไลด์ 16:9 ควบคุมด้วยแป้นลูกศร/Esc รองรับ Fullscreen และเชื่อมต่อไปยังโหมดเกม |
| **📺 กระดานเล่นเกม (Game Board)** | กระดานฉายโจทย์หน้าห้อง ปลดล็อกทีละด่าน (Level 1, 2 และ BOSS) รองรับการคลิกคัดลอกคำถาม |
| **🖨️ ใบความรู้ A4 (Printable Worksheets)** | ใบงานความรู้รายหัวข้อ จัดหน้า A4 อัตโนมัติเมื่อกดสั่งพิมพ์ (Ctrl+P / ปุ่ม Print) |
| **🧭 การนำทาง (Interactive Sidebar)** | เมนูเชื่อมโยงหัวข้อและสลับด่านกิจกรรมอัตโนมัติ |

## 3. Design Tokens & Styling Guide

### 3.1 Color System
* **Primary Accent:** `#d97706` (Amber — จุดเด่น, CTA, ไฮไลต์สำคัญ)
* **Stone Neutrals (โทนอุ่น):**
  * Dark Section Background: `#2e2b28`
  * Card Titles & Headers: `#3d3a37`
  * Body Text: `#6b6762`
  * Background: `#faf7f0` (Main), `#fffdfa` (Slide)
* **Semantic Status Colors:**
  * เขียว: `#059669` (สำเร็จ / Level 1)
  * ส้ม: `#d97706` (กำลังทำ / Level 2)
  * แดง: `#dc2626` (คำเตือน / BOSS Level)

### 3.2 Typography
* **Font-family:** `'Sarabun'` เท่านั้น (ตาม design-system `paint/aritc.css`) fallback `'Leelawadee UI'`, `'Tahoma'` — ห้ามใช้ Prompt
* **Header ขนาดใหญ่ (H1/Hero):** 48–72px ตัวหนา (Weight 700-800)
* **หัวข้อสไลด์ (H2):** 36–52px
* **เนื้อหา (Body):** 18–26px line-height 1.6–1.8

### 3.3 สไตล์ภาพรวม: มินิมอล สะอาดตา (บังคับ — ทับ 3.1 ถ้าขัดกัน)
อ้างอิงระบบ `C:\Users\Burt\Documents\GitHub\design-system` (core/graphite.css, shape.css, paint/aritc.css)

**พื้นและลาย**
* พื้นสไลด์สว่าง `#f8f8f6` + ลายจุดเรขาคณิตจาง (dot grid 24px สี `#d4d4d8`)
* ของตกแต่ง = วงกลมเส้นบาง 1px / วงกลมขาวมีเงานุ่ม ที่มุมสไลด์ ไม่บังเนื้อหา
* **ห้ามพื้นเข้มเต็มหน้า** รวมถึงปกและหน้าคั่นส่วน — ใช้พื้นสว่าง + ตัวเลขส่วนในวงกลมขาว

**รูปทรง**
* การ์ด radius 24px · ชิป/แถว 14px · ป้าย/ปุ่ม เป็น pill · ขอบ 1px `#e4e4e7` · เงานุ่ม `0 20px 45px -15px rgba(0,0,0,.07)`
* **ห้ามแถบสีหนาที่ขอบซ้ายกล่อง** (border-left accent) — ดูโบราณ รก
* ห้ามระบายพื้นเขียว/แดงทั้งกล่อง กล่องเป็นพื้นขาว สถานะบอกด้วย **จุดสี / ไอคอน / ป้าย pill** เท่านั้น

**สี**
* ตัวอักษร/ปุ่มหลัก = เทาเกือบดำ `#18181b` ไม่ใช้สีแบรนด์จัด
* สีสถานะชุดอ่อน: success `#ecfdf5/#a7f3d0/#065f46` · error `#fff1f2/#fecdd3/#9f1239` · warning `#fffbeb/#fde68a/#92400e`
* สีสด (แดง/เขียว) กินพื้นที่ไม่เกิน ~10% ของสไลด์ · แถบเตือนแดงใช้เฉพาะเรื่องอันตรายจริง
* ไฮไลต์คำ = ขีดเน้นเหลืองอ่อนครึ่งล่าง ไม่ใช่ตัวสีส้ม

**ไอคอน**
* **ห้าม emoji** ในสไลด์ (หน้าตาเปลี่ยนตาม OS/ตอนพิมพ์ PDF) — ใช้ SVG เส้นแบบ lucide (check-circle, x-circle, alert) ขนาดเท่าตัวอักษร

## 4. Offline & สถานที่อบรม (บังคับ)

> สถานที่อบรมหลายแห่ง (เรือนจำ โรงเรียนชนบท ห้องประชุมราชการ) **ไม่มีอินเทอร์เน็ต** ถ้าไฟล์พึ่งเน็ต ฟอนต์ไทยจะไม่โหลด ตัวอักษรเพี้ยน **อ่านยาก** และบางส่วนใช้งานไม่ได้

### 4.1 ถามก่อนเริ่มทุกครั้ง
ก่อนสร้างสไลด์ ให้ถามผู้ใช้ว่า **"สถานที่อบรมมีอินเทอร์เน็ตไหม?"**
* ไม่มี / ไม่แน่ใจ → ใช้ **โหมด Offline** (ข้อ 4.2) ทันที
* มีแน่นอน → ยังแนะนำโหมด Offline เป็นค่าเริ่มต้น เพราะเน็ตหน้างานไม่แน่นอน

### 4.2 กฎโหมด Offline
1. **ฝังฟอนต์ในไฟล์** — Sarabun เป็น `@font-face` แบบ base64 (`.woff2` เฉพาะ subset thai + latin) **ห้ามใช้ `fonts.googleapis.com`**
2. **ไฟล์เดียวจบ** — CSS, JS, รูปภาพ ฝังในไฟล์ทั้งหมด (รูปเป็น base64 หรือวาดเป็น SVG) ห้ามอ้าง CDN / URL ภายนอก
3. **ห้ามสิ่งที่ต้องใช้เน็ต** — YouTube, `<iframe>`, Google Form, แผนที่ออนไลน์, QR ที่ต้องสแกนเปิดเว็บระหว่างอบรม
4. **Fallback ฟอนต์อ่านง่าย** — `font-family: 'Sarabun','Leelawadee UI','Tahoma',sans-serif` (Leelawadee UI / Tahoma มีในทุกเครื่อง Windows)
5. **เปิดด้วยดับเบิลคลิก** — ทำงานจาก `file://` บนแฟลชไดรฟ์ได้ ไม่ต้องรันเซิร์ฟเวอร์
6. **ไฟล์สำรอง PDF** — ส่งออก PDF 16:9 คู่กันทุกครั้ง เผื่อเครื่องหน้างานเปิด HTML ไม่ได้

### 4.3 Checklist ก่อนออกเดินทาง
- [ ] ใช้ **โน้ตบุ๊กตัวเอง** หรือ **เครื่องของสถานที่**? (บางแห่ง เช่น เรือนจำ ไม่อนุญาตนำอุปกรณ์เข้า)
- [ ] เครื่องหน้างานมี **Chrome / Edge**? (Internet Explorer เปิดไม่ได้)
- [ ] ใช้ **แฟลชไดรฟ์** ได้ไหม / ต้องส่งไฟล์ล่วงหน้าให้เจ้าหน้าที่ตรวจ?
- [ ] โปรเจกเตอร์ต่อ **HDMI หรือ VGA** → เตรียมหัวแปลง
- [ ] ใบความรู้ A4 **พิมพ์จากข้างนอก** ไปก่อน (หน้างานอาจไม่มีเครื่องพิมพ์)
- [ ] **ทดสอบจริง**: ปิด Wi-Fi แล้วเปิดไฟล์ ตัวอักษรไทยต้องเป็น Sarabun ไม่เพี้ยน

### 4.4 การอ่านง่ายบนโปรเจกเตอร์
* เนื้อหาไม่ต่ำกว่า **24px** บนสเตจ 1280×720 (ห้องใหญ่ / ผู้เรียนสูงวัย ใช้ 28px+)
* ตัวอักษรเข้มบนพื้นสว่าง ความต่างสีอย่างน้อย 4.5:1 — โปรเจกเตอร์เก่าทำสีซีด
* สไลด์ละ 1 ประเด็น ไม่เกิน 4–5 บรรทัด
