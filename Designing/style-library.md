## 1. ขั้นเลือกสไตล์ (ทำก่อนวาดทุกงาน)

1. ดูข้อมูลที่ได้รับ: มี **ภาพจริง** ไหม (ปก ภาพหน้าจอ ภาพกิจกรรม) · มี **ตัวเลข/ขั้นตอน** ไหม · กี่รายการ
2. เลือกสไตล์จากตาราง 2 — ไม่ตรงข้อไหนเลยให้ใช้ **A**
3. จดชื่อสไตล์ลง `handover.md` ของรอบ (`สไตล์: A ครีมบรรณาธิการ`) รอบหน้าหมวดเดียวกันใช้สไตล์เดิมเป็นค่าเริ่มต้น
4. งานใหม่ที่ไม่มีในตาราง: เปิดคลังแม่แบบ (ข้อ 5) หาเลย์เอาต์ที่ข้อมูลรูปร่างเดียวกัน แล้วเพิ่มแถวในตารางนี้

## 2. ตารางเลือก: ข้อมูลที่ได้รับ → สไตล์

| ข้อมูลที่ได้รับ | สไตล์ | เหตุผล |
| :--- | :--- | :--- |
| วารสาร / นวนิยาย / หนังสือใหม่ / บริจาค — มีปกจริงหลายเล่ม | **A ครีมบรรณาธิการ** | ปกสวยอยู่แล้ว ให้ปกเป็นพระเอก พื้นเรียบ |
| ฐานข้อมูล / e-Book / วิธีใช้บริการ — มีภาพหน้าจอ เป็นขั้นตอน | **C ไล่สีเข้ม + การ์ดกระจก** | ภาพหน้าจออยู่ในการ์ด ขั้นตอนเป็นชิปติ๊กถูก |
| ประกาศเปิด-ปิด / ข่าวบริการ / ตัวเลขเด่น (จำนวน วันที่ เวลา) | **B ตัวหนาเข้ม + กล่องเบนโต้** | ตัวเลขใหญ่อ่านได้จากฟีด |
| สื่ออบรม / หลักสูตร / สรุปเนื้อหาเป็นข้อ | **D ครีมอุ่น + รายการเลขข้อ** | เลขข้อในแถบสี อ่านตามลำดับง่าย |
| อธิบายแนวคิด / เปรียบเทียบ 2–3 อย่าง | **E เทาอ่อน + การ์ดขาว** | การ์ดเท่ากันเทียบกันได้ทันที |
| เชิญเสนอชื่อหนังสือ | แม่แบบเดิม `suggest-geo.py` | เจ้าของใช้อยู่แล้ว |
| ปกโพสต์ภาพกิจกรรม | `photo_post cover` (desk-utils) | ไม่ใช่งานไฟล์นี้ |

## 3. กรอบหน้าที่ทุกสไตล์ใช้ร่วม (สิ่งที่ทำให้ "ไม่โล่ง")

```text
┌───────────────────────────────────────────┐
│ ARITC ●●●                  แนะนำวารสาร ต.ค. 69 │ ← หัวหน้า: ซ้ายแบรนด์ + จุดสี 3 จุด · ขวาชื่อชุด สีเทา
│                                           │
│ [คำนำหน้า / ชิปหมวด]                        │ ← ตัวเล็ก น้ำหนัก 600
│ หัวเรื่องหนาใหญ่                              │ ← 1–2 บรรทัด
│ คำโปรยสีเทา                                 │
│ ┌───────────────────────────────────────┐ │
│ │      ภาพจริงในภาชนะมุมมน (การ์ด/วงกลม)      │ │ ← พระเอกของหน้า
│ └───────────────────────────────────────┘ │
│ (ชิป) (ชิป) (ชิป)              เครดิตภาพ ตัวเล็ก │
│ ───────────────────────────────────────── │ ← เส้นบาง
│ โลโก้ · ศูนย์วิทยบริการ · ต.ค. 2569     02 / 05 │ ← ท้ายหน้า: เลขหน้าทุกหน้า (เลื่อนดูต่อ → ถ้ามีหน้าถัดไป)
└───────────────────────────────────────────┘
```

- **ขอบ** 144 (หน้า 2160) เท่ากันทุกหน้า หัว-ท้ายอยู่ตำแหน่งเดิมทุกหน้า = ผู้ดูรู้ว่าเป็นชุดเดียว
- **หน้าแรก** จัดกึ่งกลางได้ · **หน้าเนื้อหา** ชิดซ้าย
- **ของตกแต่ง** สูงสุด 1 ชนิดต่อสไตล์ (ตารางข้อ 4) จางพอที่ภาพย่อในฟีดแทบมองไม่เห็น
- **ชิป** ทรงแคปซูล พื้นขาว (หรือขาวโปร่งบนพื้นเข้ม) · ชิปที่ต้องการเน้น 1 อันใช้สีพื้นต่าง
- **เครดิตภาพ** ทุกครั้งที่ใช้ภาพที่ไม่ได้ถ่ายเอง

### ตัวอักษร

- **ฟอนต์เดียวทั้งชุด: Mitr** — เจ้าของเลือกจากแผ่นเทียบ 8 ฟอนต์เมื่อ 1 ต.ค. 69 (`design-system/docs/social-cover.md`) มีใน Canva ผู้ใช้แก้ข้อความต่อได้ด้วยฟอนต์เดียวกัน
- ลำดับชั้นด้วย **ขนาด + น้ำหนัก + สีเทา** ไม่ใช่เปลี่ยนฟอนต์:

| ชั้น | ขนาด (หน้า 2160) | น้ำหนัก | สี |
| :--- | :--- | :--- | :--- |
| หัวหน้า/ท้ายหน้า | 44–52 | 500 | เทา |
| คำนำหน้า/ชิปหมวด | 52–60 | 600 | สีเน้น |
| หัวเรื่อง | 150–200 (หน้าแรกถึง 260) | 600–700 | เข้มเกือบดำ / ขาวบนพื้นเข้ม |
| คำโปรย | 64–76 | 400 | เทา |
| ชิป | 56–64 | 500 | เข้ม |
| เครดิต | 36–40 | 300 | เทา |

- ห้าม `letter-spacing` กว้างกับข้อความไทย (ใช้ได้กับคำอังกฤษตัวพิมพ์ใหญ่ในหัวหน้าเท่านั้น)
- Pattaya (ตัวประดิษฐ์ขอบขาว) = แม่แบบเก่า `novel-set` / `journal-set` ยังใช้ได้เมื่อเจ้าของขอ ไม่ใช่ค่าเริ่มต้น

### สี

- **1 สีพื้น + 1 สีเน้น + เทา 2 ระดับ + ขาว** ต่อหน้า — สีที่ 3 ขึ้นไปใช้เป็นจุดเล็กเท่านั้น
- สีเน้นมาจาก **เนื้อหา** (`[GRAPHIC-SPEC]` ของ PR Agent ดึงจากปก) หรือทองของหน่วยงาน (`social-cover.json` `kicker_bg`)
- สีพื้นเปลี่ยนตามหน้าได้ (พาสเทลจากปกแต่ละเล่ม) กรอบหน้าคงเดิม

## 4. สไตล์

### A ครีมบรรณาธิการ — ค่าเริ่มต้นงานแนะนำทรัพยากร
- พื้นครีม/พาสเทลอ่อน (`#FAF6EC` หรือพาสเทลจากปก) · ข้อความเข้ม `#1F2430` · รองเทา `#6B6F78`
- หน้าแรก: หัวเรื่องกลาง → ปกทุกเล่มเรียงแถวในการ์ดมุมมน (เงาอ่อน 1 ชั้น) → ชื่อใต้ปก
- หน้าเล่ม: ชิปหมวด → ชื่อวารสาร → ฉบับ/ปี (เทา) → ปกใหญ่ในการ์ด → ชิป `เลขหมู่` `โซน` 
- ตกแต่ง: วงกลมเบลอสีพาสเทล 1–2 วง ความทึบ ≤ 15%

### B ตัวหนาเข้ม + กล่องเบนโต้
- พื้นกรมท่าเข้ม `#001f5c` (สีเว็บห้องสมุด) · สีเน้นทอง `#efc84c` · ข้อความขาว
- ตัวเลขเด่นใหญ่ 400–600 · รายละเอียดในกล่องมุมมน 2–3 กล่อง (กล่องเน้น 1 กล่องพื้นทอง)
- ท้ายหน้ามีแถบความคืบหน้าบาง + `เลื่อนดูต่อ →`
- ตกแต่ง: ตารางพิกเซลเล็ก 1 กลุ่ม

### C ไล่สีเข้ม + การ์ดกระจก
- พื้นไล่จากสีเข้มของเนื้อหาลงสว่างด้านล่าง + เส้นตารางจางมาก
- ภาพหน้าจอ/โลโก้บริการอยู่ในการ์ดโปร่งขอบบาง พื้นหลังการ์ดเบลอภาพตัวอย่าง
- ชิปติ๊กถูกเรียงแถวใต้การ์ด (`✓ ใช้บัญชีมหาวิทยาลัย` `✓ ฟรี`)
- ตกแต่ง: ประกายดาว 1–2 จุดที่การ์ด

### D ครีมอุ่น + รายการเลขข้อ
- พื้นครีมอุ่น · สีเน้น 2 สี (หลัก + รอง) + ม่วงเข้มเป็นตัวหนังสือ
- รายการ 3–5 ข้อในแถบมุมมนสีต่อข้อ หรือเส้นเวลาจุดกลมเลขข้อ
- ตกแต่ง: จุด halftone มุมเดียว

### E เทาอ่อน + การ์ดขาว
- พื้นเทาอ่อนไล่ขาวตรงกลาง · การ์ดขาวเงานุ่มเท่ากัน 2–3 ใบ · การ์ดเน้น 1 ใบขอบสี
- ป้ายเลขตอนแคปซูลเหนือหัวเรื่อง (`03 คิดเงินยังไง`)
- ตกแต่ง: เส้นรัศมีบางหลากสีจากด้านบน ความทึบ ≤ 20%
