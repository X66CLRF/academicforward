## 1. ลำดับคิดก่อนวาด (7 ข้อ ทำตามลำดับ ห้ามข้าม)

| # | ถามตัวเอง | ตัวอย่างบอร์ดเกม |
| :-: | :--- | :--- |
| 1 | **ผู้ใช้มีเทมเพลตเดิมของหมวดนี้ไหม?** ถ้ามี ใช้โครงเดิมก่อน — เปิด Canva ดูหน้าเก่า + อ่าน `novel-set.py`/`journal-set.py` ดึงสีและตำแหน่งจริง ไม่ออกแบบใหม่ | ปก = เทมเพลตชุดนิยาย: พื้นฟ้า แถบโลโก้ขาวติดขอบบน ชื่อ Pattaya ขอบขาว ป้ายเดือนแคปซูลแดง สติกเกอร์ล่าง |
| 2 | **ข้อมูลที่ได้รับมีอะไร?** (ภาพจริง/ตัวเลข/ขั้นตอน) → เลือกสไตล์ตาม `style-library` ข้อ 2 | มีกล่องจริง 5 กล่อง + แนวเกม/จำนวนคน/รหัส = ภาพจริงเป็นพระเอก ข้อมูลเป็นชิป |
| 3 | **เนื้อหาแต่ละชิ้นมี "แก่น" อะไร?** ดึง 1 วัตถุที่คนจำได้จากตัวเนื้อหา (ชื่อ/ภาพบนกล่อง/กติกา) ไม่ใช่ฉากทั่วไป | TAKE TIME → นาฬิกาพก+ใบบัว+แมลงปอ (อยู่บนกล่อง) · TIMELINE → ม้วนไทม์ไลน์+หน้ากากฟาโรห์ · NO THANKS → กล่องของขวัญโบแดง+การ์ด · FOR SALE → บ้าน+กุญแจ+เหรียญ · SIDE EFFECT → กะโหลก+แคปซูลยา |
| 4 | **สีเน้นของแต่ละชิ้นมาจากไหน?** จากสีแบรนด์/สีเด่นบนภาพจริง (ภาพถ่ายหม่นเกิน ให้เลือกสีแบรนด์เอง ไม่ใช้ค่าเฉลี่ยพิกเซล) แล้วย้อมชิป/เลขหน้า/ข้อความชิปด้วยสีนั้น (พื้นชิป = สีเน้น 16% บนขาว · ตัวอักษร = สีเน้นเข้มลง ~22%) | เขียวน้ำทะเล · ส้ม · แดง · เขียวบ้าน · ทอง |
| 5 | **ชั้นลายพื้นเลือกจากคลังตามกฎ 2.1 ของ pattern-library** เทียบ 4–6 ลายบนปกจริง ห้ามใช้ลายเดิมซ้ำ 3 งานล่าสุด | บอร์ดเกม → เมมฟิส (เล่นสนุก ไม่แย่งชื่อ) ย้อมโทนฟ้าของเทมเพลต |
| 6 | **ภาพที่ AI วาด (สติกเกอร์) ผูกกับแก่นข้อ 3 และสไตล์เดียวกับที่ผู้ใช้ผ่านแล้ว** ส่ง `imageReferences` = สติกเกอร์ที่ผ่านแล้ว/ภาพของงานเดิม พรอมท์ต่อท้ายตามโครงใน `canva-handover` ข้อ 3 | ใช้สติกเกอร์ปกที่ผู้ใช้โอเคเป็นต้นแบบให้อีก 5 ตัว |
| 7 | **ข้อความทุกก้อนมีที่ไป:** ชื่อเรื่อง/ป้ายพิเศษ = PNG ฟอนต์จริง (Pattaya) · ข้อมูลที่แก้บ่อย (แนวเกม จำนวนคน รหัส) = ข้อความจริงใน Canva | ดู typography-library ข้อ 2 ข้อ 8 |

**กฎเชื่อมโยงภาพ (หัวใจ):** ทุกองค์ประกอบบนหน้าต้องตอบได้ว่า "มาจากเนื้อหาตรงไหน" — สติกเกอร์มาจากวัตถุบนกล่อง · สีเน้นมาจากแบรนด์กล่อง · ลายมาจากอารมณ์ของหมวด (เกม = เมมฟิสสนุก · วารสาร = เซกายฮะ/อาร์ไกล์ · นิยาย = คลื่น/กิ่งใบ · ข้อมูล = กริด/พิกเซล) · ตัวเลขหน้า/ชิปใช้สีเดียวกับสติกเกอร์ของหน้านั้น — ถ้าตอบไม่ได้ให้ตัดทิ้ง

## 2. โครงหน้ามาตรฐานของชุด (ตามเทมเพลตปก)

> ⚠️ **ค่าตัวเลขและกฎที่เจ้าของแก้แล้ว (v2) อยู่ที่ [templates/boardgame-v2-owner-fixed.md](templates/boardgame-v2-owner-fixed.md) — ใช้ไฟล์นั้นก่อน** · สรุป: พื้นขาว + ลาย opacity 0.3 ชั้นเดียว · ไม่ซ้ำชื่อที่รูปมีอยู่แล้ว · ข้อความอ่านใช้ฟอนต์ไทยอ่านง่ายตัวหนา ไม่ใช้ Pattaya

**ปก:** พื้นสี → ลาย → แถบโลโก้ → สติกเกอร์ใหญ่ → ชื่อเรื่อง (PNG Pattaya ขอบขาว) → ป้ายเดือนแคปซูล
**หน้าเนื้อหา (1 รายการ = 1 หน้า):** พื้นสี → ลาย → แถบโลโก้ → ชื่อเรื่อง PNG → กรอบรูปขาว+เงา (PNG เดียว) → รูปจริง → สติกเกอร์ประจำรายการซ้อนมุมกรอบล่างซ้าย → ชิป 3 อัน (พื้นสีอ่อน+ข้อความจริง) → เลขหน้าวงกลมมุมล่างขวา (PNG ตัวเอียงสีเน้น)

ขนาดอ้างอิง (หน้า 2160): แถบโลโก้ 324×336 ที่ x 918 ติดขอบบน · ชื่อเรื่องเริ่ม y≈400 กว้างไม่เกิน ~1700 (ลดขนาดอักษรอัตโนมัติ) · รูปจริงพอดีกล่อง 900×840 กลางหน้า y≈1100 · สติกเกอร์ 380 ซ้อนที่ x = ซ้ายรูป−190 · ชิป y 1660 สูง 110 (กว้าง 900/440/440 ห่าง 24) · เลขหน้า 296 (รวมเงา) ที่ (1717,1791)

## 3. ขั้นตอนทำงานกับ Canva MCP (บทเรียนที่ต้องรู้ — ทำตามได้เลย)

1. `read-design` ดูหน้าเดิมก่อน (ผู้ใช้อาจแก้) — หน้าที่เป็น `rect` เต็มหน้ารูปเดียว = ภาพแบนที่แก้ไม่ได้ (ถ้าเจอในงานเก่าให้บอกผู้ใช้ ไม่ต้องแก้เอง)
2. เปิด transaction (`read-design` + `open_transaction`) **ทำงานเป็นร่างจนผู้ใช้อนุมัติ แล้วค่อย `commit`** — ห้าม commit เอง
3. อัปโหลด: `create-upload-url` → `curl -X POST -H "Content-Type: application/octet-stream" --data-binary @<ไฟล์>` **ไฟล์ต้องอยู่ในพาธ ASCII** (curl อ่านพาธภาษาไทยจาก Git Bash ไม่ได้ → คัดลอกไป scratchpad ชื่ออังกฤษก่อน) · URL ใช้ครั้งเดียว อายุสั้น · อัปหลายไฟล์ = เรียก `create-upload-url` ขนานกันได้
4. SVG/PNG อัปได้ · ลายพื้นอัป SVG ตรง ๆ (พื้นใส) แล้ว `insert_fill` เต็มหน้า
5. **ลำดับชั้น = ลำดับ `insert_fill`/`insert_shape` (ใส่ก่อนอยู่ล่าง)** · `layer_element back` ทำทีละชิ้น: ต้องสั่ง "ลายไปล่างสุด" แล้ว "พื้นสีไปล่างสุด" ตามลำดับ ไม่งั้นลายขึ้นไปทับชื่อ (พลาดมาแล้ว)
6. `add_text` ได้ข้อความขนาด 16 สีดำเสมอ → ต้อง `format_text` ต่อ (ขนาด น้ำหนัก สี จัดกลาง) โดยใช้ `locator_id` จากผลตอบกลับ (`<pageId>-<elementId>`) · `format_text` **ตั้งฟอนต์ไม่ได้** (ฟอนต์เริ่มต้นของ Canva) — ข้อความที่ต้อง Pattaya ใช้ PNG หรือให้ผู้ใช้เลือกฟอนต์เอง
7. **เปลี่ยนหน้า = ลบของเดิมทีละชิ้น (`delete_element`) แล้วสร้างใหม่** (ไม่มี duplicate/clear page) · พื้นสีหน้า (`background`) เปลี่ยนไม่ได้ → ใส่สี่เหลี่ยมเต็มหน้าเป็นชั้นล่างสุดแทน
8. `add_page` ตั้งชื่อหน้าได้ตอนสร้างเท่านั้น (เปลี่ยนทีหลังไม่ได้) → พิมพ์ชื่อให้ถูกตั้งแต่ต้น
9. **ตรวจตัวสะกดไทยจากผลตอบกลับทุกครั้ง** — เคยทำไม้เอกหล่น ("ไม่ละ!" แทน "ไม่ล่ะ!") ตอนแปลง escape · แนะนำเขียนข้อความไทยตรง ๆ ใน JSON ไม่แปลงเอง
10. สติกเกอร์ AI: `generate-image` (ส่ง `imageReferences` ของสติกเกอร์ที่ผู้ใช้ผ่านแล้ว) → ดูภาพ ถ้ามีตัวอักษร/ชิ้นขาดให้เจนใหม่ → `remove-background` → `insert_fill` · หลายชิ้นเจนขนานกันได้ (5 งานพร้อมกัน)
11. ผลตอบกลับของ `edit-design` ยาวมาก (ทั้งหน้า) — แบ่งงาน: ใส่ชั้นทั้งหมดในครั้งเดียว แล้ว `format_text` ครั้งเดียวต่อหน้า (2 การเรียก/หน้า)

## 4. สคริปต์ที่ทำไว้แล้ว (ใช้ซ้ำ ปรับตัวแปรบนหัวไฟล์)

| ไฟล์ | ทำอะไร |
| :--- | :--- |
| `templates/boardgame-cover-layers.py` | เรนเดอร์ชั้นปกเทมเพลตนิยาย (คลื่น/แถบโลโก้/ชื่อ Pattaya/ป้ายเดือน) เป็น PNG พื้นใส + `layers.json` — เปลี่ยน `BG, LINE, NAVY, RED` และข้อความ |
| `templates/boardgame-page-layers.py` | เรนเดอร์ชื่อเรื่อง + กรอบรูปพร้อมเงา + เลขหน้าวงกลมของหน้าเนื้อหา (ขนาดรูปจริงเข้าตาราง `GAMES`) |
| `patterns/try_on_cover.py` | ย้อมลายจากคลังเป็นโทนพื้นของเทมเพลต แล้วทำแผ่นเทียบ 6 ลายบนปกจริงก่อนเลือก |

ข้อควรระวังเครื่อง: Edge `--headless` ต้องใส่ `--allow-file-access-from-files` เมื่อโหลดภาพ/ฟอนต์จาก `file://` · คอนโซล Windows พิมพ์ภาษาไทยไม่ได้ ใช้ `PYTHONIOENCODING=utf-8` หรือพิมพ์เป็น `ensure_ascii`
