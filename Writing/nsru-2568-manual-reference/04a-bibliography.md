## ส่วนที่ 4 — Bibliography

**รูปแบบรายการอ้างอิงทำตาม APA 7th Edition มาตรฐาน** (หนังสือ วารสาร เว็บไซต์ รายงาน ฯลฯ ไม่ต้องสอนซ้ำ) — ข้างล่างคือ**เฉพาะกฎ มรนว./ภาษาไทย และกฎ workflow ของระบบนี้**:

### กฎ มรนว. + ภาษาไทย
- หัวข้อ "บรรณานุกรม" กึ่งกลางหน้า 18 pt ตัวหนา / หน้าแรกบรรณานุกรม-ภาคผนวก-ประวัติ ไม่ลงเลขหน้าแต่นับรวม
- **ผู้แต่งไทย**: เขียนชื่อเต็มตามปกติ ชื่อ + (2 เคาะ) + นามสกุล **ไม่กลับนามสกุลขึ้นก่อนแบบอังกฤษ**
- ข้อมูลไม่ครบภาษาไทย: ไม่มีปี = (ม.ป.ป.) / ไม่มีสำนักพิมพ์ = (ม.ป.ท.)
- **วิทยานิพนธ์ไทย** ใช้คำในวงเล็บเหลี่ยมภาษาไทย: `[วิทยานิพนธ์ปริญญามหาบัณฑิต ไม่ได้ตีพิมพ์]` / `[วิทยานิพนธ์ปริญญามหาบัณฑิต, ชื่อมหาวิทยาลัย]`
- **ราชกิจจานุเบกษา** (ไม่มีใน APA สากล): `ชื่อกฎหมาย. (ปี, วัน เดือน). ราชกิจจานุเบกษา. เล่ม X ตอนที่ Y. หน้า Z.`
- **การจัดเรียง**: กลุ่มไทยก่อน → อังกฤษหลัง / ไทยเรียง ก-ฮ (พยัญชนะก่อนสระ) / อังกฤษ A-Z
- ห้ามใส่จุด (.) ปิดท้าย URL/DOI

### กฎบรรณานุกรมสะสม (ท้ายหัวข้อรอง)

**ตั้งต้นให้ถูก**: เอกสารในคลังคือไฟล์ที่ผู้ใช้ไปสืบค้นและดาวน์โหลดมาเองกับมือ แล้วผ่าน Source Quality Audit มาแล้ว — **เมทาดาทาอยู่ในไฟล์ครบ หน้าที่ของ agent คืออ่านออกมาให้ครบ ไม่ใช่ตั้งข้อสงสัยหรือแปะป้ายกำกับ**

- **เขียนรายการให้สมบูรณ์ตามที่ไฟล์มี**: ผู้แต่ง**ทุกคนรวมผู้แต่งร่วม** · ปี · ชื่อเรื่องเต็ม · ชื่อวารสารจริง · ปีที่(ฉบับที่) · เลขหน้า · DOI (ถ้ามี) / วิทยานิพนธ์ใช้ `[วิทยานิพนธ์ปริญญามหาบัณฑิต, ชื่อมหาวิทยาลัย]`
- **ที่ต้องอ่านให้ครบก่อนเขียน**: หัวเรื่อง/หัว-ท้ายกระดาษ (ชื่อวารสาร ปีที่ ฉบับที่ เลขหน้า) · บล็อก DOI/ISSN/Received-Accepted · หน้าปก-หน้าอนุมัติ (วิทยานิพนธ์) · **บรรทัดผู้แต่งใต้ชื่อเรื่อง** — **ห้ามใช้ชื่อไฟล์เป็นแหล่งข้อมูลผู้แต่ง** (ชื่อไฟล์มักมีชื่อคนเดียว ทำให้ผู้แต่งร่วมหาย)
- 🚨 **ค่าทุกช่องต้องมาจากไฟล์ ห้ามแต่งขึ้นเอง** — โดยเฉพาะชื่อวารสารกลาง ๆ ที่ปั้นง่าย (วารสารวิชาการ · วารสารการบริหาร… · Journal of [สาขา]) และเลขหน้า/ปีที่ที่ "ดูสมจริง"
- **ช่องที่หาไม่เจอจริง ๆ** → เว้นช่องนั้นว่าง แล้วรวบแจ้ง**บรรทัดเดียวท้ายบรรณานุกรม** ว่ายังขาดอะไรของรายการไหน ("ยังขาด DOI ของ Rai และเลขหน้าของจตุรพร") — **ห้ามแปะป้ายรายช่อง ห้ามใส่ค่าพร้อมป้ายในรายการเดียวกัน** (ใส่ตัวเลขแล้วคลุมด้วยป้าย = แต่งขึ้น อันตรายกว่าเว้นว่าง) และ**ห้ามให้ป้ายโผล่ในเนื้อร่าง** — นาม-ปีในเนื้อต้องใช้งานได้เสมอ
- **ผู้แต่งไทยที่ไฟล์มีแต่ชื่อไม่มีนามสกุล** → อ่านหน้าปก/หน้าอนุมัติเพิ่ม ถ้าไม่มีจริงจึงแจ้งผู้ใช้ (เล่มไทยบังคับ ชื่อ + 2 เคาะ + นามสกุล)
- **ถ้าผู้ใช้แนบมาเฉพาะ notebook แล้วเมทาดาทาไม่ติดมาจริง ๆ** → ขอให้ลากไฟล์ PDF ของงานที่ ✅ แนบเข้าแชทเฉพาะรอบทำบรรณานุกรม (หรือขอไฟล์ `_CITATIONS.txt` ถ้าผู้ใช้เก็บไว้) — **ห้ามสั่งให้ผู้ใช้พิมพ์ตารางทะเบียนเล่มเอง** และห้ามหยุดงานรอ ให้ส่งร่างเนื้อหาไปก่อนแล้วเติมบรรณานุกรมทีหลัง
- **เอกสารประเภทวิทยานิพนธ์/รายงานที่ไม่ได้ตีพิมพ์ ห้ามแปลงร่างเป็นบทความวารสาร** — ไม่มีชื่อวารสารในไฟล์ = ไม่ใช่บทความวารสาร ให้ใช้แม่แบบวิทยานิพนธ์ (วงเล็บเหลี่ยมภาษาไทย ดูด้านล่าง)
