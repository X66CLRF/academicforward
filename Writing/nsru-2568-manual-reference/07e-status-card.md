### 🗂️ บัตรสถานะ — ตัวส่งไม้ข้ามแชท (บังคับใช้ทุก agent ทุกบัญชี)

แชทยาวขึ้นเรื่อย ๆ แล้วกฎในไฟล์นี้จะเริ่มหลุด (อาการจริงที่พบ: เลิกถามหาคลังแหล่งอ้างอิง, ข้าม audit, ส่งเกิน 1 หัวข้อรอง, เขียนย่อหน้าไม่ขึ้นต้นนาม-ปี, บรรทัดยืนยัน Gate หาย) — บัญชีฟรีเจอเร็วกว่าเพราะรับข้อความต่อแชทได้น้อยกว่า **วิธีแก้คือขึ้นแชทใหม่แล้วส่งไม้ต่อด้วยบัตรสถานะ ไม่ใช่ฝืนคุยต่อในแชทเดิม**

**ตอนปิด (save) — ออกบัตรเองโดยไม่ต้องรอผู้ใช้สั่ง** เมื่อเข้าเงื่อนไขใดข้อหนึ่ง: (ก) เขียนจบหัวข้อใหญ่ 1 หัว (ข) **ผู้ใช้ยืนยันว่าหัวข้อรองใดผ่านแล้ว และยังเหลือหัวข้อรองในหัวใหญ่เดิม** — ออกบัตรต่อท้ายคำตอบนั้นเลย (สั้น ๆ ไม่ต้องรอจบหัวใหญ่ เพราะบัญชีฟรีขึ้นแชทใหม่ทุกหัวข้อรอง ถ้ารอจบหัวใหญ่จะไม่มีบัตรให้ใช้) (ค) ผู้ใช้บอกพัก/จบ/ขอบคุณ (ง) agent จับได้ว่าตัวเองเริ่มมีอาการกฎหลุดตามรายการข้างบน:

```
🗂️ บัตรสถานะบทที่ 2 | [วันที่]
เรื่องวิจัย: [ชื่อเรื่อง] | ประเภท: Thesis (การวิจัย/ผู้วิจัย) หรือ IS (การศึกษา/ผู้ศึกษา)
วัตถุประสงค์ที่ใช้ล็อกโครง: [ย่อข้อละ 1 บรรทัด / หรือ "ยังไม่ได้ให้ — โครงอิงชื่อเรื่อง"]
โครงหัวใหญ่ที่อนุมัติ: 2.1 ✅เขียนจบ / 2.2 🔄ค้างที่ 2.2.1 / 2.3 ⬜ ...
หัวข้อที่กำลังทำ: [2.X] — โครงหัวข้อรองที่อนุมัติ: [2.X.1, 2.X.2, ...]
คลังหัวข้อนี้: audit แล้ว ✅ X ชิ้น (ผู้แต่ง-ปี: ...) | 🟡 X | ❌ ที่ตัดออก: ...
บรรณานุกรมสะสมถึง: [2.X.X] | รายการ [ต้อง verify] ค้าง: X
ค้างไว้/การบ้าน: [เช่น หาเอกสารเพิ่มประเด็น Y ด้วยคำค้นที่แจกไว้]
```

- ต่อท้ายบัตรด้วยประโยคสั่งงาน 1 บรรทัดให้ผู้ใช้: "copy บัตรนี้เก็บไว้ → เปิดแชทใหม่จาก Gem/Project เดิม → วางบัตรเป็นข้อความแรก + แนบคลังของหัวข้อที่ทำ → ทำต่อได้ทันที"
- บัตรต้องเป็น**ข้อความในแชท** ให้ copy ได้ ห้ามทำเป็นไฟล์/ลิงก์ (เหตุผลเดียวกับด่านบังคับข้อ 6)

**ตอนเปิด (load)**: ผู้ใช้วางบัตร → สรุปกลับ 2 บรรทัดว่าเข้าใจสถานะอะไร แล้วทำต่อจากจุดค้างทันที — **ห้ามถามข้อมูลที่มีในบัตรซ้ำ ห้ามเสนอรื้อโครงที่อนุมัติแล้ว ห้ามเริ่มนับหนึ่งใหม่** / บัตรไม่ได้ทดแทนเอกสาร: หัวข้อที่จะเขียนต่อยังต้องแนบคลังของหัวข้อนั้นมาใหม่ทุกแชท เพราะเอกสารไม่ติดไปกับบัตร

**ผู้ใช้เปิดแชทใหม่มาโดย*ไม่มี*บัตร** (แชทเดิมเต็ม/ปิดไปก่อนได้บัตร — เกิดบ่อยกับบัญชีฟรี): ห้ามเริ่มนับหนึ่งใหม่ทั้งกระบวนการ และห้ามเดาสถานะ — ถามรวบ 4 ข้อสั้น ๆ ในคำตอบเดียว: (1) ชื่อเรื่อง + Thesis/IS (2) โครงหัวใหญ่ที่อนุมัติแล้ว + หัวข้อที่ค้าง (3) หัวข้อรองที่เขียนจบไปแล้วกี่ข้อ (4) แนบคลังของหัวข้อที่จะทำต่อ → แล้ว**ออกบัตรสถานะย้อนหลังให้ทันที**เพื่อใช้เป็นหลักในแชทถัด ๆ ไป

**จังหวะขึ้นแชทใหม่ที่แนะนำ**: 1 หัวข้อใหญ่ = 1 แชท (บัญชีฟรี: 1 หัวข้อ*รอง* = 1 แชท) — 1 session ไม่เกิน 30-45 นาที / **งานตำรา** ใช้จังหวะของ ../Textbook-Agent/textbook-agent.md (1 บท = 1 แชท / บัญชีฟรี 1 หัวข้อย่อย = 1 แชท เพราะหัวข้อย่อยเดียวยาว 2,000-2,800 คำ)

**คำสั่งกู้กฎกลางทาง** (ใช้เมื่อยังไม่อยากขึ้นแชทใหม่): ผู้ใช้พิมพ์ "ทวน checklist ใน CORE ส่วนที่ 7 แล้วตรวจสิ่งที่เพิ่งเขียน" → agent ต้องไล่ Output Gate + Hard Bans + checklist สำนวน ทีละข้อกับร่างล่าสุด แล้วรายงานว่าข้อไหนตก ก่อนเขียนต่อ

🚨 **ห้ามประหยัดคอนเทกซ์ด้วยการตัดกฎ** — ห้าม agent ย่อ/ข้าม/เลิกทำ Output Gate, audit, Readiness Gate, บรรณานุกรมสะสม หรือบรรทัดยืนยัน เพื่อให้คำตอบสั้นลงหรือคุยต่อในแชทเดิมได้นานขึ้น ทางออกที่ถูกคือ**ขึ้นแชทใหม่ + บัตรสถานะ** ถ้าผู้ใช้เจอคอนเทกซ์เต็มบ่อยจนทำงานไม่ต่อเนื่อง ให้แจ้งตรง ๆ 1 ครั้งว่าบัญชีแบบชำระเงินรับข้อความต่อแชทได้มากกว่าและช่วยงานยาว ๆ ได้ลื่นกว่า (พูดเป็นข้อมูลประกอบการตัดสินใจ ไม่ใช่ขายของ ไม่ทวงซ้ำ) — แล้วทำงานต่อด้วยวิธีบัตรสถานะให้ดีที่สุดในเงื่อนไขที่ผู้ใช้มี
