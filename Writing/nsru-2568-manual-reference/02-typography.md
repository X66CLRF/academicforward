## ส่วนที่ 2 — Typography (มรนว. 2568)

- **Font**: TH Sarabun New ทั้งเล่ม
- **ขนาด**:
  - หัวข้อใหญ่/ชื่อบท: **18 pt ตัวหนา**
  - หัวข้อรอง/เนื้อหา: **16 pt** (หัวข้อรอง = ตัวหนา, เนื้อหา = ตัวธรรมดา)
- **Spacing**:
  - หลัง `,` `.` `;` → เว้น **1 เคาะ**
  - ระหว่างชื่อ–นามสกุล (ไทย) → เว้น **2 เคาะ**
### แผนภาพ/Flowchart (Mermaid) — บล็อกตั้งค่ามาตรฐาน ใช้ร่วมทุกภาพในเล่ม

🚨 **ต้องวางบล็อกนี้ครบทุกตัวแปรทุกครั้ง ห้ามตัดให้สั้นลง** — ตัวแปรที่ไม่ได้กำหนดจะตกกลับไปใช้ค่าเริ่มต้นของ mermaid ซึ่งเป็น**โทนครีม** (เคสจริง: กำหนดแค่ `primaryColor` แล้วลืม `clusterBkg` ผลคือกรอบ subgraph ของตัวแปรต้น/ตัวแปรตามออกมาพื้นครีมทุกครั้ง ทั้งที่กล่องข้างในขาว):

```
%%{init: {"theme":"base","themeVariables":{
  "fontFamily":"TH Sarabun New, Sarabun, sans-serif","fontSize":"22px",
  "background":"#ffffff","primaryColor":"#ffffff","primaryBorderColor":"#000000",
  "primaryTextColor":"#000000","secondaryColor":"#ffffff","tertiaryColor":"#ffffff",
  "clusterBkg":"#ffffff","clusterBorder":"#000000","lineColor":"#000000",
  "textColor":"#000000","edgeLabelBackground":"#ffffff","titleColor":"#000000"}}}%%
```

**กฎร่วมทุกแผนภาพ**
- ขึ้นบรรทัดในกล่องใช้ **`<br>` เท่านั้น** — `\n` ใช้ไม่ได้กับ mermaid รุ่นใหม่บางตัว
- เชื่อมเส้นข้ามกลุ่มให้**ลากจากโหนดจริงถึงโหนดจริง** (`A3 --> B1`) ห้ามลาก subgraph → subgraph (เส้นจะอ้อม)
- ทุกโหนดต้องอยู่ใน `class` ที่กำหนดสีไว้ — โหนดที่หลุด class จะกลายเป็นครีม
- พื้นขาว เส้นดำ ตัวอักษรดำ พร้อม export ขาวดำเข้าเล่ม / ต่อท้ายโค้ดทุกครั้งด้วยวิธีใช้: copy → https://mermaid.live → วางแทนของเดิม

**แม่แบบที่ 1 — กรอบแนวคิดการวิจัย (ท้ายบทที่ 2)**: ใช้ `flowchart LR`
- 🚨 **ตำแหน่งซ้าย-ขวาถูกกำหนดโดยลำดับที่ประกาศ subgraph ไม่ใช่ชื่อกลุ่ม** → **ประกาศ `subgraph IV` (ตัวแปรต้น) ก่อน `subgraph DV` (ตัวแปรตาม) เสมอ** ประกาศสลับ = ภาพออกมาตัวแปรตามอยู่ซ้าย ผิดขนบไทย
- ลูกศรมีทิศเดียว `IV --> DV` ห้ามย้อน / มีตัวแปรส่งผ่าน: `IV --> M --> DV` และเติมเส้นตรง `IV --> DV` ด้วย / ตัวแปรกำกับ (Moderator) ชี้ลงกลางเส้น ไม่ใช่ชี้เข้ากล่องตัวแปรตาม

**แม่แบบที่ 2 — โฟลว์ชาร์ตขั้นตอนการวิจัย (บทที่ 3)**: ใช้ `flowchart TB` · 1 `subgraph` ต่อ 1 ขั้นตอนการวิจัย · ปิดท้ายด้วยโหนดผลลัพธ์ทรงแคปซูล `END(["..."])`

```
%%{init: {...บล็อกตั้งค่ามาตรฐานข้างบน...}}%%
flowchart TB
    subgraph STEP1["ขั้นตอนที่ 1 [ชื่อขั้นตอน]"]
        A1["[กิจกรรม]<br>[กลุ่มเป้าหมาย/จำนวน]"]
        A2["[กิจกรรม]<br>[รายละเอียด]"]
    end
    subgraph STEP2["ขั้นตอนที่ 2 [ชื่อขั้นตอน]"]
        B1["[กิจกรรม]"]
        B2["[กิจกรรม]"]
    end
    A1 --> A2 --> B1
    B1 --> B2 --> END(["[ผลลัพธ์สุดท้ายของการวิจัย]"])
    classDef boxStyle fill:#ffffff,stroke:#000000,stroke-width:1.5px,color:#000000
    class A1,A2,B1,B2,END boxStyle
    style STEP1 fill:#ffffff,stroke:#000000
    style STEP2 fill:#ffffff,stroke:#000000
```
