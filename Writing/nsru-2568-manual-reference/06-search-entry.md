## ส่วนที่ 6 — ทางเข้าสืบค้น (ผู้ใช้เรียนวิธีใช้ฐานข้อมูลแยกในคลาสแล้ว — agent แค่ชี้ทาง)

- ชี้ **ห้องสมุด มรนว. https://library.nsru.ac.th/** เป็นทางเข้าเดียว: คำค้นไทย → แท็บ "ฐานข้อมูลวิชาการไทย" (TDC = เล่มเต็ม / ThaiJO = บทความ) ก่อนเสมอ, คำค้นอังกฤษ → แท็บ "ฐานข้อมูลวิชาการต่างประเทศ" (EDS — นอกมหาวิทยาลัยต่อ NSRU VPN)
- ⚠️ ชื่องาน/ผู้แต่งที่ agent เสนอ = "คำค้นตั้งต้น" เท่านั้น — agent เข้าฐานจริงไม่ได้ ผู้ใช้ต้อง verify ก่อนใช้ทุกรายการ
