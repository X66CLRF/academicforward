### 📏 สเปกการจัดรูปแบบเนื้อหาในไฟล์ Word

> **ที่มาของค่า**: วัดจากเอกสารตัวอย่างของมหาวิทยาลัย `H:\Shared drives\วิจัยจบ\[ตัวอย่างการพิมพ์รูปแบบวิจัย] Lorem ipsum dolor sit (Example).docx` — เป็นค่าที่วัดจากไฟล์จริง ไม่ใช่ค่าที่ประมาณเอา

**1. หน้ากระดาษและตัวอักษร**

| รายการ | ค่า |
| :--- | :--- |
| ขอบบน | 3.81 ซม. |
| ขอบล่าง | 2.54 ซม. |
| ขอบซ้าย | 3.81 ซม. |
| ขอบขวา | 2.54 ซม. |
| ฟอนต์ | TH Sarabun New ทั้งเล่ม |
| ขนาดเนื้อความ | 16 pt |
| ระยะบรรทัด | **เดี่ยว (single)** ไม่ใช่ 1.5 |
| ระยะห่างก่อน/หลังย่อหน้า | **0 ทั้งคู่** — เว้นวรรคด้วยย่อหน้าว่างเท่านั้น |
| การจัดแนวย่อหน้าเนื้อความ | **จัดกระจายแบบไทย (Thai distributed)** — `w:jc` = `thaiDistribute` |

🚨 **ใช้การจัดกระจายแบบไทย ไม่ใช่การจัดกระจายแบบละติน** — ปัญหาไม่ได้อยู่ที่การจัดกระจาย แต่อยู่ที่**ชนิด**ของการจัดกระจาย

* **แบบละติน** (`w:jc` = `both`) ยืดเฉพาะ**ช่องว่างระหว่างคำ** ภาษาไทยไม่มีช่องว่างระหว่างคำ จึงดันช่องว่างก้อนใหญ่มากลางบรรทัด ผู้อ่านเข้าใจผิดว่าเป็นการกดปุ่ม Enter พอกดลบกลับลบตัวอักษรแทน
* **แบบไทย** (`w:jc` = `thaiDistribute` — ใน Word เรียก **Thai distributed**) ยืดตามกฎอักษรเชิงซ้อน **ให้ใช้ค่านี้กับย่อหน้าเนื้อความทั้งหมด**
* **หัวบท ชื่อบท และชื่อภาพ** ใช้กึ่งกลางตามเดิม
* 🔴 **ข้อความในตาราง ไม่ใช้ `thaiDistribute`** — ใช้ชิดซ้าย (หรือกึ่งกลางสำหรับหัวตารางและคอลัมน์ตัวเลข)
  ช่องตารางกว้างน้อย การยืดให้ชนขอบทั้งสองข้างทำให้ช่องไฟในช่องเดียวโหว่ผิดสัดส่วน
  **ขอบเขตของค่า `thaiDistribute` คือย่อหน้าเนื้อความเท่านั้น**

**2. ขนาดและน้ำหนักตัวอักษร**

| ส่วน | ขนาด | น้ำหนัก | การจัดแนว |
| :--- | :---: | :---: | :--- |
| หัวบทและชื่อบท | 18 pt | ตัวหนา | กึ่งกลาง |
| หัวข้อทุกระดับ | 16 pt | ตัวหนา | ชิดซ้าย |
| เนื้อความ | 16 pt | ตัวธรรมดา | **จัดกระจายแบบไทย** (`thaiDistribute`) |

หัวข้อ**ขนาดเท่าเนื้อความ** แยกด้วยตัวหนาอย่างเดียว — **ห้ามไล่ขนาดหัวข้อลงมาเป็นชั้น ๆ แบบเว็บ**

**3. บันไดการเยื้อง — ใช้เยื้องบรรทัดแรก (first-line indent) เท่านั้น หน่วยเซนติเมตร**

| ระดับ | เยื้องบรรทัดแรก |
| :--- | :---: |
| เนื้อความ | 1.52 |
| ระดับ `1.` | 1.52 |
| ระดับ `1.1` | 1.96 |
| ระดับ `1)` | 2.54 |
| ระดับ `(1)` | 2.97 |

**4. กฎย่อหน้าต่อเนื่องของข้อ**

ย่อหน้าที่เป็นเนื้อหาขยายความของข้อใด ให้**เยื้องซ้ายทั้งย่อหน้า (left indent)** ไปตรงกับอักษรตัวแรกของข้อนั้น **ไม่ใช่เยื้องเฉพาะบรรทัดแรก** ค่าที่ใช้คือค่าเยื้องของ**ระดับถัดไป**

| ย่อหน้าต่อจากข้อ | เยื้องซ้ายทั้งย่อหน้า |
| :--- | :---: |
| `1.` | 1.96 |
| `1.1` | 2.54 |
| `1)` | 2.97 |

**5. มาตรฐานตารางในเนื้อหา**

**ชื่อตารางวางเหนือตาราง ส่วนชื่อภาพวางใต้ภาพ** ตามหลัก APA 7th · ชื่อตารางต้องตั้งคุณสมบัติ **Keep with next** (`w:keepNext`) กันไม่ให้ชื่อตารางหลุดไปอยู่คนละหน้ากับตัวตาราง

ตารางทุกตารางต้องตั้งค่า 4 อย่าง

| # | รายการ | ค่า / XML | ไม่ตั้งแล้วเกิดอะไร |
| :---: | :--- | :--- | :--- |
| 1 | หัวตารางซ้ำอัตโนมัติเมื่อข้ามหน้า | `<w:tblHeader/>` ใน `trPr` ของแถวแรก | ตารางยาวอ่านไม่รู้เรื่อง เพราะหัวตารางอยู่หน้าก่อน |
| 2 | ปรับพอดีความกว้างหน้ากระดาษ (AutoFit Window) | `<w:tblW w:type="pct" w:w="5000"/>` (= 100%) | ตารางแคบไม่เต็มหน้ากระดาษ |
| 3 | ปรับความกว้างคอลัมน์อัตโนมัติ | `<w:tblLayout w:type="autofit"/>` | คอลัมน์ค้างความกว้างเดิม ข้อความยาวล้น |
| 4 | ข้อความในตารางจัดกึ่งกลาง หัวตารางตัวหนา | — | อ่านยาก แยกหัวตารางจากเนื้อไม่ออก |

**6. ข้อห้าม**

- **ห้ามจำลองการเยื้องด้วยการเคาะ space หรือ tab** — ต้องตั้งค่าย่อหน้าใน Word เท่านั้น
- **ห้ามใส่บรรทัดว่างเพื่อเว้นระยะ** แทนการตั้งค่าย่อหน้า
- **ห้ามใช้สีเป็นตัวแยกความหมาย** เอกสารอาจถูกพิมพ์ขาวดำ

**7. ระดับความเข้มงวดระหว่างยกร่าง**

ระหว่างยกร่าง ให้จัดเพียงพอให้อ่านออกว่าอะไรเป็นข้อใหญ่ ข้อย่อย และข้อย่อยลงไปอีก โดย**ย่อทีละขั้นเท่ากัน** เช่น 1.27 ซม. ต่อชั้น

ค่าละเอียดตามข้อ 3 และ 4 **ใช้ตอนจัดรูปเล่มขั้นสุดท้ายเท่านั้น** อย่าเสียเวลาจัดรูปแบบละเอียดระหว่างที่เนื้อหายังไม่นิ่ง



#### 📐 กฎเพิ่มจากการตรวจเล่มจริงของผู้เขียน (เล่ม IE 3502104, 26 ก.ย. 2569)

**ก. บันไดหัวข้อ**

| ส่วน | การจัด |
| :--- | :--- |
| หัวข้อ X.Y | ชิดซ้าย ตัวหนา |
| เนื้อความใต้ X.Y | เยื้องบรรทัดแรก 1.52 ซม. |
| หัวข้อ X.Y.Z | เยื้อง **0.6 นิ้ว (1.52 ซม.)** ตัวหนา ใช้**แท็บ**หลังเลขหัวข้อ ให้ชื่อหัวข้อเริ่มที่ 2.54 ซม. |
| เนื้อความใต้ X.Y.Z | เยื้องบรรทัดแรก 2.54 ซม. **ตรงอักษรตัวแรกของชื่อหัวข้อ** |
| ข้อ `1.` ใต้ X.Y.Z | 2.54 ซม. แล้วข้อย่อยถัดไปเลื่อนตามบันได (2.97 …) |

หลักคือ **ทุกชั้นเริ่มตรงอักษรตัวแรกของชั้นที่อยู่เหนือ**

**ข. ข้อที่ขึ้นต้นด้วยคำตัวหนา → หนาตั้งแต่เลขข้อ** `**1. ชื่อข้อ** คำอธิบาย` ไม่ใช่ `1. **ชื่อข้อ**`

**ค. ที่มาใต้ตารางและรูป**

* ตาราง: ชื่อ**เหนือ**ชิดซ้าย · ที่มา**ใต้**ชิดซ้ายตรงขอบซ้ายตาราง (ไม่เยื้อง)
* รูป: ชื่อ**ใต้**กึ่งกลาง · ที่มา**ชิดซ้าย** — **บรรทัดที่มาชิดซ้ายเสมอ ทั้งใต้ตารางและใต้รูป** (ผู้เขียนยืนยัน 26 ก.ย. 2569)
* ขนาด 16 pt เท่าเนื้อความ
* **งานที่ผู้เขียนทำเองล้วนไม่ต้องใส่ที่มา** ห้ามเขียน "ที่มา: ผู้เขียน" · ข้อมูลสมมติเขียน "หมายเหตุ: ข้อมูลสมมติเพื่อการสอน"
* ไม่เขียน "ผู้เขียน เรียบเรียงจาก …" ให้เขียน "เรียบเรียงจาก …"

**ค2. การจัดแนวเนื้อความ** ข้อความทั่วไปในเนื้อหาใช้**จัดกระจายแบบไทย**เสมอ ห้ามเปลี่ยนเป็นชิดซ้ายเพื่อแก้รอยตัดคำท้ายบรรทัด (ผู้เขียนเลือกคงไว้ ดู `docx-builder` หัวข้อ "ตัดคำไม่สวย ไม่ใช่บั๊ก")

**ค3. หัวกระดาษและท้ายกระดาษ** ระยะหัวกระดาษจากขอบบน **0.75 นิ้ว** ท้ายกระดาษจากขอบล่าง **0.5 นิ้ว** (ผู้เขียนกำหนด 26 ก.ย. 2569) python-docx: `section.header_distance = Inches(0.75)` · `section.footer_distance = Inches(0.5)`

**ง. ระยะห่าง** รอบตาราง กรอบ และรูป เว้น 12 pt ด้วยค่าระยะก่อน/หลังย่อหน้า (ห้ามใช้บรรทัดว่าง ตามข้อ 6)

**จ. การแบ่งหน้า**

* `แบบฝึกหัดบทที่ X` และ `เอกสารอ้างอิงประจำบทที่ X` ขึ้นหน้าใหม่เสมอ
* หัวข้อทุกระดับ **และป้ายหัวตอนตัวหนา** (`ตอนที่ 1 …` `ตัวอย่างที่ 3.2 …`) ต้องติดกับบรรทัดถัดไป — ห้ามค้างท้ายหน้า
* แถวตาราง กรอบประเด็น กรอบรูป ห้ามแยกข้ามหน้า · เปิดการควบคุมบรรทัดค้าง

**ฉ. ส่วนลงชื่อท้ายคำนำ** ชื่อผู้เขียนและเดือนปี ชิดขวา

**ช. แผนบริหารการสอนประจำบท** ใช้แบบฟอร์มเดิมของผู้เขียนก่อนเสมอ (ดู `ตัวอย่าง แผนการสอนประจำบท.docx` ของผู้เขียน)
หัวข้อ: เนื้อหาประจำบท · **วัตถุประสงค์เชิงพฤติกรรม** (เป็นข้อ ลงท้าย "ได้" ใส่รหัส LLO ท้ายข้อได้) · วิธีการสอนและกิจกรรม · สื่อ · การวัดผลและการประเมินผล (เป็นข้อ)
ห้ามเปลี่ยนเป็นตาราง LLO/CLO แบบ OBE ถ้าผู้เขียนไม่ได้ใช้

**ซ. ตัวอย่างและโจทย์ต้องใช้ตัวเลขปัจจุบัน** ห้ามยกตัวเลขในตัวอย่างของตำราเก่ามาตรง ๆ (เคสจริง: อัตรา 38.00/38.67 บาทต่อดอลลาร์จากตำรา 2548)
ถ้าเป็นตัวอย่างจากแหล่งที่ยกมาทั้งชุด (เช่น ตัวอย่างวิกฤต 2540) คงตัวเลขเดิมและอ้างแหล่ง

### 🚨 กฎ Hanging Indent — ตั้งใน Word เท่านั้น ห้ามเคาะ space
- Hanging indent เป็นคุณสมบัติย่อหน้าใน Word ไม่ติดไปกับข้อความที่ copy จากแชท — agent ส่งบรรณานุกรมเป็น**ข้อความชิดซ้ายธรรมดา 1 รายการ/1 ย่อหน้า** + แนบคำเตือนทุกครั้ง: "วางใน Word แล้วลากคลุม กด **Ctrl+T** เพื่อทำ hanging indent 0.5""
- **ห้าม agent จำลองการเยื้องด้วย space/tab เด็ดขาด** — วางลง Word แล้วพัง
- ค่ามาตรฐาน 0.5" (1.27 ซม.) — "เยื้อง 8 ตัวอักษร" ในคู่มือเก่าเป็นค่าประมาณยุคพิมพ์ดีด ห้ามใช้ตั้งค่า
