## 🧯 3. ลายนิ้วมือภาษาเครื่องในภาษาไทย (Thai AI-Tells)

ต่อให้เครื่องตรวจยังไม่ให้คะแนนภาษาไทย กรรมการและบรรณาธิการอ่านออก และมันคือสัญญาณว่าผู้เขียนยังไม่ได้คิดเอง

**ทำไมการให้ AI เกลาภาษาถึงผลักสำนวนไปทางเดียวกันหมด** งานทดลองข้ามวัฒนธรรมของ Agarwal, Naaman และ Vashistha (CHI 2025) กับผู้เข้าร่วม 118 คนจากอินเดียและสหรัฐอเมริกา พบว่าข้อเสนอแนะจาก AI ทำให้ผู้เข้าร่วมชาวอินเดียเขียนแบบตะวันตกมากขึ้น **เปลี่ยนทั้งสิ่งที่เขียนและวิธีเขียน** และลดความต่างทางวัฒนธรรมในภาษาลง สอดคล้องกับรายงานที่ว่างานที่ผ่านการปรับด้วย AI มีไวยากรณ์ดีขึ้นแต่สำนวนเหมือนกันไปหมด รวมถึงคำสั่งประเภท "แก้แค่ไวยากรณ์" ที่ยังทำให้ความหมายเคลื่อนไปทางทางการและไร้ตัวตนมากขึ้น

ข้อ 1 ถึงข้อ 3 ของไฟล์นี้จึงไม่ใช่เรื่องรสนิยม แต่เป็นการกันแรงดึงที่มีอยู่จริงในเครื่องมือ — **ถ้าปล่อยให้ AI เกลาโดยไม่คุมกรอบ ผลลัพธ์จะเลื่อนไปหาโครงสร้างประโยคภาษาอังกฤษเสมอ ไม่ว่าจะสั่งให้เกลาน้อยแค่ไหน**

### 3.1 วลีต้องห้าม ใช้ได้ไม่เกิน 1 ครั้งต่อบท

| กลุ่ม | ตัวอย่างที่ต้องเลิกใช้ |
| :--- | :--- |
| เปิดย่อหน้าลอย | "ในโลกยุคปัจจุบันที่มีการเปลี่ยนแปลงอย่างรวดเร็ว" · "ในยุคดิจิทัลที่เทคโนโลยีเข้ามามีบทบาท" |
| ยกความสำคัญลอย | "มีบทบาทสำคัญอย่างยิ่ง" · "ถือเป็นสิ่งที่มีความสำคัญเป็นอย่างมาก" · "นับเป็นหัวใจสำคัญ" |
| สำนวนแปล not only…but also | "ไม่เพียงแต่…แต่ยังรวมถึง…อีกด้วย" |
| ปิดย่อหน้าสำเร็จรูป | "…ได้อย่างมีประสิทธิภาพและประสิทธิผล" · "…อย่างยั่งยืนต่อไปในอนาคต" |
| คำเชื่อมเรียงแถว | "นอกจากนี้ … อีกทั้ง … ยิ่งไปกว่านั้น … ดังนั้นจึงกล่าวได้ว่า" เรียงติดกันสี่ย่อหน้า |
| ขยายว่างเปล่า | "อย่างมีนัยสำคัญ" นอกบริบทสถิติ · "เป็นอย่างมาก" · "อย่างแท้จริง" · "อย่างครอบคลุมและรอบด้าน" |
| ทวนคำถามก่อนตอบ | "สำหรับประเด็นที่ว่า… นั้น อาจกล่าวได้ว่า…" |

### 3.2 ลายนิ้วมือเชิงโครงสร้าง

* ทุกย่อหน้ายาวเท่ากัน หรือมีสามประโยคเท่ากันหมด
* ทุกรายการแตกเป็นสามข้อพอดี ทั้งที่ต้นฉบับไม่ได้ระบุจำนวน
* ทุกหัวข้อย่อยปิดด้วย "โดยสรุป" หรือ "กล่าวโดยสรุปได้ว่า"
* ทุกย่อหน้าเปิดด้วยโครง "การ…เป็น…" เหมือนกันหมด
* ใช้ยัติภังค์ยาว — และหัวข้อ bullet แทรกกลางความเรียง (ความเรียงวิชาการไทยไม่ใช้)
* ทุกประโยคสมบูรณ์และยาวพอกัน ไม่มีประโยคสั้นไว้เน้น

### 3.3 กฎความแปรผัน (Burstiness Rule) — ทำตรงข้ามกับข้อ 3.2

* **ความยาวประโยค**: ในหนึ่งย่อหน้าต้องมีประโยคสั้น 8–15 คำ อย่างน้อย 1 ประโยค และประโยคยาว 30–45 คำ อย่างน้อย 1 ประโยค
* **ความยาวย่อหน้า**: สลับ 3–9 ประโยค ห้ามยาวเท่ากันติดกันเกิน 2 ย่อหน้า
* **จำนวนข้อในรายการ**: ตามที่ต้นฉบับระบุจริง — ต้นฉบับบอก 4 ด้าน ต้องเป็น 4 ข้อ ห้ามยุบเหลือ 3 เพื่อความสวย
* **คำเชื่อม**: หมุนคลังคำ — สอดคล้องกับ / ในทางกลับกัน / ต่างจาก / เมื่อพิจารณาร่วมกับ / แม้กระนั้น / ในทำนองเดียวกัน / อย่างไรก็ตาม — ห้ามใช้คำเดิมซ้ำภายใน 3 ย่อหน้า
* **กริยารายงาน**: หมุนเวียน — ได้ให้ความหมายว่า / อธิบายว่า / เสนอแนวคิดว่า / นิยามว่า / ได้ศึกษา / ระบุว่า / ชี้ให้เห็นว่า / โต้แย้งว่า / พบว่า
