## 🔗 17. ด่านคำเข้าคู่ (Collocation Gate) — ชั้นสุดท้ายที่ด่านอื่นจับไม่ได้

> เพิ่มเมื่อ 10 กันยายน 2569 หลังรันข้อ 12 กับหน้าตัวอย่างจริงแล้วได้ 0 จุด
> ทั้งที่ผู้เขียนอ่านแล้วรู้ทันทีว่า "ประโยคนี้ภาษาไทยไม่เขียนแบบนี้"

### 17.1 ทำไมด่าน 2 และ 12 จับไม่ได้

| ด่าน | จับที่ | ตัวอย่างที่จับได้ |
| :--- | :--- | :--- |
| ข้อ 2 | **คำ** — คำแปลผิดบริบท | `ความถูกต้อง` ที่ควรเป็น `ความตรง` |
| ข้อ 12 | **โครง** — ลำดับคำแบบอังกฤษ | `การเพิ่มขึ้นของจำนวนของ…` · `ถูกกำหนดโดย…` |
| **ข้อ 17** | **คู่คำ** — คำไทยแท้ทุกคำ โครงไทยทุกประโยค แต่ **สองคำนี้ไม่เคยอยู่ด้วยกันในภาษาไทย** | `อุปสงค์ในประเทศที่ร้อนแรงเกินไป` |

`ร้อนแรง` เป็นคำไทย `อุปสงค์` เป็นศัพท์บัญญัติ โครงประโยคเป็นไทยสมบูรณ์ ไม่มีอะไรผิดเลยเมื่อดูทีละส่วน
แต่ภาษาไทยเข้าคู่ `ร้อนแรง` กับ `เศรษฐกิจ` ไม่ได้เข้าคู่กับ `อุปสงค์` — ต้นทางคือ *overheated demand*
**นี่คือร่องรอยสำนวนแปลที่ลึกที่สุด และเป็นชั้นที่ผู้ทรงคุณวุฒิอ่านออกแต่บอกไม่ถูกว่าผิดตรงไหน**

### 17.2 บัญชีคู่คำที่อังกฤษเข้าคู่ได้ ไทยไม่เข้าคู่

#### ก. เศรษฐกิจ นโยบาย และตัวเลขมหภาค

| ❌ คู่ที่ลอกมา | ต้นทาง | ✅ |
| :--- | :--- | :--- |
| อุปสงค์ร้อนแรง · อุปสงค์ที่ร้อนแรงเกินไป | overheated demand | อุปสงค์ในประเทศขยายตัวสูงเกินไป · ภาวะเศรษฐกิจร้อนแรง |
| ราคาแข็งแกร่ง · ตัวเลขแข็งแรง | strong prices / robust figures | ราคาอยู่ในระดับสูง · ตัวเลขอยู่ในเกณฑ์ดี |
| ตลาดส่งสัญญาณแรง | strong market signal | ตลาดส่งสัญญาณชัดเจน |
| ตัวเลขกระโดดขึ้น | numbers jumped | ตัวเลขเพิ่มขึ้นอย่างมาก (คำข่าว ไม่ใช่คำตำรา) |
| สุขภาพของเศรษฐกิจ · เศรษฐกิจป่วย | health of the economy / ailing | ภาวะเศรษฐกิจ · เศรษฐกิจอยู่ในภาวะถดถอย |
| ผลของนโยบายเดินทางถึง | policy travels to | ผลของนโยบายส่งถึง |

#### ข. ข้อมูล ตาราง และภาพ

| ❌ | ต้นทาง | ✅ |
| :--- | :--- | :--- |
| ตัวเลขชุดนี้เล่าเรื่อง | the numbers tell a story | ตัวเลขชุดนี้แสดงความสัมพันธ์… |
| ข้อมูลบอกเรา · ข้อมูลชี้ให้เราเห็น | the data tell us | ข้อมูลแสดงว่า · ข้อมูลชี้ว่า (ตัด `เรา` ทิ้ง) |
| ตารางพูดถึง | the table speaks to | ตารางแสดง · ตารางนำเสนอ |
| กราฟวาดภาพให้เห็น | the graph paints a picture | กราฟแสดงให้เห็น |

#### ค. งานวิจัยและวรรณกรรม

| ❌ | ต้นทาง | ✅ |
| :--- | :--- | :--- |
| วรรณกรรมพูดเป็นเสียงเดียวกัน | the literature speaks with one voice | งานวิจัยส่วนใหญ่ให้ข้อสรุปตรงกัน |
| งานวิจัยชี้นิ้วไปที่ | research points the finger at | งานวิจัยชี้ว่า |
| ช่องว่างเรียกร้องการศึกษา | the gap calls for | ยังไม่พบการศึกษาที่… |
| เปิดประตูสู่ | opens the door to | นำไปสู่ · เป็นจุดตั้งต้นของ |
| อ่านเอกสารทีละบรรทัด | read line by line | พิจารณาเอกสารโดยละเอียด |

#### ง. อุปมาสงคราม กีฬา และการเดินทาง

| ❌ | ต้นทาง | ✅ |
| :--- | :--- | :--- |
| ต่อสู้กับปัญหา · ต่อกรกับ | combat the problem | แก้ปัญหา · รับมือกับปัญหา |
| เป็นผู้เล่นหลักในตลาด | a key player | ผู้ประกอบการรายใหญ่ · หน่วยงานหลัก |
| ยิงตรงเป้า · พุ่งเป้า | targeted | มุ่งไปยัง… โดยตรง |
| เส้นทางข้างหน้า | the road ahead | แนวทางในระยะต่อไป |
| กระดูกสันหลังของระบบ | the backbone of | โครงสร้างหลักของระบบ |
| เป็นกุญแจของ | the key to | เป็นพื้นฐานของ · เป็นเงื่อนไขสำคัญของ |

> ⚠️ **อุปมาไม่ได้ผิดทั้งหมด** ภาษาไทยวิชาการมีอุปมาที่ใช้จริงและยอมรับแล้ว เช่น `เงินเฟ้อฝังตัว`
> `ตะกร้าสินค้า` `เส้นห่อหุ้ม` `แก่นของเรื่อง` `วางรากฐาน` — เกณฑ์ตัดสินไม่ใช่ว่าเป็นอุปมาหรือไม่
> แต่คือ **มีคนไทยใช้คู่คำนี้จริงหรือไม่** ตรวจตามข้อ 13.1

### 17.3 ลักษณนามและคำแจกแจงต้องคงที่ตลอดชุด

ภาษาอังกฤษใช้ `first / second / third` ชุดเดียวจบ ภาษาไทยมีคำแจกแจงหลายชุดที่ **ความหมายไม่เท่ากัน**
เมื่อแปลจากอังกฤษ ผู้เขียนมักหยิบสลับชุดโดยไม่รู้ตัว

| คำ | ใช้กับอะไร |
| :--- | :--- |
| `ประการ` | ข้อในการแจกแจงเหตุผลหรือคุณสมบัติ |
| `ข้อ` | รายการที่นับได้ ไม่มีลำดับก่อนหลังบังคับ |
| `ขั้น` | ลำดับในกระบวนการ ต้องทำตามลำดับ |
| `ชั้น` | ระดับที่ซ้อนทับกัน อ่านจากนอกเข้าใน |
| `ระดับ` | ค่าที่มากน้อยต่างกันบนสเกลเดียว |

**ตัวอย่างจริงที่ตรวจพบ**

* ❌ `ตารางที่ 7.1 อ่านได้หลายชั้น **ชั้นแรก**คือทิศทาง … **ขั้นที่สอง**คือแหล่งที่มาของการเร่งขึ้น`
* ✅ `ตารางที่ 7.1 อ่านได้หลายชั้น **ชั้นแรก**คือทิศทาง … **ชั้นที่สอง**คือแหล่งที่มาของการเร่งขึ้น`

**กฎ**: หนึ่งชุดการแจกแจง ใช้ลักษณนามเดียวตลอด ห้ามสลับกลางชุด
**วิธีตรวจ**: ในหนึ่งย่อหน้า ถ้าพบคำแจกแจงตั้งแต่สองชุดขึ้นไป (`ชั้นแรก` + `ขั้นที่สอง`) ให้เปิดดูทุกครั้ง

### 17.4 วิธีตรวจ — ไม่มีเงื่อนไขเดียวที่จับได้หมด ต้องใช้สองทางคู่กัน

**ทางที่ 1 — ยิงจากบัญชี 17.2** ค้นได้ตรงตัว ใช้กับคู่คำที่รู้จักแล้ว

**ทางที่ 2 — แบบทดสอบคู่คำ (Collocation Test)** ใช้กับคู่คำที่ไม่อยู่ในบัญชี

```text
ขั้นที่ 1  แยกวลีเป็น [คำหลัก] + [คำขยายหรือกริยา]     เช่น อุปสงค์ + ร้อนแรง
ขั้นที่ 2  ถามตัวเองว่า ถ้าไม่เคยอ่านภาษาอังกฤษเรื่องนี้มาก่อน จะเขียนคู่นี้ไหม
ขั้นที่ 3  ถ้าลังเล ให้ตรวจตามข้อ 13.1 — ค้น "คู่คำ" ในเครื่องหมายคำพูดบน ThaiJO
เกณฑ์: พบในงานวิชาการไทยคนละสำนัก 2 ชิ้นขึ้นไป → ใช้ได้
       พบเฉพาะในข่าว บทแปล หรือบล็อก        → เปลี่ยน
       ไม่พบเลย                              → เป็นคู่คำที่แปลขึ้นเอง ต้องเปลี่ยน
```

🔴 **จุดที่ต้องระวังที่สุดคือย่อหน้าที่สรุปนัยเชิงนโยบายหรือเชิงทฤษฎี** เพราะเป็นย่อหน้าที่ผู้เขียน
หยิบสาระจากต้นฉบับภาษาอังกฤษมามากที่สุด และเป็นย่อหน้าที่คู่คำแปลกหลุดเข้ามาบ่อยที่สุด

### 17.5 เพิ่มเข้าบัตรตรวจ

```
[COLLOCATION-GATE]
คู่คำจากบัญชี 17.2 ที่พบ        : กี่จุด · ระบุคู่และตำแหน่ง
คู่คำที่ผ่านแบบทดสอบขั้นที่ 2   : กี่คู่ที่ตรวจ · กี่คู่ที่ต้องเปลี่ยน
คู่คำที่ยืนยันด้วยข้อ 13.1 แล้ว  : ระบุคู่และแหล่งที่ยืนยัน
ลักษณนามสลับชุดกลางการแจกแจง   : ต้องเป็น 0 — ระบุย่อหน้า
```
