## 🔠 16. ด่านศัพท์ข้ามสื่อ (Cross-Medium Term Lock)

> เพิ่มเมื่อ 10 กันยายน 2569 จากการตรวจสเปกภาพและตารางของร่างตำราจริง
> ข้อ 2.3 ล็อกศัพท์ใน **ความเรียง** แต่ไม่ครอบไปถึง **หัวตาราง** และ **ป้ายกำกับในภาพ**
> ป้ายภาพจึงหลุดศัพท์นอกบัญชีได้โดยไม่มีด่านใดจับ
> 🔴 และเป็นจุดที่แก้ทีหลัง **แพงที่สุดในเล่ม** เพราะต้องแก้ไฟล์เวกเตอร์แล้วแทรกใหม่ ไม่ใช่แก้ข้อความใน Word

### 16.1 กฎสามข้อ

1. **ศัพท์ที่ปรากฏในภาพหรือตาราง ต้องอยู่ในบัญชี `[GLOSSARY-LOCK]` ของเนื้อความ** — ถ้าไม่อยู่ ต้องเพิ่มเข้าบัญชีก่อน ไม่ใช่ปล่อยให้ภาพใช้คำของตัวเอง
2. **ศัพท์ที่ปรากฏในภาพ ต้องมีนิยามอยู่ในเนื้อความก่อนหน้าภาพนั้น** — ภาพขยายความสิ่งที่ผู้อ่านรู้แล้ว **ห้ามภาพเป็นที่แรกที่ศัพท์นั้นโผล่มา**
3. **รูปคำต้องเป็นรูปเดียวกันทั้งสามสื่อ** — ถ้าเนื้อความเขียน `มีความยืดหยุ่นเท่ากับหนึ่งหน่วย` ป้ายภาพเขียน `ยืดหยุ่นหนึ่งหน่วย` ไม่ได้ เว้นแต่ประกาศรูปย่อไว้ในบัญชีตั้งแต่ต้นว่าใช้รูปใดในภาพ

### 16.2 ตารางตรวจสามทาง

ทำหนึ่งตารางต่อหนึ่งบท ก่อนส่งสเปกให้ figure-agent

```text
[CROSS-MEDIUM-TABLE] บทที่ __
| ศัพท์ | รูปในเนื้อความ (ย่อหน้า) | รูปในหัวตาราง (ตารางที่) | รูปในป้ายภาพ (ภาพที่) | ตรงกัน |
```

**ตัวอย่างจริงที่ตรวจพบ** — ตำราหลักเศรษฐศาสตร์ บทที่ 2

| ระดับความยืดหยุ่น | เนื้อความ | ตารางที่ 2.4 | ป้ายภาพ 2.3.1 | ผล |
| :--- | :--- | :--- | :--- | :---: |
| elastic | มีความยืดหยุ่นมาก (elastic) | ยืดหยุ่นมาก | ยืดหยุ่นมาก | ✅ |
| inelastic | มีความยืดหยุ่นน้อย (inelastic) | ยืดหยุ่นน้อย | ยืดหยุ่นน้อย | ✅ |
| unit elastic | มีความยืดหยุ่น**เท่ากับ**หนึ่งหน่วย | ยืดหยุ่นหนึ่งหน่วย | ยืดหยุ่นหนึ่งหน่วย | ⚠️ รูปคำต่าง |
| perfectly inelastic | **ไม่มีในเนื้อความ** | **ไม่มี** | ไม่มีความยืดหยุ่นเลย | 🔴 ผิดกฎข้อ 2 |
| perfectly elastic | **ไม่มีในเนื้อความ** | **ไม่มี** | ยืดหยุ่นสมบูรณ์ | 🔴 ผิดกฎข้อ 2 |

เนื้อความนิยามไว้สามระดับ แต่สเปกสั่งวาดห้าระดับ ผู้อ่านจะเจอศัพท์สองตัวในภาพที่ยังไม่เคยอ่านนิยาม
**ทางแก้มีสองทางเท่านั้น** — เพิ่มนิยามอีกสองระดับลงเนื้อความ หรือลดภาพเหลือสามแผง เลือกก่อนสั่งผลิต

### 16.3 ภาษาพูดในป้ายภาพ — เพดาน 0 และแพงกว่าเนื้อความ

บัญชีข้อ 9.7 ก. ใช้กับ **ข้อความที่จะถูกพิมพ์ลงในภาพ** ด้วย และต้องตรวจ **ก่อน** ส่งสเปก
ตัวอย่างจริง: ป้าย `ไม่มีความยืดหยุ่นเลย` มีคำว่า `เลย` ซึ่งเป็นคำเน้นแบบสนทนา
ถ้าปล่อยผ่าน คำนี้จะไปอยู่ในไฟล์เวกเตอร์ แก้ครั้งเดียวไม่พอ ต้องแก้แล้วแทรกใหม่ทั้งภาพ

**รูปที่ใช้แทน**: `ไม่ยืดหยุ่นโดยสิ้นเชิง` หรือรูปที่ตำราไทยในสาขานั้นใช้จริง — ยืนยันตามข้อ 13.1 ก่อน

### 16.4 ที่มาในบล็อกสเปกต้องแยกสองส่วนตามข้อ 11

ช่อง `ที่มาแนวคิด:` ของสเปกภาพอยู่ใต้กฎเดียวกับข้อ 11

| ❌ ไม่พอ | ✅ ผ่าน |
| :--- | :--- |
| `ที่มาแนวคิด: ดัดแปลงแนวคิดจาก OpenStax (2022).` | `ที่มาแนวคิด: แนวคิดกราฟสี่กรณีจาก OpenStax (2022) หน้า __ · การจัดสี่แผงในภาพเดียวและการเลือกใช้มาตราส่วนร่วมเป็นการออกแบบของผู้เขียน` |
| — | `ที่มาแนวคิด: ประมวลจากข้อมูลสมมติในตารางที่ 2.1` ✅ ชัดเจนอยู่แล้ว |
| — | `ที่มาแนวคิด: ออกแบบเองล้วน` ✅ ชัดเจนอยู่แล้ว |

คำว่า **ดัดแปลง** เพียงคำเดียวไม่บอกว่าดัดแปลงอะไร ผู้ประเมินแยกไม่ออกว่าส่วนใดเป็นผลงานของผู้เขียน

### 16.5 ตัวเลขต้องตรงกันข้ามสื่อ

ทุกตัวเลขที่ปรากฏในสเปกภาพต้องสอบกลับไปยังตารางต้นทางได้ทุกตัว
ตรวจก่อนส่งสเปก ไม่ใช่ตรวจตอนได้ภาพกลับมา

### 16.6 บัตรตรวจก่อนส่งสเปกให้ figure-agent

```
[CROSS-MEDIUM-AUDIT] บทที่ __
ศัพท์ในป้ายภาพที่ไม่อยู่ใน GLOSSARY-LOCK : ต้องเป็น 0 — ระบุคำที่พบ
ศัพท์ในภาพที่ยังไม่มีนิยามในเนื้อความ    : ต้องเป็น 0 — ระบุภาพที่ใด
รูปคำต่างกันระหว่างเนื้อความ/ตาราง/ภาพ   : ต้องเป็น 0 — ระบุคู่ที่ต่าง
คำภาษาพูดในป้ายภาพ (บัญชี 9.7 ก.)        : ต้องเป็น 0
ช่อง ที่มาแนวคิด ที่ยังไม่แยกสองส่วน      : ต้องเป็น 0 — ระบุภาพที่ใด
ตัวเลขในสเปกที่สอบกลับตารางต้นทางไม่ได้   : ต้องเป็น 0
```
