## 📕 9. น้ำเสียงตำราไทย (Thai Textbook Voice) — ใช้กับงานประเภทตำรา เอกสารประกอบการสอน และหนังสือวิชาการ

> เพิ่มเมื่อ 5 ก.ย. 2569 จากการถอดรูปแบบภาษาของตำราไทยระดับอุดมศึกษาจริง
> ข้อนี้ **ไม่ใช่เรื่องคำแปลผิด** แต่เป็นเรื่องน้ำเสียงที่ผิดประเภทงาน
> ต้นฉบับอ่านรู้เรื่องดี ไวยากรณ์ถูกทุกประโยค แต่กรรมการอ่านแล้วรู้ทันทีว่า "ไม่ใช่ตำรา"

### 9.0 ขั้นตอนบังคับก่อนเขียนบทแรก

1. ถามผู้ใช้ว่ามี **ตำราหรือเอกสารประกอบการสอนเดิม** ของตนเอง หรือตำราไทยในสาขาเดียวกันหรือไม่
2. ถ้ามี ให้เปิดอ่าน **สารบัญ + ย่อหน้าเนื้อความยาว 5 ย่อหน้า** ก่อนลงมือเขียน
3. ถอดออกมา 4 อย่าง แล้วยึดตามนั้นทั้งเล่ม
   * ชื่อหัวข้อประจำ (ส่วนท้ายบทเรียกว่าอะไร)
   * คำเรียกผู้อ่าน (นักศึกษา / ผู้เรียน / ผู้อ่าน)
   * รูปประโยคนิยาม
   * รูปแบบวงเล็บภาษาอังกฤษ (ตัวพิมพ์ใหญ่หรือเล็ก)
4. ถ้าไม่มีต้นฉบับให้ดูเลย ให้ใช้ค่าตั้งต้นในข้อ 9.1–9.5 นี้

### 9.1 ตำราไม่พูดกับผู้สอน 🔴 ผิดบ่อยที่สุด

ตำราเขียนถึง **ผู้อ่าน** ไม่ใช่คู่มือครู ประโยคที่สั่งการผู้สอนหรือบรรยายกิจกรรมในห้องเรียน
ต้องอยู่ใน **ใบปะแผนบริหารการสอน** เท่านั้น ห้ามหลุดเข้าเนื้อความ

| ❌ ห้ามใช้ในเนื้อความ | ✅ ใช้แทน |
| :--- | :--- |
| ควรชี้ให้ผู้เรียนเห็นว่า | ข้อสังเกตที่สำคัญคือ |
| ต้องย้ำกับผู้เรียนตั้งแต่ต้น | เป็นเรื่องที่ต้องทำความเข้าใจตั้งแต่ต้น |
| ประเด็นที่ควรอภิปรายกับผู้เรียน | ประเด็นที่ควรพิจารณาต่อ |
| ผู้สอนควร… | ตัดทิ้ง หรือเขียนเป็นข้อความบอกเล่า |
| ควรอภิปรายในชั้นเรียน | ควรนำมาพิจารณาประกอบ |
| ประเด็นนี้สำคัญมากในการสอน | ประเด็นนี้สำคัญมาก |

**วิธีตรวจเร็ว**: ค้นคำว่า `ผู้สอน` `ในชั้นเรียน` `ควรชี้ให้` `ย้ำกับ` ในไฟล์เนื้อหา
ถ้าเจอนอกใบปะ = ต้องแก้ทุกจุด

### 9.2 คำเรียกผู้อ่าน

ตำราไทยส่วนใหญ่ใช้ **นักศึกษา** ในเนื้อความ และใช้ **ผู้เรียน** เฉพาะในถ้อยคำมาตรฐานของ
ใบปะแผนบริหารการสอน (วัตถุประสงค์เชิงพฤติกรรม วิธีสอน การวัดและประเมินผล)
ตรวจกับต้นฉบับของผู้เขียนก่อน แล้วใช้คำเดียวกันทั้งเล่ม ห้ามสลับไปมา

### 9.3 วงเล็บภาษาอังกฤษใช้ Title Case

เขียน `อุปสงค์ต่อราคา (Price Demand)` · `วงจรชีวิตผลิตภัณฑ์ (Product Life Cycle Theory)` · `อัตราการค้า (Terms of Trade)`
ไม่ใช่ `(price demand)` และไม่ใช่ `(Price demand)` ตัวย่อคงรูปเดิม เช่น `(GDP)` `(f.o.b.)`
รายละเอียดคำที่ใช้ตัวเล็กอยู่ในกฎวงเล็บข้อ 5 หัวข้อ 2.2 (แก้ 27 ก.ย. 2569 ตามคำสั่งผู้เขียน เดิมเป็น sentence case)

### 9.3ก ห้ามเขียนคำอ่านหรือคำทับศัพท์กำกับ

ไม่ต้องบอกผู้อ่านว่าคำนี้อ่านหรือเรียกทับศัพท์ว่าอะไร เช่น ~~ซึ่งธนาคารพาณิชย์นิยมเรียกทับศัพท์ว่าเลตเตอร์ออฟเครดิต~~
ใช้ศัพท์บัญญัติ + วงเล็บอังกฤษครั้งแรกก็พอ

### 9.3ข วงเล็บอังกฤษซ้ำและคำสามัญ (เคสจริงเล่ม IE)

สแกนทุกบทก่อนส่ง: วงเล็บอังกฤษของคำเดียวกันห้ามซ้ำในบทเดียวกัน และห้ามใส่กับคำสามัญ
เคสที่พบ: (Exports) (Imports) (Balance) (Surplus) (Deficit) (Services) (Income) (Quota) กับคำทับศัพท์ `โควตา (Quota)` `ดราฟต์ (Draft)`

### 9.4 รูปประโยคนิยาม

* ✅ `X (english) หมายถึง …`
* ❌ `X คือ…` แบบห้วน · `เราเรียกสิ่งนี้ว่า…` · `พูดง่าย ๆ ว่า…` · `ลองนึกภาพว่า…` (ใช้ได้เฉพาะย่อหน้าเปิดหัวข้อ ไม่เกิน 1 ครั้ง)

### 9.5 สำนวนบล็อกและสำนวนแปลที่หลุดเข้าตำราบ่อย

| ❌ | ✅ |
| :--- | :--- |
| ตัวเลขชุดนี้เล่าเรื่อง… | ตัวเลขชุดนี้แสดงความสัมพันธ์… |
| บทเรียนแรกคือ / บทเรียนที่สองคือ | ข้อแรกคือ / ข้อที่สองคือ |
| เป็นกุญแจของ… | เป็นพื้นฐานของ… |
| เครื่องมือที่ยิงตรงเป้า / พุ่งเป้า | เครื่องมือที่มุ่งไปยังต้นตอของปัญหาโดยตรง |
| ผลของนโยบายเดินทางถึง… | ผลของนโยบายส่งถึง… |
| อ่านเอกสารทีละบรรทัด | พิจารณาเอกสารโดยละเอียด |
| เหตุการณ์ที่หน้าตาคล้ายกัน | เหตุการณ์ที่มีลักษณะคล้ายกัน |
| เชิงวิพากษ์ (ใช้พร่ำเพรื่อ) | ใช้เมื่อวิพากษ์จริงเท่านั้น |

คำเชื่อมที่ตำราไทยใช้จริง: `ดังนั้น` `ทั้งนี้` `กล่าวคือ` `นั่นหมายความว่า` `จะเห็นว่า`
`ได้แก่` `ดังนี้` `เนื่องจาก` `อย่างไรก็ตาม` `ในทางกลับกัน`

### 9.6 หัวข้อย่อยเป็นวลีนาม

* ✅ `ปัจจัยที่กำหนดอุปสงค์` · `ความหมายของภาษีอากร` · `โครงสร้างต้นทุนในระยะสั้น`
* ❌ `ทำไมเส้นต้นทุนจึงเป็นรูปตัวยู` · `มาดูโครงสร้างต้นทุนกัน`

### 9.7 ภาษาเขียนกับภาษาพูด 🔴 ร้ายแรงที่สุดสำหรับตำรา

> เพิ่มเมื่อ 8 กันยายน 2569 จากการตรวจร่างตำราจริง 5 บท พบคำภาษาพูดตกค้างประมาณ 65 จุด
> ทั้งที่ร่างผ่านด่าน 9.1–9.6 หมดแล้ว แปลว่าด่านเดิมไม่ครอบคลุมเรื่องนี้

**เขียนคือเขียน พูดคือพูด** ตำราเป็นงานเขียนที่เป็นทางการที่สุดในบรรดางานของผู้เขียน
กรรมการประเมินผลงานทางวิชาการจับจุดนี้ก่อนจุดอื่นเสมอ เพราะเห็นได้โดยไม่ต้องอ่านเนื้อหา
และคำภาษาพูดหลุดมา **ทีละคำ** ไม่ได้หลุดทั้งย่อหน้า การอ่านทวนรวมจึงจับไม่ได้ ต้องค้นทีละคำ

#### ก. บัญชีคำภาษาพูดต้องห้ามในเนื้อความตำรา — เพดาน 0

| ❌ คำภาษาพูด | ✅ ภาษาเขียนที่ใช้แทน |
| :--- | :--- |
| เท่าไร · เท่าไหร่ | เท่าใด · เพียงใด · ในระดับใด · จำนวนเท่าใด |
| แค่ไหน · มากแค่ไหน | เพียงใด · มากน้อยเพียงใด · ในระดับใด |
| กี่ (กี่ชาม กี่บาท ในเนื้อความ) | จำนวนเท่าใด (คงไว้ได้เฉพาะในโจทย์แบบฝึกหัด) |
| อยากรู้ · อยากทราบ | ต้องการทราบ · ประเด็นที่ต้องพิจารณาคือ |
| ก็ (กลางประโยคแบบพูด: ราคาก็ลดลง · ก็จะกลายเป็น · ก็ยังคง) | ตัดทิ้ง หรือใช้ `จึง` `ย่อม` `ยังคง` |
| ก็คือ | คือ · กล่าวคือ · ได้แก่ |
| ก็ต่อเมื่อ | เมื่อ… เท่านั้น · ต่อเมื่อ |
| หมายความว่า (ขึ้นต้นประโยค) | นั่นหมายความว่า · กล่าวคือ · แสดงว่า |
| ทำให้เห็นว่า | แสดงให้เห็นว่า · ชี้ให้เห็นว่า |
| กว่าจะ | จนกระทั่ง · ก่อนที่จะ |
| นั่นเอง · นั่นแหละ | ตัดทิ้ง |
| ด้วยซ้ำ · แถม · อีกต่างหาก | ตัดทิ้ง หรือ `ยิ่งไปกว่านั้น` |
| ค่อนข้าง · พอสมควร · ไม่ค่อย | ระบุปริมาณจริง หรือตัดทิ้ง |
| เยอะ · นิดหน่อย · แค่ · เลย | จำนวนมาก · เล็กน้อย · เพียง · ตัดทิ้ง |
| ขนาดนั้น · ตรงนี้ · ตรงนั้น | ในระดับดังกล่าว · ในประเด็นนี้ · ในส่วนดังกล่าว |
| ไม่ได้หายไปไหน | มิได้สูญหายไป · ยังคงอยู่ในระบบ |
| อะไรบางอย่าง | ปัจจัยบางประการ · สิ่งใดสิ่งหนึ่ง |
| ยังไง · แบบไหน · พวก… | อย่างไร · ลักษณะใด · กลุ่ม… |
| จริง ๆ · เอาเข้าจริง · ที่จริงแล้ว | ตัดทิ้ง หรือ `ในความเป็นจริง` |
| ลองนึกภาพ · ลองคิดดูว่า · เรามาดูกัน | พิจารณากรณี… · ตัวอย่างเช่น |
| เจอ · โดน · เอามา | พบ · ได้รับ · นำมา |
| แล้วก็ · พอ…ก็ · ทีนี้ | และ · เมื่อ… จึง · ลำดับต่อไป |

#### ข. ข้อยกเว้น ห้ามแก้

* ข้อความยกมาตรงพร้อมอัญประกาศ และถ้อยคำของแบบฟอร์มราชการ
* ชื่อเฉพาะ ชื่อโครงการ ชื่อหลักสูตร
* คำที่หน้าตาเหมือนกันแต่คนละคำ — `เก็บ` `คุณภาพ` `คุณสมบัติ` `แบบฝึกหัด` `รูปแบบ` `พอดี` `ชนิด`
  (ค้นด้วยคำเปล่าจะได้ผลบวกลวงจากคำเหล่านี้เสมอ ต้องดูบริบททุกจุด)
* โจทย์แบบฝึกหัดที่จำเป็นต้องใช้รูปคำถามธรรมชาติ ใช้ได้แต่ต้องสม่ำเสมอทั้งเล่ม

#### ค. คำเชื่อมที่ตำราไทยใช้จริง

`ดังนั้น` · `ทั้งนี้` · `กล่าวคือ` · `นั่นหมายความว่า` · `จะเห็นว่า` · `ได้แก่` · `ดังนี้` ·
`เนื่องจาก` · `อย่างไรก็ตาม` · `ในทางกลับกัน` · `สำหรับ` · `ส่วน` · `จึง` · `ย่อม`

### 9.8 เพิ่มเข้า Pre-Delivery Language Audit (ข้อ 6)

เมื่องานเป็นประเภทตำรา ให้เพิ่ม 5 บรรทัดนี้ในบัตรตรวจทุกหัวข้อย่อย

```
[TEXTBOOK-VOICE-AUDIT]
วลีที่พูดกับผู้สอนนอกใบปะ   : ต้องเป็น 0
คำภาษาพูดตามบัญชี 9.7 ก.   : ต้องเป็น 0 — ระบุคำที่ตรวจแล้วและจำนวนที่พบ
คำเรียกผู้อ่าน              : ใช้คำเดียวทั้งเล่ม ระบุคำที่ใช้
วงเล็บอังกฤษขึ้นต้นตัวเล็ก  : ต้องเป็น 0 (ยกเว้นตัวย่อ เช่น f.o.b.) · วงเล็บซ้ำในบท: 0
ชื่อหัวข้อส่วนท้ายบท        : ตรงกับสารบัญต้นฉบับของผู้เขียน ใช่/ไม่ใช่
```

🔴 บรรทัด "คำภาษาพูด" ห้ามรายงานว่าผ่านโดยไม่ได้ค้นจริง ต้องค้นทีละคำจากบัญชี 9.7 ก.
ก่อนส่งทุกหัวข้อย่อย ไม่ใช่ตรวจตอนปิดบท เพราะแก้ตอนปิดบทจะพลาดและเสียเวลากว่ามาก
