## 🎯 0. เข้าใจก่อนว่า "ติด" มีกี่แบบ

เครื่องตรวจมี 2 ตระกูล คนละเรื่องกัน แต่มักถูกเรียกรวมเป็นคำเดียวว่า "ติด"

| ตระกูล | ตัวอย่างเครื่องมือ | ตรวจอะไร | ตรวจภาษาไทยได้ไหม |
| :--- | :--- | :--- | :--- |
| **ความซ้ำ (Similarity / Plagiarism)** | Turnitin Similarity, อักขราวิสุทธิ์, iThenticate, CopyCatch | ข้อความที่ตรงกับคลังเอกสารเดิม | **ได้เต็ม** — นี่คือความเสี่ยงจริงของเนื้อไทย |
| **การเขียนด้วย AI (AI Writing Detection)** | Turnitin AI Writing | รูปแบบภาษาที่โมเดลมักผลิต | **ยังไม่รองรับภาษาไทย** รองรับอังกฤษ ญี่ปุ่น สเปน (กลุ่ม AI-paraphrased รองรับอังกฤษอย่างเดียว ไม่เกิน 30,000 คำ) |

**ข้อสรุปที่ตามมา 3 ข้อ**

1. **เนื้อไทยไม่ได้ถูกให้คะแนน AI แต่ถูกให้คะแนนความซ้ำเต็ม ๆ** — ถ้าจะกลัวเลข ให้กลัวเลขความซ้ำก่อน
2. **จุดที่ถูกตรวจ AI จริงคือส่วนภาษาอังกฤษ** ได้แก่ บทคัดย่อภาษาอังกฤษ ชื่อเรื่องภาษาอังกฤษ และ manuscript ที่ส่งวารสารต่างประเทศ
3. **เส้นทางที่โดนจับบ่อยที่สุดคือ ร่างอังกฤษก่อนแล้วให้ AI แปลเป็นไทย** เพราะได้ทั้งภาษาไทยที่อ่านเป็นสำนวนแปล และคู่ภาษาอังกฤษที่ถูกให้คะแนนได้

> **ที่มาของข้อมูลขอบเขตเครื่องตรวจ**: อินโฟกราฟิก “AI writing detection” โดย CMMU Library ห้องสมุด วิทยาลัยการจัดการ มหาวิทยาลัยมหิดล (library.cm.mahidol.ac.th) — สำเนาเก็บไว้ที่ [AI Detection 2026.jpeg](AI%20Detection%202026.jpeg)

### 0.3 เครื่องตรวจผิดพลาดได้ และผิดพลาดกับผู้เขียนแบบไหนบ่อยที่สุด

ก่อนจะกลัวเลข ต้องรู้ว่าเลขนั้นเชื่อได้แค่ไหน

* **ผู้เขียนที่ไม่ใช่เจ้าของภาษาอังกฤษถูกธงผิดมากที่สุด** งานของ Liang และคณะ (2023) ทดสอบเครื่องตรวจ 7 ตัวกับเรียงความ TOEFL พบผลบวกลวงราวร้อยละ 61 ขณะที่เรียงความของนักเรียนเจ้าของภาษาเกือบไม่ถูกธงเลย ผู้วิจัยสรุปว่าเครื่องตรวจ "อาจลงโทษผู้เขียนที่มีการแสดงออกทางภาษาจำกัดโดยไม่ตั้งใจ" และเตือนไม่ให้ใช้ในบริบทประเมินผล
* **เหตุผลเชิงกลไก**: เครื่องตรวจวัดความคาดเดาได้ของถ้อยคำ คำศัพท์เรียบและโครงประโยคตรงไปตรงมาจึงถูกอ่านว่าเป็นภาษาเครื่อง ทั้งที่เป็นลักษณะปกติของผู้เขียนภาษาที่สอง
* **Turnitin ระบุเองว่าคะแนนไม่ใช่คำตัดสิน** เป็นเพียงข้อมูลประกอบดุลยพินิจ ห้ามใช้เป็นฐานเดียวในการลงโทษ และช่วงคะแนน 0–20 มีผลบวกลวงสูงกว่าช่วงอื่นจนระบบต้องติดเครื่องหมาย `*` กำกับว่าเชื่อถือได้น้อยลง

**สิ่งที่ต้องทำตั้งแต่วันแรก ไม่ใช่ตอนโดนธง — เก็บหลักฐานกระบวนการเขียน**

1. เขียนในไฟล์ที่มี **ประวัติการแก้ไข** (Google Docs หรือ Word ที่เปิด version history) ห้ามพิมพ์ที่อื่นแล้ววางทีเดียวจบ
2. เก็บ **โน้ตย่อจากการอ่าน** ที่เขียนก่อนร่างจริงตามขั้นตอนข้อ 1 ไว้เป็นไฟล์แยก
3. เก็บ **ร่างระหว่างทาง** อย่างน้อย 2–3 รอบ พร้อมวันที่
4. ถ้าใช้ AI ช่วยจุดใด บันทึก prompt และผลลัพธ์ไว้ — วารสารไทยบางฉบับเรียกดูจริง (ดูข้อ 8.7)

หลักฐานชุดนี้คือสิ่งเดียวที่ใช้ยืนยันได้เมื่อถูกธงผิด การไปแก้ถ้อยคำให้ "ดูเหมือนคนเขียน" ไม่ใช่ทางออก และเข้าข่ายกลุ่ม AI-bypassed ตามหัวข้อถัดไป

### 🚫 สิ่งที่ไฟล์นี้ไม่ทำ

ไม่มีเทคนิคหลบเครื่องตรวจอยู่ในไฟล์นี้ และห้ามใช้ทุกกรณี — โยกคำ สลับคำ แทนอักขระยูนิโค้ดหน้าตาคล้ายกัน แทรกอักษรสีขาว ปั่นคำด้วยเครื่องมือ paraphrase ทั้งหมดนี้จัดอยู่ในกลุ่ม **AI-bypassed** ซึ่งเป็นหมวดที่เครื่องตรวจแยกจับไว้โดยเฉพาะ และเป็นความผิดทางจริยธรรมวิจัยอีกกระทงหนึ่ง

**ทางเดียวที่ทำให้เลขต่ำอย่างถาวรคือเนื้อหาเป็นของผู้เขียนจริง** — อ่านให้เข้าใจ แล้วเขียนใหม่ด้วยภาษาตัวเอง พร้อมอ้างอิงครบ ไฟล์นี้คือวิธีทำแบบนั้นให้เป็นระบบ ไม่ใช่วิธีหลบ

> **พูดกันตรง ๆ**: ไม่มีใครรับประกันเลข 0 ให้ได้ เพราะเกณฑ์ของแต่ละสถาบันและคลังเอกสารเทียบของแต่ละระบบต่างกัน สิ่งที่รับประกันได้คืองานที่ผ่านด่านในไฟล์นี้จะไม่มีข้อความที่ไม่ใช่ของผู้เขียนหลุดไปโดยไม่ตั้งใจ

## ✍️ 1. กฎเขียนไทยจากศูนย์ (Native Thai Draft Rule)

**ห้ามแปลประโยคต่อประโยค** ทั้งจากต้นฉบับภาษาอังกฤษ และจากโครงภาษาอังกฤษที่ร่างไว้ในหัว

### ขั้นตอนบังคับเมื่อต้นฉบับเป็นภาษาอังกฤษ

1. **อ่านให้จบย่อหน้าหรือจบหัวข้อ** ไม่ใช่อ่านทีละประโยค
2. **สรุปใจความเป็นไทยสั้น ๆ 1–2 บรรทัดก่อน** ว่าตรงนี้เขาบอกอะไร
3. **ปิดต้นฉบับ** แล้วเขียนขยายจากใจความนั้นด้วยโครงประโยคไทย
4. **เปิดกลับไปตรวจ** ว่าสาระตรงหรือไม่ ตัวเลขถูกหรือไม่ — ตรวจสาระ ไม่ใช่ตรวจถ้อยคำ
5. **ใส่นาม-ปี** ทุกใจความที่มาจากต้นฉบับ

### สัญญาณว่ากำลังแปลอยู่ ไม่ได้เขียนอยู่

* ประโยคไทยยาวเกิน 40 คำ มีอนุประโยคซ้อนสามชั้น
* ขึ้นต้นด้วย "มันเป็นที่ชัดเจนว่า" "เป็นที่ทราบกันดีว่า" "สิ่งนี้แสดงให้เห็นว่า"
* ใช้ "ซึ่ง" เกินหนึ่งครั้งในประโยคเดียว
* ใช้ "โดย" ต่อท้ายทุกประโยคเพื่อลากอนุประโยคต่อ
* เรียง ประธาน–กริยา–กรรม–ส่วนขยาย ตามอังกฤษเป๊ะทั้งย่อหน้า
* คำชี้เฉพาะ "สิ่งนี้" "ดังกล่าว" เกาะต้นประโยคทุกประโยค (ไทยละได้ อังกฤษละไม่ได้)

## 🔤 2. ด่านศัพท์เฉพาะ (Terminology Gate) — จุดที่พังบ่อยที่สุด

### 2.1 ลำดับความน่าเชื่อถือของคำแปล ห้ามข้ามขั้น

```text
1. ศัพท์บัญญัติของสำนักงานราชบัณฑิตยสภา
2. คำที่วารสาร TCI สาขานั้นใช้จริง (ยืนยันจากเปเปอร์ที่แนบมา 2 ชิ้นขึ้นไป)
3. คำที่ตำราหลักของสาขาใช้
4. ทับศัพท์ + วงเล็บอังกฤษครั้งแรก
5. แปลเอง  ← ทางเลือกสุดท้าย และต้องแจ้งผู้ใช้ว่าเป็นคำที่เสนอเอง
```

**ค้นขั้นที่ 1 ได้ที่ไหน**: ฐานศัพท์บัญญัติ 40 สาขาวิชา สำนักงานราชบัณฑิตยสภา <https://coined-word.orst.go.th/> — ค้นก่อนเสมอ ห้ามข้ามไปเดาคำแปลเอง

**กฎเหล็ก**: ถ้าไม่มีหลักฐานจากขั้น 1–3 ให้ **ทับศัพท์** ห้ามเดาคำแปลแล้วเขียนลงไปเงียบ ๆ — คำแปลที่เดาเองคือจุดที่กรรมการจับได้เร็วที่สุด และแก้ทีหลังยากเพราะกระจายไปทั้งเล่มแล้ว

### 2.2 กฎวงเล็บภาษาอังกฤษ 5 ข้อ

1. **ครั้งแรกครั้งเดียวต่อบท** — ปรากฏครั้งแรกใส่วงเล็บ ครั้งต่อไปใช้คำไทยล้วนตลอดบท
2. **ห้ามใส่วงเล็บกับคำสามัญ** — การเรียนรู้ การพัฒนา ความสำเร็จ การจัดการ ความสัมพันธ์ ไม่ต้องมีวงเล็บอังกฤษ ใส่แล้วอ่านเหมือนเอกสารแปล
3. **ใส่เฉพาะเมื่อผู้อ่านต้องใช้คำนั้นไปค้นต่อ** หรือเมื่อคำไทยมีหลายสำนวนจนกำกวม
4. **วงเล็บใส่รูปฐาน ไม่ใส่รูปผัน** — เขียน (self-regulated learning) ไม่ใช่ (self-regulated learnings)
5. **ตัวพิมพ์เล็กทั้งหมด ยกเว้นวิสามานยนาม** — (cognitive load) ไม่ใช่ (Cognitive Load) ส่วนชื่อทฤษฎีและชื่อบุคคลขึ้นต้นตัวใหญ่ตามปกติ

> **เพดานเชิงปริมาณ**: ในหนึ่งหัวข้อย่อย วงเล็บอังกฤษไม่ควรเกิน **5 คำ** ถ้าเกิน แปลว่ากำลังเขียนอภิธานศัพท์ ไม่ได้เขียนความเรียง ให้ยกส่วนเกินไปไว้ที่นิยามศัพท์เฉพาะบทที่ 1 หรือดัชนีคำค้นท้ายเล่ม

### 2.3 กฎหนึ่งความหมาย หนึ่งคำไทย

ล็อกคำตั้งแต่หัวข้อแรก แล้วใช้คำเดิมตลอดทั้งเล่ม ห้ามสลับ

```text
[GLOSSARY-LOCK]
english term | คำไทยที่ล็อก | ที่มาของคำ (ราชบัณฑิต / วารสาร / ตำรา / ทับศัพท์)
```

ตัวอย่างการสลับที่ต้องกันไว้ก่อน: ผู้เรียน↔นักเรียน↔นักศึกษา↔ผู้เข้าร่วม · รูปแบบ↔ตัวแบบ↔แบบจำลอง · สมรรถนะ↔ความสามารถ↔ศักยภาพ · การประเมิน↔การประเมินผล↔การวัดผล

### 2.4 ตารางกับดักคำแปลตรงตัว (Exact-Match Traps)

คอลัมน์กลางคือคำที่มักถูกหยิบมาใช้โดยไม่ดูบริบท

| English | คำที่มักแปลผิด | คำที่ถูกตามบริบทวิชาการ |
| :--- | :--- | :--- |
| significant | มีนัยสำคัญ (ใช้ทุกที่) | บริบทสถิติ = มีนัยสำคัญทางสถิติ · บริบททั่วไป = สำคัญ / มาก / ชัดเจน |
| validity | ความถูกต้อง | ความตรง (content validity = ความตรงเชิงเนื้อหา) |
| reliability | ความน่าเชื่อถือ | ความเที่ยง / ความเชื่อมั่นของเครื่องมือ |
| accuracy | ความเที่ยง | ความแม่นยำ |
| self-efficacy | ประสิทธิภาพแห่งตน | การรับรู้ความสามารถของตนเอง |
| purposive sampling | การสุ่มแบบเจาะจง | การเลือกกลุ่มตัวอย่างแบบเจาะจง (ไม่ใช่การสุ่ม) |
| subject / participant | หัวข้อ / วิชา | ผู้เข้าร่วมการวิจัย / กลุ่มตัวอย่าง |
| instrument | เครื่องมือ (ลอย ๆ) | เครื่องมือที่ใช้ในการวิจัย |
| item | รายการ | ข้อคำถาม (ในแบบสอบถาม/แบบทดสอบ) |
| rating scale | สเกลการให้คะแนน | มาตรประมาณค่า |
| effect size | ขนาดผล | ขนาดอิทธิพล |
| correlation | ความสัมพันธ์ | สหสัมพันธ์ (relationship = ความสัมพันธ์) |

### 2.5 คำที่ทับศัพท์ได้ กับคำที่ห้ามทับศัพท์

* **ทับศัพท์ได้**: ชื่อเทคโนโลยีและแพลตฟอร์ม (แพลตฟอร์ม แอปพลิเคชัน อัลกอริทึม) · หน่วยวัด · ชื่อค่าสถิติที่ไทยไม่มีคำใช้จริง
* **ห้ามทับศัพท์**: คำที่มีศัพท์บัญญัติใช้แพร่หลายแล้ว — ห้ามเขียน คอนเทนต์ แทน เนื้อหา / เอาต์พุต แทน ผลผลิต / อิมพลีเมนต์ แทน การนำไปใช้
* **ชื่อบุคคลและชื่อทฤษฎี**: ชื่อบุคคลคงรูปอังกฤษในวงเล็บอ้างอิงเสมอ · ชื่อทฤษฎีใช้ชื่อไทยที่วงการใช้ + วงเล็บอังกฤษครั้งแรก
* **อักษรย่อ**: ครั้งแรกเขียน `คำไทยเต็ม (English Full Form, ABBR)` ครั้งต่อไปใช้ `ABBR` อย่างเดียว
* **อักษรย่อหน่วยวัดในเนื้อความภาษาไทยให้ใช้รูปย่อไทย** — ซม. ลบ.ม. กก. มล. ไม่ใช่ cm m³ kg ml และต้องใช้รูปเดียวกันตลอดทั้งเล่ม (ตามแนวปฏิบัติของสำนักพิมพ์ทางวิชาการไทย)

## 🧯 3. ลายนิ้วมือภาษาเครื่องในภาษาไทย (Thai AI-Tells)

ต่อให้เครื่องตรวจยังไม่ให้คะแนนภาษาไทย กรรมการและบรรณาธิการอ่านออก และมันคือสัญญาณว่าผู้เขียนยังไม่ได้คิดเอง

**ทำไมการให้ AI เกลาภาษาถึงผลักสำนวนไปทางเดียวกันหมด** งานทดลองข้ามวัฒนธรรมของ Agarwal, Naaman และ Vashistha (CHI 2025) กับผู้เข้าร่วม 118 คนจากอินเดียและสหรัฐอเมริกา พบว่าข้อเสนอแนะจาก AI ทำให้ผู้เข้าร่วมชาวอินเดียเขียนแบบตะวันตกมากขึ้น **เปลี่ยนทั้งสิ่งที่เขียนและวิธีเขียน** และลดความต่างทางวัฒนธรรมในภาษาลง สอดคล้องกับรายงานที่ว่างานที่ผ่านการปรับด้วย AI มีไวยากรณ์ดีขึ้นแต่สำนวนเหมือนกันไปหมด รวมถึงคำสั่งประเภท "แก้แค่ไวยากรณ์" ที่ยังทำให้ความหมายเคลื่อนไปทางทางการและไร้ตัวตนมากขึ้น

ข้อ 1 ถึงข้อ 3 ของไฟล์นี้จึงไม่ใช่เรื่องรสนิยม แต่เป็นการกันแรงดึงที่มีอยู่จริงในเครื่องมือ — **ถ้าปล่อยให้ AI เกลาโดยไม่คุมกรอบ ผลลัพธ์จะเลื่อนไปหาโครงสร้างประโยคภาษาอังกฤษเสมอ ไม่ว่าจะสั่งให้เกลาน้อยแค่ไหน**

### 3.1 วลีต้องห้าม ใช้ได้ไม่เกิน 1 ครั้งต่อบท

| กลุ่ม | ตัวอย่างที่ต้องเลิกใช้ |
| :--- | :--- |
| เปิดย่อหน้าลอย | "ในโลกยุคปัจจุบันที่มีการเปลี่ยนแปลงอย่างรวดเร็ว" · "ในยุคดิจิทัลที่เทคโนโลยีเข้ามามีบทบาท" |
| ยกความสำคัญลอย | "มีบทบาทสำคัญอย่างยิ่ง" · "ถือเป็นสิ่งที่มีความสำคัญเป็นอย่างมาก" · "นับเป็นหัวใจสำคัญ" |

| ปิดย่อหน้าสำเร็จรูป | "…ได้อย่างมีประสิทธิภาพและประสิทธิผล" · "…อย่างยั่งยืนต่อไปในอนาคต" |

### 3.2 ลายนิ้วมือเชิงโครงสร้าง

* ทุกย่อหน้ายาวเท่ากัน หรือมีสามประโยคเท่ากันหมด
* ทุกรายการแตกเป็นสามข้อพอดี ทั้งที่ต้นฉบับไม่ได้ระบุจำนวน
* ทุกหัวข้อย่อยปิดด้วย "โดยสรุป" หรือ "กล่าวโดยสรุปได้ว่า"
* ทุกย่อหน้าเปิดด้วยโครง "การ…เป็น…" เหมือนกันหมด
* ใช้ยัติภังค์ยาว — และหัวข้อ bullet แทรกกลางความเรียง (ความเรียงวิชาการไทยไม่ใช้)
* ทุกประโยคสมบูรณ์และยาวพอกัน ไม่มีประโยคสั้นไว้เน้น

### 3.3 กฎความแปรผัน (Burstiness Rule) — ทำตรงข้ามกับข้อ 3.2

* **ความยาวประโยค**: ในหนึ่งย่อหน้าต้องมีประโยคสั้น 8–15 คำ อย่างน้อย 1 ประโยค และประโยคยาว 30–45 คำ อย่างน้อย 1 ประโยค
* **ความยาวย่อหน้า**: สลับ 3–9 ประโยค ห้ามยาวเท่ากันติดกันเกิน 2 ย่อหน้า
* **จำนวนข้อในรายการ**: ตามที่ต้นฉบับระบุจริง — ต้นฉบับบอก 4 ด้าน ต้องเป็น 4 ข้อ ห้ามยุบเหลือ 3 เพื่อความสวย
* **คำเชื่อม**: หมุนคลังคำ — สอดคล้องกับ / ในทางกลับกัน / ต่างจาก / เมื่อพิจารณาร่วมกับ / แม้กระนั้น / ในทำนองเดียวกัน / อย่างไรก็ตาม — ห้ามใช้คำเดิมซ้ำภายใน 3 ย่อหน้า
* **กริยารายงาน**: หมุนเวียน — ได้ให้ความหมายว่า / อธิบายว่า / เสนอแนวคิดว่า / นิยามว่า / ได้ศึกษา / ระบุว่า / ชี้ให้เห็นว่า / โต้แย้งว่า / พบว่า

## 🔒 4. ด่านคุมความซ้ำ (Similarity Control) — ความเสี่ยงจริงของเนื้อไทย

1. **เพดานวลีต่อเนื่อง**: ห้ามใช้ถ้อยคำต่อเนื่องจากต้นฉบับเกิน **8 คำติดกัน** โดยไม่ใส่อัญประกาศ ถ้าจำเป็นต้องใช้ถ้อยคำเดิม ให้ยกมาตรงในเครื่องหมาย " " พร้อมเลขหน้า
2. **นิยามศัพท์คือจุดติดสูงสุด** เพราะทุกเล่มลอกนิยามเดียวกัน วิธีที่ถูกคือสังเคราะห์จาก **3 แหล่งขึ้นไป** ชี้จุดร่วมจุดต่าง แล้วปิดท้ายด้วยนิยามเชิงปฏิบัติการของผู้วิจัยเอง
3. **บทที่ 3 ระเบียบวิธีวิจัยติดสูงเป็นธรรมดา** เพราะประโยคมาตรฐานและชื่อสถิติซ้ำกันทั้งวงการ ลดได้ด้วยการเขียนบริบทของงานตัวเองแทนการลอกนิยามระเบียบวิธี
4. **บทที่ 5 อภิปรายผลห้ามติดเด็ดขาด** เป็นส่วนที่ต้องเป็นความคิดผู้วิจัยล้วน ถ้าตรวจแล้วพบความซ้ำในส่วนนี้ สำนักพิมพ์และวารสารปฏิเสธได้ทันที
5. **ย่อหน้าสรุปสังเคราะห์** เขียนเป็นภาษาผู้วิจัยล้วน ห้ามใส่นาม-ปีซ้ำ และห้ามทวนถ้อยคำจากบล็อกด้านบน
6. **ตารางและภาพที่ดัดแปลงมา** ต้องระบุที่มาใต้ตารางและใต้ภาพเสมอ

## 🌐 5. ส่วนภาษาอังกฤษ — จุดเดียวที่ถูกให้คะแนน AI จริง

ใช้กับบทคัดย่อภาษาอังกฤษ ชื่อเรื่องภาษาอังกฤษ และ manuscript ที่ส่งวารสารนานาชาติ

1. **ห้ามแปลบทคัดย่อไทยเป็นอังกฤษแบบประโยคต่อประโยค** ให้เขียนใหม่จากโครง Purpose / Method / Results / Conclusion โดยใช้ตัวเลขจริงจากงาน
2. **แจ้งผู้ใช้ทุกครั้งก่อนส่งมอบส่วนภาษาอังกฤษ** ว่านี่คือส่วนที่เครื่องตรวจ AI ให้คะแนนได้จริง และผู้เขียนต้องอ่านทวนแล้วปรับถ้อยคำด้วยตัวเองก่อนส่ง
3. **ห้ามใช้เครื่องมือ paraphrase อัตโนมัติ** กับส่วนนี้ เพราะเข้าเกณฑ์กลุ่ม AI-paraphrased ที่ตรวจจับได้โดยตรง
   3.1 **ถ้าใช้ AI ช่วยแปลอย่างมีนัยสำคัญ ต้องเปิดเผยด้วย** ไม่ใช่แค่เขียนใหม่ให้ดี — ดูเกณฑ์รายสำนักพิมพ์และแม่แบบข้อความเปิดเผยในข้อ 8
4. **คุมความยาวประโยคอังกฤษ** สลับสั้นยาวเช่นเดียวกับข้อ 3.3 และเลี่ยงวลีสำเร็จรูป: "plays a crucial role" · "in today's rapidly evolving landscape" · "it is worth noting that" · "delve into" · "comprehensive understanding"
5. **ศัพท์เฉพาะภาษาอังกฤษต้องตรงกับที่วารสารเป้าหมายใช้** ยืนยันจากเปเปอร์ในวารสารนั้น 2 ชิ้นขึ้นไป

## ✅ 6. ด่านตรวจก่อนส่งทุกหัวข้อย่อย (Pre-Delivery Language Audit)

1. เขียนจากความเข้าใจ ไม่ได้แปลประโยคต่อประโยค
2. ศัพท์เฉพาะทุกคำมาจากลำดับความน่าเชื่อถือขั้น 1–4 ไม่มีคำที่เดาเอง
3. วงเล็บอังกฤษไม่เกิน 5 คำ และทุกคำเป็นการปรากฏครั้งแรกของบท
4. ไม่มีวงเล็บอังกฤษกำกับคำสามัญ
5. คำที่ล็อกไว้ใน `[GLOSSARY-LOCK]` ไม่ถูกสลับเป็นคำอื่น
6. ไม่มีวลีต้องห้ามในข้อ 3.1
7. ความยาวประโยคและย่อหน้าแปรผันตามข้อ 3.3
8. ไม่มีวลีต่อเนื่องจากต้นฉบับเกิน 8 คำที่ไม่ได้ใส่อัญประกาศ

```text
ข้อความยกมาตรง: [n] แห่ง (ใส่อัญประกาศ + เลขหน้าครบ: ใช่/ไม่)
จุดที่ผู้เขียนต้องอ่านทวนเอง: [ระบุ / ไม่มี]
```

## 🧭 7. เมื่อผู้ใช้ขอให้ "ทำให้ไม่ติด AI"

ตอบตามนี้ ห้ามรับปากตัวเลข

1. อธิบายตารางในข้อ 0 ว่าเนื้อไทยไม่ได้ถูกให้คะแนน AI แต่ถูกให้คะแนนความซ้ำ
2. ชี้ว่าส่วนที่ต้องระวังจริงคือบทคัดย่อภาษาอังกฤษและ manuscript ภาษาอังกฤษ
3. เสนอสิ่งที่ทำให้ได้จริง คือด่านในข้อ 1–6 ของไฟล์นี้
4. ปฏิเสธเทคนิคหลบทุกชนิด พร้อมบอกเหตุผลว่ากลุ่ม AI-bypassed คือหมวดที่ถูกจับแยกไว้แล้ว
5. ถ้าผู้ใช้ยืนยันขอเทคนิคหลบ ให้ปฏิเสธสั้น ๆ แล้วเสนอการตรวจภาษาตามข้อ 6 แทน
6. ถ้าคำถามจริงคือ "ใช้ AI ช่วยได้แค่ไหนโดยไม่ผิดกติกา" ให้ข้ามไปตอบด้วยข้อ 8 เพราะเป็นคนละเรื่องกับเครื่องตรวจ

### 7.1 เมื่อผู้ใช้ถูกธงทั้งที่เขียนเอง

กรณีนี้เกิดจริงและเกิดกับผู้เขียนที่ไม่ใช่เจ้าของภาษาบ่อยที่สุดตามข้อ 0.3 **ห้ามแนะนำให้แก้ถ้อยคำเพื่อให้เลขลด** เพราะเท่ากับยอมรับผิดโดยไม่ได้ทำ และเข้าข่ายกลุ่ม AI-bypassed ให้ทำตามนี้แทน

1. ขอดูรายงานฉบับเต็มว่าเป็นคะแนนกลุ่มใด ความซ้ำหรือการเขียนด้วย AI และช่วงคะแนนเท่าไร — ถ้าอยู่ช่วง 0–20 ให้ชี้ว่าผู้ให้บริการเองระบุว่าช่วงนี้เชื่อถือได้น้อย
2. รวบรวมหลักฐานกระบวนการเขียนตามข้อ 0.3 คือประวัติการแก้ไขไฟล์ โน้ตย่อจากการอ่าน และร่างระหว่างทาง
3. เสนอให้ผู้เขียนอธิบายกระบวนการทำงานเป็นลายลักษณ์อักษรต่อกรรมการ พร้อมแนบหลักฐานข้อ 2
4. ถ้าเป็นคะแนนความซ้ำ ให้ไล่ดูรายจุดตามข้อ 4 ว่าเป็นนิยามศัพท์ ชื่อสถิติ หรือถ้อยคำที่ลอกมาจริง แล้วแก้เฉพาะจุดที่เป็นปัญหาจริง
5. ย้ำกับผู้ใช้ว่าคะแนนจากเครื่องตรวจไม่ใช่คำตัดสินว่าประพฤติมิชอบ ตามที่ผู้ให้บริการระบุไว้เอง

## 📜 8. นโยบายการใช้ AI ของสำนักพิมพ์ — ใช้ได้แค่ไหน ต้องแจ้งตรงไหน

ข้อ 0–7 ตอบว่า "เขียนอย่างไรให้เป็นภาษาของผู้เขียนจริง" ข้อนี้ตอบอีกคำถามที่ต่างกันคนละเรื่อง คือ **"ที่ใช้ AI ช่วยไปนั้น สำนักพิมพ์ยอมรับหรือไม่ และต้องเปิดเผยอย่างไร"** — เรื่องแรกคือคุณภาพภาษา เรื่องนี้คือจริยธรรมการตีพิมพ์ ผ่านข้อแรกแล้วยังตกข้อนี้ได้

### 8.1 หลักร่วมของทุกสำนักพิมพ์ 5 ข้อ

ทั้งหกสำนักพิมพ์ในข้อ 8.2 ต่างกันในรายละเอียด แต่ตรงกันหมดใน 5 ข้อนี้ ถ้าจำได้แค่ส่วนเดียว ให้จำส่วนนี้

1. **AI เป็นผู้แต่งไม่ได้** ทุกราย — เพราะการเป็นผู้แต่งผูกกับความรับผิดชอบที่มีแต่มนุษย์รับได้ และห้ามอ้างอิง AI ในฐานะผู้แต่งด้วย
2. **ผู้เขียนรับผิดชอบทุกถ้อยคำ** รวมถึงข้อความและรายการอ้างอิงที่ AI ร่างให้ ถ้าอ้างอิงผิดหรือไม่มีจริง ความผิดเป็นของผู้เขียนเต็ม ๆ
3. **ห้ามให้ AI สร้างหรือแก้ข้อมูล ผลการวิจัย และรายการอ้างอิง** — เข้าข่ายการปลอมแปลงข้อมูล ไม่ใช่เรื่องนโยบายการเขียนอีกต่อไป
4. **ขัดเกลาภาษาของตัวเอง = ไม่ต้องแจ้ง / สร้างเนื้อหาใหม่ = ต้องแจ้ง** เส้นแบ่งอยู่ตรงนี้แทบทุกราย
5. **นโยบายกลางเป็นเพียงพื้น วารสารรายฉบับตั้งเงื่อนไขเข้มกว่าได้** ต้องอ่าน Instructions for Authors ของวารสารเป้าหมายทุกครั้งก่อนส่ง

**เหนือสำนักพิมพ์ขึ้นไปอีกชั้นคือมาตรฐานกลางที่วารสารจำนวนมากอ้างต่อ**

* **COPE** ระบุว่า AI ลงเป็นผู้แต่งไม่ได้ เพราะรับผิดชอบต่องานไม่ได้ และไม่ใช่นิติบุคคลจึงประกาศผลประโยชน์ทับซ้อนและจัดการลิขสิทธิ์ไม่ได้ — จุดยืนเดียวกับ WAME และ JAMA Network
* **ICMJE** มีหัวข้อเฉพาะว่าด้วยการใช้ AI ในการตีพิมพ์ และกำหนดให้ผู้เขียนที่ใช้ AI ในการเขียนและจัดเตรียมต้นฉบับเปิดเผยใน **Materials and Methods** ว่าใช้เครื่องมือใดและใช้อย่างไร
* ประโยชน์ในทางปฏิบัติ: วารสารไทยและวารสารเล็กจำนวนมากไม่ได้เขียนนโยบายเอง แต่อ้างสองฉบับนี้ **ถ้าวารสารปลายทางไม่มีนโยบายของตัวเอง ให้ยึดสองฉบับนี้เป็นเกณฑ์**

### 8.3 เส้นที่ต่างกันจริง 3 จุด อย่าเหมารวม

1. **first draft**: Taylor & Francis และ Emerald ห้ามให้ AI ร่างส่วนใดของต้นฉบับโดยตรง ส่วน Elsevier และ SAGE เปิดให้ช่วยจัดโครงและงานสนับสนุนได้ถ้าเปิดเผย — **ตั้งวิธีทำงานแบบเดียวแล้วส่งได้ทุกวารสารไม่ได้ ต้องดูปลายทางก่อนลงมือ**
2. **ภาพ**: Springer Nature ไม่รับภาพจาก generative AI เลย · Elsevier ห้ามเฉพาะภาพงานวิจัยจริงและ graphical abstract แต่ให้ทำภาพอธิบายและภาพข้อมูลได้ · Wiley และ Taylor & Francis เปิดให้ทำภาพข้อมูลได้ในกรอบของตน
3. **การแปล**: Wiley ระบุชัดว่าการแปลอย่างมีนัยสำคัญต้องแจ้ง ซึ่งเกี่ยวตรงกับงานไทยที่แปลบทคัดย่อเป็นภาษาอังกฤษ — **ถ้าใช้ AI ช่วยแปลบทคัดย่อ ไม่ใช่แค่ต้องเขียนใหม่ตามข้อ 5 แต่ต้องแจ้งด้วย**

### 8.4 ความลับของต้นฉบับ — ข้อที่คนลืมบ่อยที่สุด

Springer Nature ห้ามอัปโหลดต้นฉบับที่ยังไม่ตีพิมพ์เข้าเครื่องมือ generative AI ส่วน SAGE และ Wiley ห้ามส่งข้อมูลลับและต้นฉบับที่รับมาทำหน้าที่ผู้ประเมินเข้าเครื่องมือ AI **การวางต้นฉบับทั้งฉบับลงในแชตเพื่อ "ช่วยตรวจภาษา" จึงผิดนโยบายได้ตั้งแต่ก่อนเขียนอะไรลงไป** โดยเฉพาะต้นฉบับของผู้อื่นที่รับมาประเมิน ห้ามเด็ดขาดทุกกรณี

### 8.5 แม่แบบข้อความเปิดเผย (Disclosure Statement)

**ภาษาไทย — วางไว้ท้ายบทความก่อนรายการอ้างอิง หรือในกิตติกรรมประกาศ**

```text

ในการจัดเตรียมต้นฉบับนี้ ผู้เขียนใช้ [ชื่อเครื่องมือ เวอร์ชัน] เพื่อ [ขอบเขตที่ใช้จริง
เช่น ขัดเกลาภาษาและความชัดเจนของข้อความที่ผู้เขียนเรียบเรียงไว้แล้ว] หลังการใช้เครื่องมือดังกล่าว
ผู้เขียนได้ตรวจทานและแก้ไขเนื้อหาทั้งหมดด้วยตนเอง และรับผิดชอบต่อเนื้อหาของบทความนี้ทั้งหมด
```

1. ระบุ **เวอร์ชัน** ด้วยเสมอ — Taylor & Francis และ Emerald เรียกร้องข้อนี้ตรง ๆ
2. เขียนขอบเขตให้จำเพาะ ห้ามใช้คำกว้างว่า "ช่วยเขียน" ให้บอกว่าช่วยตรงไหน ในขั้นตอนใด
3. ถ้าใช้ AI ในกระบวนการวิจัย เช่น วิเคราะห์ข้อมูล เขียนโค้ด จัดหมวดวรรณกรรม ให้เขียนใน **Methods** ไม่ใช่แค่กิตติกรรมประกาศ เพราะเป็นส่วนหนึ่งของวิธีวิจัยที่ต้องทำซ้ำได้
4. เก็บ prompt และบันทึกการใช้ไว้ ถ้าบรรณาธิการขอหลักฐาน ต้องแสดงได้

### 8.6 ด่านตรวจนโยบายก่อนส่ง (Policy Gate)

ใช้เมื่อผู้ใช้เตรียมส่งบทความ ต้องถามและบันทึกให้ครบ

1. **วารสารเป้าหมายคือฉบับใด สังกัดสำนักพิมพ์ใด** ถ้ายังไม่รู้ ให้ยึดเกณฑ์เข้มสุดในตาราง 8.2 ไว้ก่อน
2. **รอบนี้ AI แตะอะไรบ้าง** ภาษา / โครงเรื่อง / ร่างเนื้อหา / ทบทวนวรรณกรรม / แปล / โค้ด / ภาพ / วิเคราะห์ข้อมูล
3. เทียบรายการข้อ 2 กับช่อง "ห้าม" ของสำนักพิมพ์นั้น ถ้าตกช่องห้าม **ให้แก้ที่งาน ไม่ใช่แก้ที่ข้อความเปิดเผย**
4. เทียบกับช่อง "ต้องแจ้ง" แล้วเขียนข้อความเปิดเผยตามแม่แบบ 8.5 วางตำแหน่งให้ตรงตามที่สำนักพิมพ์กำหนด
5. เปิด Instructions for Authors ของวารสารฉบับนั้นอ่านทับอีกครั้ง เพราะรายฉบับเข้มกว่านโยบายกลางได้
6. ยืนยันว่าไม่มีการอัปโหลดต้นฉบับที่ยังไม่ตีพิมพ์ของผู้อื่นเข้าเครื่องมือ AI

```text
[POLICY-CHECK]
วารสาร / สำนักพิมพ์: [ชื่อ] — เกณฑ์ที่ใช้: [กลาง / รายฉบับ / เข้มสุดเพราะยังไม่ระบุ]
AI แตะส่วนใดบ้าง: [รายการ]
ตกช่องห้ามหรือไม่: [ไม่ / ตก: ข้อใด และแก้ที่งานอย่างไร]
ต้องแจ้ง: [ใช่/ไม่] — ตำแหน่ง: [Methods / Declaration ก่อนรายการอ้างอิง / Acknowledgements / cover letter]
เครื่องมือ + เวอร์ชันที่ระบุในข้อความเปิดเผย: [ระบุ]
อ่าน Instructions for Authors รอบล่าสุดเมื่อ: [วันที่]
```

### 8.7 วารสารไทยและ TCI

ยังไม่มีนโยบายกลางฉบับเดียวที่ผูกวารสารไทยทุกฉบับ วารสารในระบบ ThaiJO ทยอยประกาศนโยบายรายฉบับเอง โดยส่วนใหญ่รับหลักเดียวกับสากลคือ **AI เป็นผู้แต่งไม่ได้ และต้องเปิดเผยการใช้**

**ข้อควรรู้ที่สำคัญที่สุด: วารสารไทยหลายฉบับเข้มกว่าสำนักพิมพ์ระดับโลก** ตัวอย่างจริงสองฉบับ

| วารสาร | อนุญาตให้ใช้ AI ทำอะไร | ห้าม | การเปิดเผย |
| :--- | :--- | :--- | :--- |
| **วารสารวิทยาการเรียนรู้และศึกษาศาสตร์** (so07) | ตรวจแก้ภาษา ไวยากรณ์ ความอ่านง่าย · ตรวจการคัดลอก · จัดการรายการอ้างอิง | สร้างเนื้อหาทั้งหมด ข้อความ ภาพ เสียง ตาราง · ลง AI เป็นผู้เขียนหรือผู้เขียนร่วม | ระบุใน **เชิงอรรถ**: ชื่อรุ่น เลขเวอร์ชัน ผู้ผลิต และ **ส่ง prompt กับ output ทั้งหมดให้วารสาร** · ห้ามนำต้นฉบับหรือข้อเสนอแนะของผู้ประเมินที่ยังไม่เผยแพร่เข้าเครื่องมือ AI |
| **PULINET Journal** (so14) | พิสูจน์อักษร ตรวจสะกด ตรวจไวยากรณ์ · จัดการอ้างอิง · ตรวจการคัดลอก | จัดทำเนื้อหาบทความ ทั้งบทคัดย่อ วรรณกรรมปริทัศน์ และผลวิจัย · วิเคราะห์ผลหรือเขียนผลลัพธ์ · สร้างหรือแก้ข้อมูล ภาพ ตาราง · ลง AI เป็นผู้เขียน | ระบุชื่อเครื่องมือ เวอร์ชัน ผู้ผลิต ใน **Methodology หรือเชิงอรรถ** และ **ส่ง prompt กับ output ให้บรรณาธิการ** |

สองฉบับนี้เรียก prompt และ output ทั้งชุด ซึ่ง Elsevier, Wiley และ SAGE ไม่ได้เรียก และเปิดให้ใช้ AI แคบกว่ามาก คือจำกัดอยู่ที่ระดับพิสูจน์อักษรและจัดการอ้างอิงเท่านั้น **จึงห้ามใช้เกณฑ์สากลมาตอบผู้ใช้ที่กำลังส่งวารสารไทย**

**สิ่งที่ต้องทำ**

* **ต้องเปิดหน้า "นโยบายการใช้ AI" ของวารสารไทยฉบับนั้นอ่านตรง ๆ ทุกครั้ง** ห้ามอนุมานจากวารสารฉบับอื่นในสถาบันเดียวกัน
* **เก็บ prompt กับ output ไว้ตั้งแต่วันแรกที่เริ่มใช้ AI** ไม่ใช่ไปรวบรวมย้อนหลังตอนวารสารเรียก เพราะรวบรวมย้อนหลังไม่ได้จริง
* **งาน ป.โท-ป.เอก มีกติกาซ้อนสองชั้น** คือประกาศของสถาบันกับนโยบายวารสารปลายทาง หลายมหาวิทยาลัยออกประกาศแนวปฏิบัติการใช้ AI ในช่วงปี 2568 แล้ว ให้เช็กประกาศฉบับล่าสุดของบัณฑิตวิทยาลัยทุกปีการศึกษา และยึดฉบับที่เข้มกว่า
* ถ้าวารสารยังไม่ประกาศนโยบาย ให้ยึดเกณฑ์เข้มสุดในตาราง 8.2 แล้วเปิดเผยไว้ ปลอดภัยกว่าเงียบ
* ความเสี่ยงหลักของต้นฉบับไทยยังเป็น **ความซ้ำ** ตามข้อ 4 ไม่ใช่คะแนน AI — ข้อ 8 นี้เพิ่มอีกชั้นหนึ่งคือเรื่องการเปิดเผย ไม่ได้มาแทนข้อ 4

### 8.8 คำตอบมาตรฐานเมื่อผู้ใช้ถามว่า "ใช้ AI เขียนบทความได้ไหม"

ตอบด้วยการแยกสามชั้นนี้เสมอ ห้ามตอบว่า "ได้" หรือ "ไม่ได้" ลอย ๆ

1. **ขัดเกลาภาษาที่ผู้เขียนเขียนเองแล้ว** ทุกสำนักพิมพ์รับ ส่วนใหญ่ไม่ต้องแจ้ง ยกเว้น Springer Nature ที่ให้แจ้งใน cover letter และ Emerald ที่ให้แจ้งตอนส่ง
2. **ช่วยสร้างเนื้อหา จัดโครง แปล ทบทวนวรรณกรรม วิเคราะห์ข้อมูล ทำภาพ** บางรายรับถ้าเปิดเผย บางรายห้าม ต้องเช็กรายสำนักพิมพ์ก่อนลงมือ ไม่ใช่ก่อนส่ง
3. **สร้างข้อมูล ผลการวิจัย อ้างอิง หรือภาพงานวิจัย** ห้ามทุกราย ไม่มีข้อยกเว้น และไม่มีข้อความเปิดเผยใดทำให้ถูกต้องได้

> **ประโยคปิดที่ใช้ได้ทุกกรณี**: AI ไม่ใช่ ghostwriter ผู้เขียนต้องเป็นเจ้าของความคิดและรับผิดชอบทุกข้อความ — ใช้ช่วยภาษาปลอดภัยที่สุด ใช้ช่วยสร้างเนื้อหาต้องตรวจนโยบายและเปิดเผยเสมอ

## 📕 9. น้ำเสียงตำราไทย (Thai Textbook Voice) — ใช้กับงานประเภทตำรา เอกสารประกอบการสอน และหนังสือวิชาการ

> เพิ่มเมื่อ 5 ก.ย. 2569 จากการถอดรูปแบบภาษาของตำราไทยระดับอุดมศึกษาจริง
> ข้อนี้ **ไม่ใช่เรื่องคำแปลผิด** แต่เป็นเรื่องน้ำเสียงที่ผิดประเภทงาน
> ต้นฉบับอ่านรู้เรื่องดี ไวยากรณ์ถูกทุกประโยค แต่กรรมการอ่านแล้วรู้ทันทีว่า "ไม่ใช่ตำรา"

### 9.0 ขั้นตอนบังคับก่อนเขียนบทแรก

1. ถามผู้ใช้ว่ามี **ตำราหรือเอกสารประกอบการสอนเดิม** ของตนเอง หรือตำราไทยในสาขาเดียวกันหรือไม่
2. ถ้ามี ให้เปิดอ่าน **สารบัญ + ย่อหน้าเนื้อความยาว 5 ย่อหน้า** ก่อนลงมือเขียน
3. ถอดออกมา 4 อย่าง แล้วยึดตามนั้นทั้งเล่ม
   * ชื่อหัวข้อประจำ (ส่วนท้ายบทเรียกว่าอะไร)
   * คำเรียกผู้อ่าน (นักศึกษา / ผู้เรียน / ผู้อ่าน)
   * รูปประโยคนิยาม
   * รูปแบบวงเล็บภาษาอังกฤษ (ตัวพิมพ์ใหญ่หรือเล็ก)
4. ถ้าไม่มีต้นฉบับให้ดูเลย ให้ใช้ค่าตั้งต้นในข้อ 9.1–9.5 นี้

### 9.1 ตำราไม่พูดกับผู้สอน 🔴 ผิดบ่อยที่สุด

ตำราเขียนถึง **ผู้อ่าน** ไม่ใช่คู่มือครู ประโยคที่สั่งการผู้สอนหรือบรรยายกิจกรรมในห้องเรียน
ต้องอยู่ใน **ใบปะแผนบริหารการสอน** เท่านั้น ห้ามหลุดเข้าเนื้อความ

| ❌ ห้ามใช้ในเนื้อความ | ✅ ใช้แทน |
| :--- | :--- |
| ควรชี้ให้ผู้เรียนเห็นว่า | ข้อสังเกตที่สำคัญคือ |
| ต้องย้ำกับผู้เรียนตั้งแต่ต้น | เป็นเรื่องที่ต้องทำความเข้าใจตั้งแต่ต้น |
| ประเด็นที่ควรอภิปรายกับผู้เรียน | ประเด็นที่ควรพิจารณาต่อ |
| ผู้สอนควร… | ตัดทิ้ง หรือเขียนเป็นข้อความบอกเล่า |
| ควรอภิปรายในชั้นเรียน | ควรนำมาพิจารณาประกอบ |
| ประเด็นนี้สำคัญมากในการสอน | ประเด็นนี้สำคัญมาก |

**วิธีตรวจเร็ว**: ค้นคำว่า `ผู้สอน` `ในชั้นเรียน` `ควรชี้ให้` `ย้ำกับ` ในไฟล์เนื้อหา
ถ้าเจอนอกใบปะ = ต้องแก้ทุกจุด

### 9.2 คำเรียกผู้อ่าน

ตำราไทยส่วนใหญ่ใช้ **นักศึกษา** ในเนื้อความ และใช้ **ผู้เรียน** เฉพาะในถ้อยคำมาตรฐานของ
ใบปะแผนบริหารการสอน (วัตถุประสงค์เชิงพฤติกรรม วิธีสอน การวัดและประเมินผล)
ตรวจกับต้นฉบับของผู้เขียนก่อน แล้วใช้คำเดียวกันทั้งเล่ม ห้ามสลับไปมา

### 9.3 วงเล็บภาษาอังกฤษใช้ตัวพิมพ์เล็ก

ตำราไทยเขียน `อุปสงค์ต่อราคา (price demand)` · `อำนาจซื้อ (purchasing power)`

## 👑 10. การอ้างอิงพระราชดำรัส พระราชดำริ และเอกสารที่เกี่ยวกับสถาบัน

> เพิ่มเมื่อ 5 ก.ย. 2569 จากการเขียนบทว่าด้วยปรัชญาของเศรษฐกิจพอเพียง
> ใช้กับทุกงานที่อ้างพระราชดำรัส พระราชดำริ โครงการอันเนื่องมาจากพระราชดำริ
> หรือปรัชญาที่มีที่มาจากพระราชดำริ

### 10.1 กฎเหล็ก 4 ข้อ

1. 🔴 **ห้ามแต่งข้อความพระราชดำรัสขึ้นเองโดยเด็ดขาด** ไม่ว่ากรณีใด
   ถ้าไม่มีเอกสารต้นฉบับอยู่ตรงหน้า ให้เว้นช่องไว้แล้วขอจากผู้ใช้
2. 🔴 **ห้ามเรียบเรียงใหม่แล้วใส่เครื่องหมายอัญประกาศ** การใส่อัญประกาศ
   หมายความว่าเป็นถ้อยคำตรงตามต้นฉบับทุกตัวอักษร
3. ✅ **ยกมาตรงได้เฉพาะจากเอกสารทางการ** พร้อมระบุ **วันที่พระราชทาน** และแหล่งที่พิมพ์เผยแพร่ทุกครั้ง
4. ✅ **การเรียบเรียงเนื้อความ** ทำได้ แต่ต้องระบุแหล่งที่มาและไม่ใส่อัญประกาศ

### 10.2 ข้อความที่ผ่านการประมวลและกลั่นกรองแล้ว

ปรัชญาหรือหลักการที่หน่วยงานของรัฐประมวลจากพระราชดำรัสหลายวโรกาส
แล้วได้รับพระราชทานพระบรมราชานุญาตให้เผยแพร่ ถือเป็น **ถ้อยคำฉบับทางการ**
ให้อ้างจากฉบับนั้น พร้อมระบุวันที่ได้รับพระราชทานพระบรมราชานุญาต
อย่าไปประมวลขึ้นใหม่เองจากพระราชดำรัสดิบ

### 10.3 คำราชาศัพท์และพระปรมาภิไธย

* พระปรมาภิไธยต้องเขียนเต็มตามที่ปรากฏในเอกสารทางการฉบับล่าสุด **ห้ามย่อเอง**
* คำราชาศัพท์ทุกคำต้องตรวจกับเอกสารทางการ
* 🚨 **ให้ผู้เขียนซึ่งเป็นเจ้าของผลงานตรวจย่อหน้าเหล่านี้ด้วยตนเองก่อนส่งเสมอ**
  และระบุไว้ในบัตรตรวจว่าเป็นจุดที่ต้องตรวจด้วยตา

## 🧱 12. ด่านโครงสร้างประโยค (Syntax Calque Gate) — ชั้นที่หายไประหว่างคำกับย่อหน้า

> เพิ่มเมื่อ 10 กันยายน 2569 หลังตรวจพบว่าร่างที่ผ่านด่านคำ (ข้อ 2) และด่านย่อหน้า (ข้อ 3) หมดแล้ว
> ยังอ่านเป็นสำนวนแปลอยู่ เพราะ **คำถูกทุกคำ แต่โครงประโยคยังเป็นโครงอังกฤษ**

### 12.1 ปัญหานี้คนละเรื่องกับข้อ 2

ข้อ 2 แก้ที่ **คำ** — เลือก "ความตรง" แทน "ความถูกต้อง"
ข้อ 12 แก้ที่ **โครง** — ประโยคที่ใช้คำไทยถูกทุกคำ แต่วางคำตามลำดับของภาษาอังกฤษ

ตัวอย่างที่คำถูกหมดแต่โครงผิด

* ❌ `การเพิ่มขึ้นของจำนวนของผู้เรียนที่มีความหลากหลายทางวัฒนธรรมได้ถูกพบว่ามีความสัมพันธ์กับ…`
* ✅ `ผู้เรียนที่มีภูมิหลังทางวัฒนธรรมต่างกันมีจำนวนมากขึ้น และจำนวนที่เพิ่มขึ้นนี้สัมพันธ์กับ…`

ประโยคแรกไม่มีคำแปลผิดแม้แต่คำเดียว แต่ยัดโครง `the increase of the number of` และโครงกรรมวาจก
`has been found to` ลงในภาษาไทยทั้งดุ้น

| :--- | :--- | :--- |
| การเพิ่มขึ้นของจำนวนของ… | the increase of the number of | จำนวน…เพิ่มขึ้น |
| ทำการศึกษา · ทำการวิเคราะห์ · ทำการทดลอง | conduct a study / perform an analysis | ศึกษา · วิเคราะห์ · ทดลอง |
| ดำเนินการจัดทำ · ดำเนินการพัฒนา | carry out the development of | จัดทำ · พัฒนา |
| มีความสำคัญ · มีความจำเป็น · มีความหลากหลาย | is important / necessary / diverse | สำคัญ · จำเป็น · หลากหลาย |
| มีการใช้ · มีการนำมาประยุกต์ | there is the use of | ใช้ · นำมาประยุกต์ |
| ในการที่จะทำให้… | in order to | เพื่อให้… · เพื่อ… |
| การมีอยู่ของ… | the existence of | ตัดทิ้ง แล้วเขียนเป็นประโยคบอกเล่า |
| มันเป็นสิ่งสำคัญที่จะต้อง… | it is important to… | จำเป็นต้อง… · ควร… |
| การให้ความสำคัญกับ (ทุกย่อหน้า) | focus on / emphasise | มุ่ง… · เน้น… |

**กฎ**: ถ้าประโยคหนึ่งมีคำขึ้นต้นด้วย `การ` หรือ `ความ` เกิน **3 คำ** ให้เขียนใหม่ โดยเปลี่ยนอย่างน้อยหนึ่งคำกลับเป็นกริยา

#### ข. โซ่ "ของ" — มาจากโซ่ of ในภาษาอังกฤษ

* ❌ `ผลของการใช้ของรูปแบบของการจัดการเรียนรู้ของครู`
* ✅ `ผลของรูปแบบการจัดการเรียนรู้ที่ครูใช้`

**เพดาน**: `ของ` ไม่เกิน **1 ครั้งต่อวลีนาม** และไม่เกิน **2 ครั้งต่อประโยค**
ส่วนที่เกินให้แปลงเป็นวลีขยายด้วย `ที่` หรือแตกเป็นประโยคใหม่

#### ค. กรรมวาจก (Passive) — ภาษาไทยส่วนใหญ่ไม่ต้องทำเครื่องหมาย

| ❌ | ต้นทาง | ✅ |
| :--- | :--- | :--- |
| ถูกใช้ · ถูกพบ · ถูกนำมาใช้ | is used / was found / was applied | ใช้ · พบ · นำมาใช้ |
| ได้รับการดำเนินการ · ได้รับการวิเคราะห์ | was conducted / was analysed | ดำเนินการ · วิเคราะห์ |
| ข้อมูลถูกเก็บรวบรวมโดยผู้วิจัย | data were collected by the researcher | ผู้วิจัยเก็บรวบรวมข้อมูล |
| เมื่อถูกนำเสนอด้วย… | when presented with… | เมื่อเผชิญกับ… |

🔴 `ถูก` ในภาษาไทยมีนัย **ไม่พึงประสงค์** — `ถูกวิจารณ์` `ถูกปฏิเสธ` ใช้ได้ แต่ `ถูกใช้` `ถูกพบ` ผิดน้ำเสียง
เมื่อจำเป็นต้องเลี่ยงการระบุผู้กระทำจริง ให้ใช้ `ได้รับการ…` และจำกัดปริมาณไว้
**`ถูก` กับ `ได้รับการ` รวมกันไม่เกิน 2 ครั้งต่อหน้า**

#### ง. อนุประโยคขยายซ้อน — หนึ่งประโยค สามอนุประโยค

* เพดาน `ซึ่ง` = **1 ครั้งต่อประโยค** (ย้ำจากข้อ 1)
* เพดาน `ที่` ในหน้าที่ประพันธสรรพนาม = **2 ครั้งต่อประโยค**
  ⚠️ ค้นด้วยคำเปล่าจะได้ผลบวกลวงจาก `ที่มา` `ที่ผ่านมา` `สถานที่` `ที่สุด` ต้องดูบริบททุกจุด
* `อัน` ในความเรียงวิชาการร่วมสมัยใช้น้อยมาก ถ้าเจอเกิน 1 ครั้งต่อหัวข้อย่อย แปลว่ากำลังลากอนุประโยคแบบอังกฤษ
* วิธีซ่อม: ตัดที่จุดเชื่อม แล้วขึ้นประโยคใหม่ด้วย `ทั้งนี้` `กล่าวคือ` `จึง` `ส่งผลให้`

#### จ. กาลและมาลา — ภาษาไทยไม่ทำเครื่องหมายกาลทุกประโยค

| ❌ ใช้พร่ำเพรื่อ | ต้นทาง | ✅ |
| :--- | :--- | :--- |
| ได้ศึกษา · ได้พบว่า · ได้มีการ (ทุกประโยค) | past tense | ศึกษา · พบว่า · มี |
| สามารถ…ได้ (ทุกประโยค) | can / be able to | ตัดทิ้ง หรือใช้ `ย่อม` `อาจ` |
| จะ (ในประโยคที่ไม่ใช่อนาคตจริง) | will / would | ตัดทิ้ง |
| มีแนวโน้มที่จะ | tend to | มัก… · โดยมาก… |
| ควรจะต้อง | should have to | ควร… |

**เพดาน**: `สามารถ…ได้` ไม่เกิน **2 ครั้งต่อหัวข้อย่อย** · `ได้` นำหน้ากริยาเพื่อบอกอดีต ไม่เกิน **3 ครั้งต่อย่อหน้า**

#### ฉ. เครื่องหมายพหูพจน์ที่ภาษาไทยไม่ต้องมี

* ❌ `ปัจจัยต่าง ๆ` `งานวิจัยต่าง ๆ` `นักเรียนทั้งหลาย` `ตัวแปรทั้งหลาย` — มาจากหน่วยพหูพจน์ `-s`
* ✅ `ปัจจัย` `งานวิจัย` `นักเรียน` `ตัวแปร` — ภาษาไทยเข้าใจเป็นพหูพจน์จากบริบทอยู่แล้ว
* คงไว้ได้เฉพาะเมื่อต้องการเน้นความหลากหลายจริง และไม่เกิน 1 ครั้งต่อย่อหน้า
* ❌ `จำนวนของผู้เข้าร่วม` ✅ `จำนวนผู้เข้าร่วม`

#### ช. บุพบทและวลีเชื่อมที่ลอกมาทั้งวลี

| ❌ | ต้นทาง | ✅ |
| :--- | :--- | :--- |
| ในแง่ของ · ในเทอมของ | in terms of | ด้าน… · ในด้าน… · เมื่อพิจารณาจาก… |
| เมื่อพูดถึง… | when it comes to | ในกรณีของ… · สำหรับ… |
| ผ่านทางการ… | through | ด้วย… · โดย… |
| ภายใต้บริบทของ | under the context of | ในบริบทของ |
| เล่นบทบาทสำคัญ | play an important role | มีบทบาทสำคัญ |
| เป็นที่น่าสังเกตว่า | it is worth noting that | ข้อสังเกตคือ · จะเห็นว่า |
| บนพื้นฐานของ | on the basis of | ตาม… · โดยอาศัย… (ใช้ได้ แต่ไม่เกิน 1 ครั้งต่อหัวข้อย่อย) |

#### ซ. ประธานย้ำซ้ำ — อังกฤษต้องมีประธานทุกประโยค ไทยละได้

* ❌ `ผู้วิจัยได้เก็บข้อมูล จากนั้นผู้วิจัยได้วิเคราะห์ข้อมูล และผู้วิจัยได้สรุปผล`
* ✅ `ผู้วิจัยเก็บรวบรวมข้อมูล วิเคราะห์ แล้วสรุปผลตามลำดับ`
* เกณฑ์: ประธานเดิมย้ำได้ไม่เกิน **2 ครั้งติดกัน** เว้นแต่การละทำให้กำกวมว่าผู้ใดเป็นผู้กระทำ

### 12.5 ข้อยกเว้น ห้ามนับเป็นความผิด (False-Positive Guard) 🔴

> เพิ่มเมื่อ 10 กันยายน 2569 หลังนำข้อ 12 ไปรันกับร่างตำราหลักเศรษฐศาสตร์ 2 บทจริง
> พบว่า **ผลบวกลวงมากกว่าความผิดจริงประมาณสามเท่า** ถ้าไม่มีบัญชีนี้ ผู้ใช้จะถูกสั่งให้แก้สิ่งที่ถูกอยู่แล้ว

| นับไม่ได้ | เหตุผล | ตัวอย่างจริง |
| :--- | :--- | :--- |
| `มีความ + ศัพท์เฉพาะ` | เป็นศัพท์บัญญัติของสาขา ไม่ใช่นามธรรมเฟ้อ | `อุปสงค์มีความยืดหยุ่นมาก` (elastic) · `มีความตรงเชิงเนื้อหา` (content validity) |
| `ต่าง ๆ` ที่อยู่ในนิยามมาตรฐานของสาขา | เป็นถ้อยคำของนิยามที่วงการล็อกไว้แล้ว แก้แล้วนิยามเพี้ยน | `ณ ระดับราคาต่าง ๆ ในช่วงเวลาหนึ่ง` ในนิยามอุปสงค์และอุปทาน |
| `สามารถ…ได้` ในถ้อยคำมาตรฐานของใบปะแผนบริหารการสอน | เป็นแบบฟอร์ม ไม่ใช่ความเรียง | `เมื่อเรียนจบบทนี้แล้ว นักศึกษาสามารถกระทำสิ่งต่อไปนี้ได้` |
| `ถูก` ที่เป็นคำวิเศษณ์ ไม่ใช่หน่วยกรรมวาจก | คนละคำกันโดยสิ้นเชิง | `ราคาถูกลง` · `คำตอบที่ถูกต้อง` · `ทำเลที่ค่าเช่าถูกลง` |
| `กว่าจะ` ที่เกิดจากคำติดกัน | ผลบวกลวงจากการค้นด้วยคำเปล่า | `เลือ**กว่าจะ**เปิดหรือปิด` · `มา**กว่าจะ**…` |
| `ก็` ที่อยู่ในคำอื่น | ผลบวกลวงจากรูปเขียน | `เ**ก็**บ` |
| `ที่` ที่ไม่ใช่ประพันธสรรพนาม | ผลบวกลวงจากการค้นด้วยคำเปล่า | `ที่มา` · `ที่ผ่านมา` · `ที่สุด` · `สถานที่` |

**กฎการรายงาน**: ตัวเลขจากการค้นอัตโนมัติคือ **จำนวนจุดที่ต้องเปิดดู** ไม่ใช่จำนวนความผิด
ต้องแยกรายงานสองตัวเลขเสมอ — `พบ n จุด · เป็นความผิดจริง m จุด · ผลบวกลวง n−m จุด`
รายงานเฉพาะตัวเลขดิบโดยไม่คัดกรอง ถือว่ายังไม่ได้ตรวจ

#### กับดักของ regex ภาษาไทย — ผลลบลวงที่มองไม่เห็น 🔴

ผลบวกลวงยังเห็นได้เพราะมันโผล่มาในรายงาน แต่ **ผลลบลวงเงียบสนิท** และเกิดจากสาเหตุเดียวซ้ำ ๆ

**สระหน้าเขียนไว้ก่อนพยัญชนะ** — `เ` `แ` `โ` `ใ` `ไ` (U+0E40–U+0E44) อยู่ **นอกช่วง** `[ก-ฮ]` (U+0E01–U+0E2E)
เงื่อนไข `ทำการ(?=[ก-ฮ])` จึงจับ `ทำการผลิต` ได้ แต่ **จับ `ทำการแบ่ง` `ทำการเลือก` `ทำการไหล` ไม่ได้เลย**

```text
❌ ทำการ(?=[ก-ฮ])          จับได้เฉพาะคำที่ขึ้นต้นด้วยพยัญชนะ
✅ ทำการ(?=[ก-ฮเแโใไ])     ครอบคลุมคำที่ขึ้นต้นด้วยสระหน้าด้วย
```

ใช้กฎเดียวกันกับทุกเงื่อนไขที่มองหา "พยัญชนะตัวถัดไป" — `การ` `ความ` `มี` `ถูก` `ได้รับการ`
ทดสอบทุกเงื่อนไขด้วยคำตัวอย่างที่ขึ้นต้นด้วยสระหน้าอย่างน้อยหนึ่งคำก่อนใช้จริง

## 🗂️ 13. คลังรูปประโยคไทยวิชาการ (Thai-First Pattern Bank)

> เพิ่มพร้อมข้อ 12 · **ข้อนี้คือส่วนที่ขาดหายมาตลอด** — ข้อ 1 สั่งให้ "ปิดต้นฉบับแล้วเขียนด้วยโครงประโยคไทย"
> แต่ไม่เคยบอกว่าโครงประโยคไทยมีอะไรให้หยิบใช้บ้าง เมื่อไม่มีคลังให้หยิบ ผู้เขียนและโมเดล
> ย่อมกลับไปหยิบโครงอังกฤษที่คุ้นที่สุดเสมอ

### 13.0 กฎการใช้คลังนี้ — ห้ามใช้เป็นตารางแปล

คลังนี้จัดตาม **หน้าที่ในความเรียง** ไม่ได้จัดตามคำอังกฤษ ออกแบบเช่นนี้โดยตั้งใจ
เพราะการจับคู่ `english phrase → วลีไทย` คือกลไกที่ผลิตสำนวนแปลตั้งแต่ต้นทาง

**ขั้นตอนที่ถูก**: ถามตัวเองว่าย่อหน้านี้ทำหน้าที่อะไร (นิยาม เปรียบเทียบ หรือระบุช่องว่าง)
แล้วเปิดหมวดนั้นเลือกรูปประโยค — ห้ามเริ่มจากประโยคอังกฤษแล้วย้อนมาหาคู่

### 13.1 กฎหลักฐานระดับวลี (Phrase-Level Evidence Rule) 🔴

ข้อ 2.1 บังคับหาหลักฐานของ **คำศัพท์** แต่ไม่เคยบังคับหาหลักฐานของ **วลี**
ช่องโหว่นี้คือทางที่สำนวนแปลเดินเข้ามา เพราะคำผ่านด่านไปหมดแล้ว

**ก่อนใช้วลีเชื่อมหรือรูปประโยคที่ไม่แน่ใจ ต้องตรวจว่ามีผู้เขียนไทยใช้จริงหรือไม่**

```text
1. ค้นวลีในเครื่องหมายคำพูดบน ThaiJO   "วลีที่สงสัย" site:so01.tci-thaijo.org
2. ค้นบน Google Scholar ภาษาไทย        "วลีที่สงสัย"
3. เทียบกับตำราไทยในสาขาที่ผู้ใช้แนบมา

เกณฑ์: พบในงานวิชาการไทยคนละสำนัก 2 ชิ้นขึ้นไป  → ใช้ได้
       พบเฉพาะในเว็บแปล บล็อก หรือคำบรรยายวิดีโอ → ห้ามใช้
       ไม่พบเลย                                   → เป็นวลีที่แปลขึ้นเอง ต้องเปลี่ยน
```

### 13.2 รูปประโยคตามหน้าที่

| หน้าที่ในความเรียง | รูปประโยคไทยที่ใช้ได้ | ข้อควรระวัง |
| :--- | :--- | :--- |
| **นิยาม** | `X (english) หมายถึง …` · `นักวิชาการให้ความหมายของ X ไว้หลากหลาย … สรุปได้ว่า …` · `ในการศึกษาครั้งนี้ X หมายถึง …` | เลี่ยง `X คือ…` ห้วน ๆ ในงานตำรา (ข้อ 9.4) |
| **จำแนกประเภท** | `X แบ่งออกเป็น n ประเภท ได้แก่ …` · `จำแนกตามเกณฑ์ … ได้เป็น …` · `ประกอบด้วยองค์ประกอบ n ประการ ดังนี้` | จำนวนต้องตรงต้นฉบับจริง ห้ามยุบเหลือ 3 เพื่อความสวยงาม (ข้อ 3.3) |
| **แจกแจงลำดับ** | `ประการที่หนึ่ง … ประการที่สอง … ประการสุดท้าย …` · `ข้อแรกคือ … ข้อถัดมาคือ …` | ❌ `สุดท้ายนี้` เป็นถ้อยคำปิดจดหมายและคำกล่าว ไม่ใช่ความเรียงวิชาการ |
| **เหตุและผล** | `เนื่องจาก … จึง …` · `ส่งผลให้ …` · `เป็นผลมาจาก …` · `ด้วยเหตุนี้ …` · `อธิบายได้ว่า …` | ห้ามใช้ `ดังนั้น` ทุกย่อหน้า ให้หมุนคลังคำ (ข้อ 3.3) |
| **เปรียบเทียบ** | `ต่างจาก … ตรงที่ …` · `สอดคล้องกับ …` · `ในทำนองเดียวกัน` · `เมื่อเทียบกับ … พบว่า …` · `ในทางกลับกัน` | `ในทางกลับกัน` ใช้เมื่อกลับด้านจริง ไม่ใช่แปลจาก on the other hand ทุกครั้ง |
| **เงื่อนไขและข้อยกเว้น** | `หาก … ย่อม …` · `เว้นแต่ …` · `ทั้งนี้ขึ้นอยู่กับ …` · `ภายใต้เงื่อนไขที่ว่า …` | — |
| **อ้างงานของผู้อื่น** | `ชื่อ (ปี) ศึกษา … พบว่า …` · `ผลการศึกษาของ … ชี้ให้เห็นว่า …` · `สอดคล้องกับข้อค้นพบของ …` · `ขณะที่ … ให้ข้อสรุปต่างออกไป` | หมุนกริยารายงาน ห้ามใช้ `พบว่า` ทุกประโยค (ข้อ 3.3) |
| **ระบุช่องว่างงานวิจัย** | `งานที่ผ่านมามุ่งไปที่ … แต่ยังไม่พบการศึกษาที่ …` · `ยังไม่มีข้อสรุปที่ตรงกัน` · `หลักฐานในบริบทไทยยังมีจำกัด` | ต้องมีหลักฐานรองรับจริง มิใช่อ้างว่าไม่มีเพราะยังค้นไม่พบ |
| **ข้อสรุปของผู้เขียน** | `จากที่กล่าวมา สรุปได้ว่า …` · `จึงกล่าวได้ว่า …` · `ข้อสังเกตที่ได้คือ …` · `ผู้เขียนเห็นว่า …` | ❌ ปิดทุกหัวข้อย่อยด้วย `กล่าวโดยสรุปได้ว่า` (ข้อ 3.2) |
| **ตีความผล** | `ผลดังกล่าวอธิบายได้ด้วย …` · `ข้อค้นพบนี้สะท้อนว่า …` · `เป็นไปได้ว่า …` | ระวังอ้างเกินหลักฐาน (ดูไฟล์ 6) |
| **ข้อจำกัด** | `ข้อค้นพบนี้จำกัดอยู่เฉพาะ …` · `ควรตีความด้วยความระมัดระวัง` · `ยังไม่อาจสรุปเป็นการทั่วไปได้` | — |
| **เชื่อมและส่งต่อหัวข้อ** | `ในหัวข้อต่อไปจะกล่าวถึง …` · `ส่วนที่กล่าวมาเป็น … ลำดับต่อไปคือ …` | ❌ `ส่วนที่เหลือของบทนี้จะ…` (ลอกจาก the remainder of this chapter) |

### 13.3 ช่องที่ยังต้องเติมจากคลังจริง `[ต้องยืนยันจากคลัง]`

ตารางข้างต้นครอบคลุมหน้าที่พื้นฐาน แต่ยังไม่ครอบคลุม **ภาษาเฉพาะสาขา**
รูปประโยคของสายวิทยาศาสตร์สุขภาพ สายวิศวกรรม และสายมนุษยศาสตร์ต่างกันจริง
ช่องเหล่านี้ต้องเติมจากเอกสารที่ผู้ใช้แนบมาตามข้อกำหนดในข้อ 15 ห้ามเติมด้วยการเดา

## 📗 14. กฎใช้คู่มือการเขียนภาษาอังกฤษ (Foreign Handbook Rule)

> เพิ่มพร้อมข้อ 12–13 · เกิดจากการนำ *Academic Writing Handbook for Learners in the FET Sector*
> (FESS และ ETBI สาธารณรัฐไอร์แลนด์ 2019) มาใช้เป็นฐานอ้างอิงการเขียน

คู่มือการเขียนภาษาอังกฤษมีของดีจริง แต่มันสอนสองอย่างพร้อมกัน คือ **วินัยการคิด** กับ **แม่แบบภาษา**
และแม่แบบภาษาของมันคือแม่แบบของภาษาอังกฤษ เมื่อรับมาทั้งก้อน
สิ่งที่ได้คือย่อหน้าไทยที่หายใจเป็นภาษาอังกฤษ

### 14.1 รับอะไร ปฏิเสธอะไร

| ✅ รับได้เต็ม (วินัยการคิด ไม่ผูกกับภาษา) | ❌ ปฏิเสธ (แม่แบบภาษา ผูกกับภาษาอังกฤษ) |
| :--- | :--- |
| ทุกข้ออ้างต้องมีหลักฐานรองรับ | แม่แบบ Topic Sentence / PEEL / TEEL วางทับทุกย่อหน้าไทย |
| หนึ่งย่อหน้าว่าด้วยหนึ่งความคิด | ตารางคำเชื่อม (transition words) แปลตรงตัวมาใช้ |
| เลี่ยงข้อความเหมารวมกว้าง ๆ | โซ่ `ประการแรก … นอกจากนี้ … สุดท้ายนี้` ที่ลอกจาก Firstly / Additionally / Finally |
| แยกข้อเท็จจริงออกจากความเห็น | ภาษาชี้ทางแบบ `บทความนี้จะโต้แย้งว่า…` (this essay will argue that) |
| เสนอมุมมองที่ต่างและตอบโต้ด้วยหลักฐาน | ประโยคสรุปย่อหน้าสำเร็จรูปติดท้ายทุกย่อหน้า |
| อ้างที่มาทุกครั้งที่หยิบความคิดผู้อื่นมา | น้ำเสียงคู่มือที่เรียกผู้อ่านว่า "คุณ" หรือสั่งผู้อ่านโดยตรง |
| ปริมาณไม่ได้แปลว่าคุณภาพ เขียนให้กระชับ | รูปแบบการอ้างอิงและเครื่องหมายวรรคตอนของคู่มือต่างประเทศ (ใช้ มรนว. 2568 และ APA 7th) |

### 14.2 ขั้นตอนบังคับเมื่อหยิบเนื้อหาจากคู่มือต่างประเทศ

1. อ่านจนจบหัวข้อ แล้วถามว่า **ข้อนี้เป็นเรื่องวินัยการคิด หรือเรื่องแม่แบบภาษา**
2. ถ้าเป็นวินัยการคิด รับสาระมา แล้วเขียนใหม่ด้วยรูปประโยคจากข้อ 13
3. ถ้าเป็นแม่แบบภาษา ให้ **หยุด** แล้วไปหาว่าตำราไทยหรือวารสาร TCI ทำหน้าที่เดียวกันนี้ด้วยรูปประโยคใด
4. ถ้าหาไม่พบ ให้เขียนแบบเรียบที่สุดโดยไม่ใช้แม่แบบใดเลย ดีกว่านำแม่แบบต่างประเทศมาแปล
5. ทุกครั้งที่หยิบสาระมา ต้องใส่นาม-ปี ตามข้อ 1 ขั้นที่ 5

### 14.3 ตัวอย่างเดียวกัน สองทาง

ย่อหน้าตัวอย่างเรื่องการออกกำลังกายกับสุขภาพจิตในคู่มือ FESS หน้า 35–36
มีสาระเหมือนกันทั้งสองทาง ต่างกันที่เส้นทางการเขียน

**❌ ทางแปลตรงตัว**

> การออกกำลังกายเป็นหนึ่งในวิธีที่มีประสิทธิภาพมากที่สุดในการปรับปรุงสุขภาพจิตของเรา ประการแรก การออกกำลังกายทางกายภาพสามารถต่อต้านอาการของภาวะซึมเศร้าและมีส่วนช่วยในการปรับปรุงอารมณ์ให้ดีขึ้นได้ เนื่องจากการออกกำลังกายจะปลดปล่อยสารเคมีซึ่งควบคุมอารมณ์และการนอนหลับ นอกจากนี้ การออกกำลังกายยังสามารถช่วยให้ผู้คนรับมือได้อย่างมีสุขภาพดีเมื่อถูกนำเสนอด้วยความท้าทายทางจิตใจหรืออารมณ์ต่าง ๆ ในชีวิต สุดท้ายนี้ การเข้าร่วมกิจกรรมทางกายภาพสามารถมอบโอกาสในการมีปฏิสัมพันธ์กับผู้คนได้

ร่องรอยที่ตรวจพบ: `หนึ่งใน…ที่สุด` · `การปรับปรุง` · `ของเรา` · `ทางกายภาพ` · `สามารถ…ได้` สามครั้ง ·
`มีส่วนช่วยในการ` · `เมื่อถูกนำเสนอด้วย` · `ต่าง ๆ` · `สุดท้ายนี้` ·
โซ่ ประการแรก–นอกจากนี้–สุดท้ายนี้ · ทุกประโยคยาวใกล้เคียงกัน

**✅ ทางเขียนไทยจากใจความ**

> การออกกำลังกายเป็นวิธีดูแลสุขภาพจิตที่ได้ผลชัดเจนวิธีหนึ่ง เหตุผลประการที่หนึ่งอยู่ที่กลไกทางสรีรวิทยา เมื่อร่างกายเคลื่อนไหว ระบบประสาทจะหลั่งสารที่ควบคุมอารมณ์และการนอนหลับ อาการของภาวะซึมเศร้าจึงทุเลาลง ประการที่สอง การออกกำลังกายเป็นทางเลือกในการรับมือความกดดันที่ไม่ก่อผลเสียตามมา ต่างจากการดื่มสุราหรือใช้สารเสพติด (Harris, Cronkite, & Moos, 2006) ประการที่สาม กิจกรรมทางกายเปิดโอกาสให้ผู้เข้าร่วมได้พบปะผู้อื่นและขยายเครือข่ายทางสังคม ซึ่งเป็นองค์ประกอบสำคัญของคุณภาพชีวิต (Higgins, 2008) อย่างไรก็ตาม งานวิจัยอีกกลุ่มหนึ่งชี้ว่าการออกกำลังกายที่มากเกินพอดีส่งผลเสียต่อสุขภาพเช่นกัน

สิ่งที่เปลี่ยน: แตกประโยคยาวเป็นสั้นสลับยาว · ตัด `ของเรา` และ `สามารถ…ได้` ออกทั้งหมด ·
ย้ายกลไกขึ้นก่อนผลตามลำดับที่ภาษาไทยเล่าเหตุและผล · ใช้ `จึง` แทนการลาก `ซึ่ง` ·
เก็บนาม-ปีและสาระครบเท่าเดิม · ประโยคปิดทำหน้าที่ส่งต่อย่อหน้าถัดไปโดยไม่ต้องมีคำว่า `สุดท้าย`

### 15.2 รูปแบบไฟล์ที่ใช้ได้จริง

* **หน้าที่มีค่าที่สุด**: เนื้อความบรรยายกลางบท และย่อหน้าที่นิยามศัพท์
* **หน้าที่แทบไม่มีค่า**: ปก คำนำ สารบัญ บรรณานุกรม ภาคผนวก และหน้าที่เป็นแบบฝึกหัดล้วน

### 15.3 สิ่งที่จะทำกับเอกสารที่ได้รับ

1. ถอด **รูปประโยคตามหน้าที่** เข้าตาราง 13.2 พร้อมระบุว่ามาจากเล่มใด หน้าใด
2. ถอด **คำศัพท์คู่ไทย-อังกฤษที่วงการใช้จริง** เข้าตาราง 2.4 พร้อมระบุที่มา
3. ถอด **โครงประโยคที่คนไทยใช้แต่ภาษาอังกฤษไม่มี** เข้าข้อ 12 เป็นทางเลือกฝั่ง ✅
4. ถ้าได้คู่แปลกับต้นฉบับตามลำดับที่ 7 ให้ทำ **ตารางเทียบสองคอลัมน์** ว่าเรื่องเดียวกันสองสำนวนต่างกันตรงไหน
5. ทุกแถวที่เพิ่ม ต้องมีช่องที่มา — **แถวที่ไม่มีที่มา ห้ามเพิ่ม**

### 15.4 ข้อจำกัดที่ต้องพูดตรง ๆ

* เอกสารที่มีลิขสิทธิ์ใช้เพื่อ **ถอดรูปแบบภาษาและอ้างอิงสาระ** เท่านั้น
  ห้ามคัดลอกข้อความยาวลงงานของผู้ใช้ (ดูข้อ 4 ด่านคุมความซ้ำ)
* ตารางในไฟล์นี้ที่ยังไม่มีเอกสารรองรับ จะทำเครื่องหมาย `[ต้องยืนยันจากคลัง]` กำกับไว้
  ห้ามรายงานว่าเป็นข้อมูลที่ตรวจสอบแล้ว

## 🔠 16. ด่านศัพท์ข้ามสื่อ (Cross-Medium Term Lock)

> เพิ่มเมื่อ 10 กันยายน 2569 จากการตรวจสเปกภาพและตารางของร่างตำราจริง
> ข้อ 2.3 ล็อกศัพท์ใน **ความเรียง** แต่ไม่ครอบไปถึง **หัวตาราง** และ **ป้ายกำกับในภาพ**
> ป้ายภาพจึงหลุดศัพท์นอกบัญชีได้โดยไม่มีด่านใดจับ
> 🔴 และเป็นจุดที่แก้ทีหลัง **แพงที่สุดในเล่ม** เพราะต้องแก้ไฟล์เวกเตอร์แล้วแทรกใหม่ ไม่ใช่แก้ข้อความใน Word

### 16.1 กฎสามข้อ

1. **ศัพท์ที่ปรากฏในภาพหรือตาราง ต้องอยู่ในบัญชี `[GLOSSARY-LOCK]` ของเนื้อความ** — ถ้าไม่อยู่ ต้องเพิ่มเข้าบัญชีก่อน ไม่ใช่ปล่อยให้ภาพใช้คำของตัวเอง
2. **ศัพท์ที่ปรากฏในภาพ ต้องมีนิยามอยู่ในเนื้อความก่อนหน้าภาพนั้น** — ภาพขยายความสิ่งที่ผู้อ่านรู้แล้ว **ห้ามภาพเป็นที่แรกที่ศัพท์นั้นโผล่มา**
3. **รูปคำต้องเป็นรูปเดียวกันทั้งสามสื่อ** — ถ้าเนื้อความเขียน `มีความยืดหยุ่นเท่ากับหนึ่งหน่วย` ป้ายภาพเขียน `ยืดหยุ่นหนึ่งหน่วย` ไม่ได้ เว้นแต่ประกาศรูปย่อไว้ในบัญชีตั้งแต่ต้นว่าใช้รูปใดในภาพ

### 16.2 ตารางตรวจสามทาง

ทำหนึ่งตารางต่อหนึ่งบท ก่อนส่งสเปกให้ figure-agent

```text
[CROSS-MEDIUM-TABLE] บทที่ __
| ศัพท์ | รูปในเนื้อความ (ย่อหน้า) | รูปในหัวตาราง (ตารางที่) | รูปในป้ายภาพ (ภาพที่) | ตรงกัน |
```

**ตัวอย่างจริงที่ตรวจพบ** — ตำราหลักเศรษฐศาสตร์ บทที่ 2

| ระดับความยืดหยุ่น | เนื้อความ | ตารางที่ 2.4 | ป้ายภาพ 2.3.1 | ผล |
| :--- | :--- | :--- | :--- | :---: |
| elastic | มีความยืดหยุ่นมาก (elastic) | ยืดหยุ่นมาก | ยืดหยุ่นมาก | ✅ |
| inelastic | มีความยืดหยุ่นน้อย (inelastic) | ยืดหยุ่นน้อย | ยืดหยุ่นน้อย | ✅ |
| unit elastic | มีความยืดหยุ่น**เท่ากับ**หนึ่งหน่วย | ยืดหยุ่นหนึ่งหน่วย | ยืดหยุ่นหนึ่งหน่วย | ⚠️ รูปคำต่าง |
| perfectly inelastic | **ไม่มีในเนื้อความ** | **ไม่มี** | ไม่มีความยืดหยุ่นเลย | 🔴 ผิดกฎข้อ 2 |
| perfectly elastic | **ไม่มีในเนื้อความ** | **ไม่มี** | ยืดหยุ่นสมบูรณ์ | 🔴 ผิดกฎข้อ 2 |

เนื้อความนิยามไว้สามระดับ แต่สเปกสั่งวาดห้าระดับ ผู้อ่านจะเจอศัพท์สองตัวในภาพที่ยังไม่เคยอ่านนิยาม
**ทางแก้มีสองทางเท่านั้น** — เพิ่มนิยามอีกสองระดับลงเนื้อความ หรือลดภาพเหลือสามแผง เลือกก่อนสั่งผลิต

### 16.3 ภาษาพูดในป้ายภาพ — เพดาน 0 และแพงกว่าเนื้อความ

บัญชีข้อ 9.7 ก. ใช้กับ **ข้อความที่จะถูกพิมพ์ลงในภาพ** ด้วย และต้องตรวจ **ก่อน** ส่งสเปก
ตัวอย่างจริง: ป้าย `ไม่มีความยืดหยุ่นเลย` มีคำว่า `เลย` ซึ่งเป็นคำเน้นแบบสนทนา
ถ้าปล่อยผ่าน คำนี้จะไปอยู่ในไฟล์เวกเตอร์ แก้ครั้งเดียวไม่พอ ต้องแก้แล้วแทรกใหม่ทั้งภาพ

**รูปที่ใช้แทน**: `ไม่ยืดหยุ่นโดยสิ้นเชิง` หรือรูปที่ตำราไทยในสาขานั้นใช้จริง — ยืนยันตามข้อ 13.1 ก่อน

### 16.4 ที่มาในบล็อกสเปกต้องแยกสองส่วนตามข้อ 11

ช่อง `ที่มาแนวคิด:` ของสเปกภาพอยู่ใต้กฎเดียวกับข้อ 11

| ❌ ไม่พอ | ✅ ผ่าน |
| :--- | :--- |
| `ที่มาแนวคิด: ดัดแปลงแนวคิดจาก OpenStax (2022).` | `ที่มาแนวคิด: แนวคิดกราฟสี่กรณีจาก OpenStax (2022) หน้า __ · การจัดสี่แผงในภาพเดียวและการเลือกใช้มาตราส่วนร่วมเป็นการออกแบบของผู้เขียน` |
| — | `ที่มาแนวคิด: ประมวลจากข้อมูลสมมติในตารางที่ 2.1` ✅ ชัดเจนอยู่แล้ว |
| — | `ที่มาแนวคิด: ออกแบบเองล้วน` ✅ ชัดเจนอยู่แล้ว |

คำว่า **ดัดแปลง** เพียงคำเดียวไม่บอกว่าดัดแปลงอะไร ผู้ประเมินแยกไม่ออกว่าส่วนใดเป็นผลงานของผู้เขียน

### 16.5 ตัวเลขต้องตรงกันข้ามสื่อ

ทุกตัวเลขที่ปรากฏในสเปกภาพต้องสอบกลับไปยังตารางต้นทางได้ทุกตัว
ตรวจก่อนส่งสเปก ไม่ใช่ตรวจตอนได้ภาพกลับมา

### 16.6 บัตรตรวจก่อนส่งสเปกให้ figure-agent

```
[CROSS-MEDIUM-AUDIT] บทที่ __
ศัพท์ในป้ายภาพที่ไม่อยู่ใน GLOSSARY-LOCK : ต้องเป็น 0 — ระบุคำที่พบ
ศัพท์ในภาพที่ยังไม่มีนิยามในเนื้อความ    : ต้องเป็น 0 — ระบุภาพที่ใด
รูปคำต่างกันระหว่างเนื้อความ/ตาราง/ภาพ   : ต้องเป็น 0 — ระบุคู่ที่ต่าง
คำภาษาพูดในป้ายภาพ (บัญชี 9.7 ก.)        : ต้องเป็น 0

ตัวเลขในสเปกที่สอบกลับตารางต้นทางไม่ได้   : ต้องเป็น 0
```
