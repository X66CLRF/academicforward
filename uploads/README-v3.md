### ชุดนี้ทำอะไรได้?

ชุด Agent Suite v3.0 ช่วยให้คุณ **เริ่มต้นงานเขียนได้ทันที** โดยไม่ต้องเดาว่า AI จะเข้าใจบริบทมหาวิทยาลัยของเราหรือเปล่า เพราะเราได้ฝังกฎ มรนว. 2568 + APA 7th ไว้ใน `CORE-rules.md` แล้ว

## 🚀 วิธีใช้ทีละขั้น

### ขั้นที่ 1 — เลือกไฟล์

ดูตาราง "เลือก Agent ให้ถูกตัว" ด้านบน → ระบุว่าคุณต้องใช้ไฟล์ใด

### ขั้นที่ 2 — เปิดไฟล์ที่ต้องการ

เปิดไฟล์ 2 ไฟล์นี้ในโปรแกรมแก้ข้อความ (Notepad, VS Code, ฯลฯ):

```
CORE-rules.md          ← ต้องแนบเสมอ
[role]-agent.md        ← ตามบทบาทของคุณ
```

### ขั้นที่ 3 — สร้าง System Prompt

**วิธีที่ 1: Claude.ai (Projects)**
1. ไปที่ Projects → สร้าง Project ใหม่
2. กด "Set project instructions"
3. Copy เนื้อหา `CORE-rules.md` วางก่อน แล้วตามด้วย `[role]-agent.md`
4. กด Save → ใช้ Project นี้สำหรับงานทุกชิ้น

**วิธีที่ 2: ChatGPT (Custom GPT)**
1. Explore GPTs → Create a GPT
2. ในช่อง Instructions → วาง `CORE-rules.md` + `[role]-agent.md`
3. Save → ใช้ Custom GPT นี้

**วิธีที่ 3: ใส่ใน Chat ทุกครั้ง (ทุก AI)**
1. เปิด Chat ใหม่
2. Paste เนื้อหาทั้ง 2 ไฟล์เป็นข้อความแรก
3. กด Send → AI จะรับ context แล้วเริ่มทำงาน

> 💡 **แนะนำวิธีที่ 1 หรือ 2** — ไม่ต้อง paste ซ้ำทุกครั้ง

### ขั้นที่ 4 — ตอบคำถามต้อนรับ

เมื่อ AI ได้รับ system prompt จะถาม 3 คำถาม:
1. ชื่อ/บทบาทของคุณ
2. หัวข้อ/ชื่อโปรเจกต์
3. โหมดที่ต้องการ (เลือก 1-4)

ตอบให้ครบทั้ง 3 ข้อ แล้ว AI จะเริ่มต้นทำงานในโหมดที่เลือก

### ขั้นที่ 5 — ทำงานเป็น Session

```
Session แนะนำต่อ 1 ครั้ง:
├── 1 หัวข้อ / 1 โหมด
├── ไม่เกิน 30-45 นาที
└── สิ้นสุด session → เปิด chat ใหม่สำหรับหัวข้อถัดไป
```

> ⚠️ AI ลืมทุกอย่างเมื่อปิด chat (ถ้าไม่ใช้ Projects/Custom GPT)  
> บันทึกงานออกมาทุกครั้งก่อนปิด

## 🔗 การใช้ CORE-rules.md ให้ถูกต้อง

`CORE-rules.md` คือ **"กฎรวมศูนย์"** ที่ agent ทุกตัวต้องอ้างอิง มีเนื้อหา:

```
CORE-rules.md ประกอบด้วย:
├── มาตรฐาน มรนว. 2568 (ฟอนต์ TH Sarabun New, ขนาด, ระยะห่าง)
├── APA 7th Edition (การอ้างอิงในเนื้อหา + บรรณานุกรม)
├── คำศัพท์เฉพาะ มรนว. (IS vs Thesis, ปริญญานิพนธ์ vs วิทยานิพนธ์)
└── Integrity Rules (ระดับความเข้มงวดตาม role)
```

### กฎการใช้ CORE-rules.md

| สถานการณ์ | วิธีปฏิบัติ |
|-----------|-----------|
| ใช้ agent คนเดียว | Paste CORE-rules.md + agent ไฟล์เดียว |
| ใช้หลาย agent วันเดียวกัน | ใช้ CORE-rules.md เดียวกัน ไม่ต้องแก้ |
| คู่มือ มรนว. update เป็น 2569 | แก้แค่ `CORE-rules.md` — agent อื่นๆ อัปเดตอัตโนมัติ |
| APA 8th ออกในอนาคต | แก้แค่ `CORE-rules.md` เช่นกัน |
| ต้องการปรับ tone เฉพาะกลุ่ม | แก้ `[role]-agent.md` นั้นๆ อย่างเดียว |

## 📁 โครงสร้างโฟลเดอร์ที่แนะนำ (สำหรับ Workshop)

จัดไฟล์งานวิจัยของคุณแบบ **3 มิติ** ก่อนเริ่ม:

```
📂 [ชื่อหัวข้อวิจัย]/
├── 01_[มิติที่ 1]/         ← เช่น 01_ทฤษฎีการเรียนรู้
├── 02_[มิติที่ 2]/         ← เช่น 02_เทคโนโลยีการศึกษา
├── 03_[มิติที่ 3]/         ← เช่น 03_กลุ่มตัวอย่าง
└── _UNSORTED/              ← ไฟล์ที่ยังไม่ได้จัดหมวด (safety net)
```

> ❗ **_UNSORTED ≠ ถังขยะ** — ย้ายไฟล์ที่ "ไม่ผ่าน" มาไว้ที่นี่ก่อน  
> รอ 7 วัน ค่อยพิจารณาซ้ำก่อนลบถาวร

## 📊 เปรียบเทียบ 3 Agents (v3.0)

| มิติ | ป.ตรี | ป.โท/เอก | นักวิจัย |
|------|------|---------|---------|
| **โทน** | "พี่/น้อง" อบอุ่น | "ผม/คุณ" มืออาชีพ | "Peer" ตรงประเด็น |
| **ความลึก APA** | กฎหลัก + ตัวอย่างเยอะ | ครบทุก edge case | ครบ + variant วารสาร |
| **สัดส่วน TH:EN** | 70:30 | 50–60 : 40–50 | ตาม target journal |
| **งานวิจัย/หัวข้อ** | 3–5 ชิ้น | 5–10 ชิ้น | 10–15 ชิ้น |
| **Theory source** | หนังสือพื้นฐาน | Primary + secondary | Seminal + recent reviews |
| **Integrity** | เข้มสุด | กลาง | ยืดหยุ่น |
| **Predatory check** | สั้น | กลาง | ละเอียด มี tools |
| **สื่อการเรียนรู้** | Lesson Plan + Quiz + Worksheet | Training Module + E-Learning | Course Design + Backward Design |
| **คู่มือ** | คู่มือโครงการ/ชมรม | SOP + Research Protocol | นโยบายสถาบัน + Lab Manual |
| **ตำรา** | ตำราระดับ ป.ตรี | ตำราระดับบัณฑิต | ตำราระดับบัณฑิตศึกษา |
